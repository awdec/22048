<h1><center>常见的不能用初等函数表示的不定积分</center></h1>

::: tip 一句话结论
下面这些不定积分虽然被积函数是初等函数，但其原函数**不能用初等函数表示**。数学二范围内，遇到它们"积不出来"是正常的：不定积分**不会**直接让你"积出来"，但"积不出来的函数"会以**变限积分**和**反常积分敛散性**的形式出现，那才是真正的考点。
:::

## 1. 什么叫"不能用初等函数表示"

对初等函数 $f(x)$，不定积分 $\int f(x)\,dx$ 的原函数**不一定**还是初等函数。

- $f$ 连续 ⇒ 原函数必存在，只是不能写成初等函数有限次复合的形式。
- 这是**本质的**"积不出来"，不是换元、分部技巧不够（严格证明属数学分析范畴，数学二只需记结论）。
- 数学二范围内，只需**记住清单**：会认、会判断即可，不需要记特殊函数名称。

## 2. 常见清单

| 不定积分 | 数学二中可能出现的方式 |
| --- | --- |
| $\displaystyle\int e^{-x^2}\,dx$ | 变限积分 $F(x)=\int_0^x e^{-t^2}\,dt$ 最常见 |
| $\displaystyle\int \frac{\sin x}{x}\,dx$ | 变限积分、分部积分中途出现 |
| $\displaystyle\int \frac{\cos x}{x}\,dx$ | 同上 |
| $\displaystyle\int \frac{e^x}{x}\,dx$ | 变限积分偶尔出现 |
| $\displaystyle\int \frac{dx}{\ln x}$ | 少见，认识即可 |
| $\displaystyle\int \sin(x^2)\,dx$ | 少见，认识即可 |

::: tip 记法要点
把"分母一次式的 $\dfrac{\sin x}{x}$、$\dfrac{\cos x}{x}$、$\dfrac{e^x}{x}$、$\dfrac{1}{\ln x}$"和"指数平方 $e^{\pm x^2}$"归为一类老朋友——**见到就停止尝试换元或分部**。这些积分对应的误差函数、正弦积分等特殊函数**不在考研范围内**，无需记名称。
:::

## 3. 数学二中的实际考法

**（1）不定积分：遇到就停。**
数学二不会考"把 $\int e^{-x^2}\,dx$ 积出来"。若某题算到中途出现这类积分，往往是你**方法选错**，需要回头检查（比如分部积分中 $u,\ dv$ 选反了）。

**（2）变限积分函数（高频考点）。**
"积不出来的函数"可以定义成**变限积分**，再反过来研究它。例如：

$$
F(x)=\int_0^x e^{-t^2}\,dt
$$

由微积分基本定理 $F'(x)=e^{-x^2}$——**不求原函数，而是对它求导**，进而求极限、判等价无穷小、研究单调性与极值。

**（3）反常积分：判敛散，不求值。**
反常积分 $\int_0^{+\infty} e^{-x^2}\,dx$ 的敛散性用**比较审敛法**判断即可（如 $x\ge1$ 时 $e^{-x^2}\le e^{-x}$），数学二**不要求**求出它的值。

::: warning 注意
"条件收敛 / 绝对收敛"及 Dirichlet、Abel 判别法**不属于数学二要求**，$\int_0^{+\infty}\dfrac{\sin x}{x}\,dx$ 这类振荡型反常积分的精细判别不必深究。
:::

## 4. 例题

::: info 例 1.
判断 $\int e^{-x^2}\,dx$ 能否用初等函数表示。
:::

::: details 解析
不能。$e^{-x^2}$ 的原函数不存在初等形式（严格证明属数学分析范畴，数学二只需记住结论）。

注意：数学二不会考"把它积出来"。它真正的用法是定义一个变限积分函数来研究，见例 2。
:::

::: info 例 2.
设 $F(x)=\int_0^x e^{-t^2}\,dt$。求 $F'(x)$、$F''(x)$，并求 $\lim\limits_{x\to0}\dfrac{F(x)}{x}$。
:::

::: details 解析
由微积分基本定理：

$$
F'(x)=e^{-x^2}
$$

再求导：

$$
F''(x)=-2x e^{-x^2}
$$

由导数定义，且 $F(0)=0$：

$$
\lim_{x\to0}\frac{F(x)}{x}=F'(0)=e^0=1
$$

**要点**：$\int e^{-x^2}\,dx$ 积不出来，但它的变限积分函数照样可求导、可求极限——这正是数学二的考法。
:::

::: info 例 3.
判断反常积分 $\int_0^{+\infty} e^{-x^2}\,dx$ 的敛散性。
:::

::: details 解析
分段讨论：

- 在 $[1,+\infty)$ 上，$x^2\ge x$，故 $e^{-x^2}\le e^{-x}$，而 $\int_1^{+\infty}e^{-x}\,dx$ 收敛，由比较审敛法，$\int_1^{+\infty}e^{-x^2}\,dx$ 收敛。
- 在 $(0,1]$ 上，$e^{-x^2}$ 连续有界，积分显然收敛。

故原反常积分收敛。**只需判敛散，不求值**——它的值 $\dfrac{\sqrt\pi}{2}$（高斯积分）不在数学二要求范围内。
:::

## 5. 小结

1. 认出清单里的"老朋友" → 不定积分不可初等表出 → 停止尝试。
2. 数学二真正考的是**变限积分函数**：积不出来没关系，用微积分基本定理求导、求极限。
3. 反常积分只**判敛散**（比较审敛法），不要求求出"积不出来"的积分值。
