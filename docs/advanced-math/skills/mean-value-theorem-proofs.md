<h1><center>各类中值定理证明题总结</center></h1>

::: tip 一句话
中值定理证明题只有三步：**看结论的形式 → 选定理 → 构造辅助函数**。难点全在第三步，而第三步有通法：把结论中的 $\xi$ 换成 $x$，解微分方程，把常数分离出来，剩下的就是辅助函数。本页把这套流程拆开，并汇总常见题型。
:::

定理的原始表述见[一元函数微分学第二节](../content/single-variable-differential-calculus/section-2)、[积分学第二节](../content/integral-calculus/section-2)。

::: tip 配套习题
本页讲方法，动手练见[各类中值定理证明题（专题习题）](./mean-value-theorem-exercises)——15 道题按题型分七组，全部配有折叠解析，并有一张题型与辅助函数的对照表。建议读完本页第 3 节后即开始做题。
:::

## 1. 四件工具的适用场景

| 工具 | 结论形式 | 什么时候用它 |
| --- | --- | --- |
| 罗尔定理 | $f'(\xi)=0$ | 结论能整理成"某个辅助函数的导数为 $0$" |
| 拉格朗日 | $f(b)-f(a)=f'(\xi)(b-a)$ | 结论含 $f(b)-f(a)$，或含两个函数值之差 |
| 柯西 | $\dfrac{f(b)-f(a)}{g(b)-g(a)}=\dfrac{f'(\xi)}{g'(\xi)}$ | 结论是两个增量之比，分母含 $b^2-a^2$、$e^b-e^a$ 等 |
| 泰勒公式 | 含 $f''(\xi)$、$f'''(\xi)$ | 出现二阶及以上导数的估计 |

选择顺序：

1. 先看**最高阶导数**。出现 $f''$ 基本锁定泰勒。
2. 再看**结论能不能写成"函数值之比"**。能写就是柯西或拉格朗日。
3. 都不是，就是罗尔——此时任务变成"构造辅助函数 + 找两个等值点"。

::: warning 使用前提
三个定理都要求**闭区间连续、开区间可导**，柯西还额外要求 $g'(x)\ne0$。答题时这三句话必须写出来，否则步骤分会被扣。
:::

## 2. 辅助函数构造通法：微分方程法

这是本页最重要的一节。设要证明存在 $\xi\in(a,b)$ 使某个含 $f(\xi),f'(\xi),\xi$ 的等式成立。

**步骤**：

1. 把结论中的 $\xi$ **换成 $x$**，得到一个关于 $f(x)$ 的微分方程；
2. 解这个微分方程，把任意常数 $C$ 单独留在一边，写成 $\Phi(x)=C$ 的形式；
3. $\Phi(x)$ 就是辅助函数。

**为什么成立**：$\Phi(x)=C$ 的两条积分曲线在等值点处切线水平，即 $\Phi'(\xi)=0$，而 $\Phi'(\xi)=0$ 恰好还原成原结论。

::: warning 本节只解决一半问题
微分方程法给出的是辅助函数 $F$，它**本身不保证 $\xi$ 存在**。真正保证存在的是**罗尔定理**——造出 $F$ 之后必须回到第 4 节找到 $F(a)=F(b)$，推理链才闭合。本节管"构造函数"，罗尔管"$\xi$ 存在"。
:::

**例**：要证 $f'(\xi)+\lambda f(\xi)=0$。

$$
f'+\lambda f=0
\ \Longrightarrow\
\frac{f'}{f}=-\lambda
\ \Longrightarrow\
\ln\lvert f\rvert=-\lambda x+C
\ \Longrightarrow\
f(x)e^{\lambda x}=C.
$$

所以辅助函数取 $F(x)=f(x)e^{\lambda x}$。验证：

$$
F'(x)=e^{\lambda x}\bigl(f'(x)+\lambda f(x)\bigr),
$$

$F'(\xi)=0$ 当且仅当 $f'(\xi)+\lambda f(\xi)=0$，正是要证的结论。

**更一般的形式**：结论若为 $a(\xi)f'(\xi)+b(\xi)f(\xi)=0$，解一阶线性齐次方程得

$$
F(x)=f(x)\exp\!\left(\int\frac{b(x)}{a(x)}\,dx\right).
$$

### 2.1 通法如何落地到各个定理

微分方程法只负责"辅助函数怎么找"，$\xi$ 的存在性由定理保证。**结论的形式决定落到哪个定理**：

| 结论的形式 | 落脚到哪个定理 | 具体做法 |
| --- | --- | --- |
| 只含 $\xi,\ f(\xi),\ f'(\xi)$ 的**单点形式** | **罗尔定理** | 用本节方法造 $F$，再按第 4 节找 $F(a)=F(b)$ |
| 含 $f(b)-f(a)$，能整理成增量比 | **拉格朗日** | 不必构造，直接引用 |
| 两个函数的增量比，分母形如 $b^2-a^2$、$e^b-e^a$ | **柯西** | 取对应的 $g$，直接引用；并验 $g'(x)\ne0$ |
| 含 $f''(\xi)$，或要对导数作估计 | **泰勒公式** | **不适用**本节方法，见第 6 节 |

**为什么后两种也能用本节方法解释**：结论中出现 $f(b)-f(a)$ 时，把它**当作常数**一起解进方程，造出的辅助函数恰好就是拉格朗日与柯西的标准辅助函数。

**拉格朗日**：

$$
f'(x)(b-a)-\bigl[f(b)-f(a)\bigr]=0
\ \Longrightarrow\
F(x)=(b-a)f(x)-\bigl[f(b)-f(a)\bigr]x.
$$

验证等值点：

$$
F(b)-F(a)=(b-a)\bigl[f(b)-f(a)\bigr]-\bigl[f(b)-f(a)\bigr](b-a)=0.
$$

**柯西**：

$$
f'(x)\bigl[g(b)-g(a)\bigr]-g'(x)\bigl[f(b)-f(a)\bigr]=0
\ \Longrightarrow\
F(x)=\bigl[g(b)-g(a)\bigr]f(x)-\bigl[f(b)-f(a)\bigr]g(x).
$$

同样有

$$
F(b)-F(a)=\bigl[g(b)-g(a)\bigr]\bigl[f(b)-f(a)\bigr]-\bigl[f(b)-f(a)\bigr]\bigl[g(b)-g(a)\bigr]=0.
$$

由罗尔定理得 $F'(\xi)=0$，还原成

$$
\frac{f'(\xi)}{g'(\xi)}=\frac{f(b)-f(a)}{g(b)-g(a)},
$$

这正是柯西中值定理。

::: tip 理解归理解，做题别绕远路
上面这两段说明的是**柯西与拉格朗日的辅助函数从哪来**——本质上它们也是"构造辅助函数 + 罗尔"的产物。但真正做题时，结论一旦是增量比的形式，**直接引用定理即可**，不必亲手把 $F$ 造出来。
:::

::: tip 积分中值定理的位置
积分中值定理不在这张表里——它不用来"落脚"，而是用来**造等值点**：由 $\displaystyle\int_a^b f=0$ 得到内部零点 $f(c)=0$，再把这个 $c$ 喂给罗尔定理。用法见第 4 节。
:::

## 3. 结论形式与辅助函数对照表

| 要证的结论 | 辅助函数 $F(x)$ | 求导依据 |
| --- | --- | --- |
| $f'(\xi)=0$ | $f(x)$ | $(f)'=f'$ |
| $f'(\xi)+\lambda f(\xi)=0$ | $f(x)e^{\lambda x}$ | $(fe^{\lambda x})'=e^{\lambda x}(f'+\lambda f)$ |
| $f'(\xi)-\lambda f(\xi)=0$ | $f(x)e^{-\lambda x}$ | $(fe^{-\lambda x})'=e^{-\lambda x}(f'-\lambda f)$ |
| $f'(\xi)+p(\xi)f(\xi)=0$ | $f(x)e^{\int p(x)dx}$ | 一阶线性齐次通式 |
| $\xi f'(\xi)+kf(\xi)=0$ | $x^kf(x)$ | $(x^kf)'=x^{k-1}(xf'+kf)$ |
| $f(\xi)+\xi f'(\xi)=0$ | $xf(x)$ | 上式中 $k=1$ |
| $\xi f'(\xi)-f(\xi)=0$ | $\dfrac{f(x)}{x}$ | 上式中 $k=-1$ |
| $f'(\xi)g(\xi)+f(\xi)g'(\xi)=0$ | $f(x)g(x)$ | 乘积求导法则 |
| $f'(\xi)g(\xi)-f(\xi)g'(\xi)=0$ | $\dfrac{f(x)}{g(x)}$ | 商的求导法则 |

::: tip 记忆抓手
- 系数是**常数 $\lambda$** $\to$ 配指数因子 $e^{\pm\lambda x}$；
- 系数是 **$x$ 的幂 $k$** $\to$ 配幂因子 $x^k$；
- 结论是**商的形式** $\dfrac{f'}{f}=\dfrac{g'}{g}$ $\to$ 辅助函数取 $\dfrac{f}{g}$；
- 结论是**乘积形式** $-\dfrac{f'}{f}=\dfrac{g'}{g}$ $\to$ 取 $fg$。

把 $f$ 换成 $g'$ 之类的复合情形，先化成上面九种之一再套。
:::

## 4. 罗尔定理的关键：找两个等值点

构造出 $F(x)$ 后，还要找到 $a,b$ 使 $F(a)=F(b)$。题目**直接给出** $f(a)=f(b)$ 是最省事的，否则用下面的办法"造"等值点：

| 造等值点的办法 | 说明 |
| --- | --- |
| 题设已给 | 如 $f(0)=f(1)=0$ |
| **介值定理 / 零点定理** | 由函数值符号或范围定出内部零点 |
| **积分中值定理** | $\displaystyle\int_a^b f=0\ \Rightarrow\ \exists c\in(a,b),\ f(c)=0$ |
| **费马引理** | 最值点、极值点处导数为 $0$，本身可能就是结论 |
| **对已知条件再取一次中值定理** | 由 $f'$ 的性质反推 $f$ 的等值点 |
| 由恒等式直接看出 | 如 $F(a)=F(b)=0$ 由构造方式自动成立 |

::: warning 开区间陷阱
罗尔定理给出的是 $\xi\in(a,b)$，**取不到端点**。用积分中值定理造点时，务必确认零点落在**开区间内部**：教材写的是 $\xi\in[a,b]$，但 $f$ 连续时结论可加强为 $\xi\in(a,b)$，答题时直接写开区间。

另外，若辅助函数含 $\dfrac{f(x)}{x}$ 这类项而区间端点含 $0$，需要先说明它可连续延拓（或用内部子区间绕开 $0$）。
:::

## 5. 双中值问题的处理

结论中出现**两个中值** $\xi,\eta$（通常还要求 $\xi\ne\eta$）时，分两种情形。

### 5.1 区间分割法

当结论中 $\xi$ 与 $\eta$ **可以分离**（各自出现在独立的因式或项里），做法是：

1. 在 $(a,b)$ 内取一个分点 $c$，$c$ 由题设条件确定（常用介值定理）；
2. 在 $[a,c]$ 与 $[c,b]$ 上**各用一次**中值定理；
3. 由于 $\xi\in(a,c)$、$\eta\in(c,b)$，两区间不相交，**$\xi\ne\eta$ 自动成立**，不必单独证明。

### 5.2 两次中值定理

当结论中 $\xi,\eta$ **耦合在同一个表达式里**，通常先用一次中值定理产生一个点，再对该点所在的区间用第二次。常见顺序是先拉格朗日后柯西，或先柯西后拉格朗日。

## 6. 泰勒公式证明题

**识别信号**：结论含 $f''(\xi)$、$f^{(n)}(\xi)$，或要对导数做**估计**（不等号）。

| 题目特征 | 展开点选在哪 |
| --- | --- |
| 给出 $f(0),f(1)$ 与 $f''$ | 在**中点** $x_0=\dfrac12$ 展开 |
| 存在极值或最值点 | 在**极值点**展开（该处 $f'=0$，可少一项） |
| 给出某点导数值 $f'(x_0)=k$ | 在 $x_0$ 展开 |
| 端点值为零 | 在内部极值点展开 |

**核心操作**：在展开点写泰勒公式，再把**区间的另一个端点**代进去，得到含 $f''(\xi_1)$ 与 $f''(\xi_2)$ 的两式，然后**相减或相加**，消去未知的 $f(x_0)$、$f'(x_0)$。

::: tip 看到"最大值"要先定位
题目说"最大值为 $M$"，先写一句：设最大值在 $x_0\in(a,b)$ 处取到，则 $f'(x_0)=0$（费马引理）。这一步既提供了展开点，又消掉了泰勒公式里的一次项。
:::

## 7. 用中值定理证明不等式

**固定套路**：

1. 把不等式整理成 $\dfrac{f(b)-f(a)}{b-a}$ 的形状；
2. 用拉格朗日写成 $f'(\xi)=\dfrac{f(b)-f(a)}{b-a}$；
3. 利用 $f'$ 在区间上的**单调性或上下界**，把 $f'(\xi)$ 放缩成 $f'(a)$ 与 $f'(b)$ 之间的值；
4. 代入 $\xi\in(a,b)$ 得结论。

**例**：证明 $0<a<b$ 时

$$
\frac{b-a}{b}<\ln\frac ba<\frac{b-a}{a}.
$$

取 $f(x)=\ln x$ 在 $[a,b]$ 上用拉格朗日：

$$
\ln\frac ba=\ln b-\ln a=f'(\xi)(b-a)=\frac{b-a}{\xi},\qquad a<\xi<b.
$$

由 $a<\xi<b$ 得 $\dfrac1b<\dfrac1\xi<\dfrac1a$，两边同乘 $b-a>0$ 即得结论。

## 8. 典型例题

::: info 例 1：指数因子型（罗尔 + $e^{-\lambda x}$）
设 $f(x)$ 在 $[0,1]$ 上连续，在 $(0,1)$ 内可导，且 $f(0)=f(1)=0$。证明存在 $\xi\in(0,1)$，使

$$
f'(\xi)=f(\xi).
$$

:::

::: details 解析
结论即 $f'(\xi)-f(\xi)=0$。按第 2 节通法，解 $f'-f=0$ 得 $f(x)e^{-x}=C$，故取

$$
F(x)=f(x)e^{-x}.
$$

验证罗尔三条件：$F$ 在 $[0,1]$ 上连续，在 $(0,1)$ 内可导，且

$$
F(0)=f(0)e^0=0,\qquad F(1)=f(1)e^{-1}=0.
$$

由罗尔定理，存在 $\xi\in(0,1)$ 使 $F'(\xi)=0$。而

$$
F'(x)=e^{-x}\bigl(f'(x)-f(x)\bigr),
$$

故 $f'(\xi)-f(\xi)=0$，即 $f'(\xi)=f(\xi)$。

**要点**：$e^{-x}$ 永远不为零，所以 $F'(\xi)$ 的零点与原结论完全等价，不会引入多余解。
:::

::: info 例 2：幂因子型（罗尔 + $x^k$）
设 $f(x)$ 在 $[0,1]$ 上连续，在 $(0,1)$ 内可导，且 $f(1)=0$。证明存在 $\xi\in(0,1)$，使

$$
\xi f'(\xi)=-2f(\xi).
$$

:::

::: details 解析
结论即 $\xi f'(\xi)+2f(\xi)=0$，属于 $\xi f'+kf=0$ 型（$k=2$），取

$$
F(x)=x^2f(x).
$$

$F(0)=0\cdot f(0)=0$，$F(1)=1\cdot f(1)=0$，罗尔三条件满足，故存在 $\xi\in(0,1)$ 使 $F'(\xi)=0$。而

$$
F'(x)=2xf(x)+x^2f'(x)=x\bigl(2f(x)+xf'(x)\bigr),
$$

当 $x=\xi\in(0,1)$ 时 $x\ne0$，故 $2f(\xi)+\xi f'(\xi)=0$，结论成立。

**要点**：幂因子 $x^k$ 在 $x=0$ 处为零，只要求 $f(1)=0$ 就够；但要确认 $\xi\ne0$ 才能在约去 $x$ 时保险。
:::

::: info 例 3：柯西中值定理
设 $f(x)$ 在 $[a,b]$ 上连续，在 $(a,b)$ 内可导，其中 $0\le a<b$。证明存在 $\xi\in(a,b)$，使

$$
2\xi\bigl[f(b)-f(a)\bigr]=(b^2-a^2)f'(\xi).
$$

:::

::: details 解析
把结论改写为增量之比：

$$
\frac{f(b)-f(a)}{b^2-a^2}=\frac{f'(\xi)}{2\xi}.
$$

右边正是 $\dfrac{f'(\xi)}{g'(\xi)}$ 的形状，取 $g(x)=x^2$，则 $g'(x)=2x$。

验证柯西的条件：$f,g$ 在 $[a,b]$ 连续、在 $(a,b)$ 可导；且当 $x\in(a,b)$ 时 $x>0$（因为 $a\ge0$ 且 $x>a\ge0$），故 $g'(x)=2x\ne0$。

由柯西中值定理，存在 $\xi\in(a,b)$ 使

$$
\frac{f(b)-f(a)}{b^2-a^2}=\frac{f'(\xi)}{2\xi},
$$

交叉相乘即得结论。

**要点**：必须交代 $g'(x)\ne0$。这里 $a\ge0$ 正是为了保证 $2x$ 在开区间内不为零；即使 $a=0$，$x\in(0,b)$ 时仍有 $x>0$。
:::

::: info 例 4：双中值（区间分割法）
设 $f(x)$ 在 $[0,1]$ 上连续，在 $(0,1)$ 内可导，且 $f(0)=0$，$f(1)=1$。证明存在**互不相同**的 $\xi,\eta\in(0,1)$，使

$$
\frac{1}{f'(\xi)}+\frac{1}{f'(\eta)}=2.
$$

:::

::: details 解析
结论中 $\xi$ 与 $\eta$ 分别出现在两个独立的项里，用**区间分割法**。

**第一步：找分点**。$f$ 在 $[0,1]$ 上连续，$f(0)=0<f(1)=1$，由介值定理存在 $c\in(0,1)$ 使

$$
f(c)=\frac12.
$$

**第二步：两段各用一次拉格朗日**。

在 $[0,c]$ 上：存在 $\xi\in(0,c)$ 使

$$
f(c)-f(0)=f'(\xi)(c-0)\ \Longrightarrow\ f'(\xi)=\frac{1/2}{c}=\frac{1}{2c}.
$$

在 $[c,1]$ 上：存在 $\eta\in(c,1)$ 使

$$
f(1)-f(c)=f'(\eta)(1-c)\ \Longrightarrow\ f'(\eta)=\frac{1/2}{1-c}=\frac{1}{2(1-c)}.
$$

**第三步：验证**。因为 $\xi\in(0,c)$、$\eta\in(c,1)$，两个区间不相交，所以 $\xi\ne\eta$ **自动成立**。且

$$
\frac{1}{f'(\xi)}+\frac{1}{f'(\eta)}=2c+2(1-c)=2.
$$

**要点**：分点 $c$ 由介值定理给出，取在函数值为 $\frac12$ 处是为了让两段增量都是 $\frac12$，这样相加才能消去 $c$。分点位置是从"想要什么结果"反推出来的。
:::

::: info 例 5：泰勒公式与最大值
设 $f(x)$ 在 $[0,1]$ 上二阶可导，$f(0)=f(1)=0$，且 $f$ 在 $[0,1]$ 上的最大值为 $1$。证明存在 $\xi\in(0,1)$，使

$$
f''(\xi)\le-8.
$$

:::

::: details 解析
最大值 $1>0=f(0)=f(1)$，故最大值在内部取到。设

$$
f(x_0)=1,\qquad x_0\in(0,1).
$$

由费马引理 $f'(x_0)=0$。

在 $x_0$ 处展开泰勒公式（展开到二阶），分别代入 $x=0$ 与 $x=1$：

$$
0=f(0)=1+f''(\xi_1)\frac{x_0^2}{2},\qquad
0=f(1)=1+f''(\xi_2)\frac{(1-x_0)^2}{2},
$$

其中 $\xi_1$ 在 $0$ 与 $x_0$ 之间、$\xi_2$ 在 $x_0$ 与 $1$ 之间。于是

$$
f''(\xi_1)=-\frac{2}{x_0^2},\qquad
f''(\xi_2)=-\frac{2}{(1-x_0)^2}.
$$

因为 $x_0$ 与 $1-x_0$ 中必有一个不超过 $\frac12$：若 $x_0\le\frac12$，则

$$
f''(\xi_1)=-\frac{2}{x_0^2}\le-\frac{2}{1/4}=-8;
$$

若 $x_0\ge\frac12$，则 $1-x_0\le\frac12$，

$$
f''(\xi_2)=-\frac{2}{(1-x_0)^2}\le-8.
$$

两种情况都找到满足 $f''(\xi)\le-8$ 的点 $\xi\in(0,1)$（分别取 $\xi=\xi_1$ 或 $\xi=\xi_2$）。

**要点**：不指定是 $\xi_1$ 还是 $\xi_2$，而是**分类讨论取较优的那个**——这是"存在性"证明的常见手法。展开点选在最值点，使一次项消失，是本题能算出来的关键。
:::

::: info 例 6：变限积分构造辅助函数
设 $f(x)$ 在 $[0,1]$ 上连续。证明存在 $\xi\in(0,1)$，使

$$
\int_0^{\xi}f(t)\,dt=(1-\xi)f(\xi).
$$

:::

::: details 解析
令 $u(x)=\displaystyle\int_0^x f(t)\,dt$。由微积分基本定理，$u$ 可导且 $u'(x)=f(x)$，$u(0)=0$。结论即为

$$
u(\xi)=(1-\xi)u'(\xi).
$$

按第 2 节的微分方程法，解 $u=(1-x)u'$：

$$
\frac{u'}{u}=\frac{1}{1-x}
\ \Longrightarrow\
\ln\lvert u\rvert=-\ln(1-x)+C
\ \Longrightarrow\
u(x)(1-x)=C.
$$

故取辅助函数

$$
F(x)=(1-x)u(x)=(1-x)\int_0^x f(t)\,dt.
$$

验证罗尔三条件：$F$ 在 $[0,1]$ 上连续，在 $(0,1)$ 内可导，且

$$
F(0)=(1-0)\cdot 0=0,\qquad
F(1)=(1-1)\int_0^1 f(t)\,dt=0.
$$

由罗尔定理，存在 $\xi\in(0,1)$ 使 $F'(\xi)=0$。而

$$
F'(x)=(1-x)u'(x)-u(x)=(1-x)f(x)-\int_0^x f(t)\,dt,
$$

故

$$
(1-\xi)f(\xi)-\int_0^{\xi}f(t)\,dt=0,
$$

即 $\displaystyle\int_0^{\xi}f(t)\,dt=(1-\xi)f(\xi)$。

**要点**：**看到结论含变限积分，就把积分整体记作 $u(x)$**，然后对 $u$ 用微分方程法。变限积分天然满足 $u(a)=0$，这是最容易凑出的一个等值点。
:::

## 9. 易错结论速查

| 说法 | 判断与说明 |
| --- | --- |
| 罗尔定理只要求 $f(a)=f(b)$ | 错，还要求闭区间连续、开区间可导 |
| 拉格朗日定理要求 $f(a)=f(b)$ | 错，那是罗尔定理的条件；拉格朗日没有这一条 |
| 柯西定理不需要额外条件 | 错，还要求 $g'(x)\ne0$，否则分母可能为零 |
| 柯西定理中令 $g(x)=x$ 就退化为拉格朗日 | 对，这是两者的包含关系 |
| 中值定理中的 $\xi$ 唯一 | 错，只保证**存在**，不保证唯一 |
| $\xi$ 可以取到区间端点 | 错，三个定理都给出 $\xi\in(a,b)$ 的开区间 |
| 辅助函数随便构造一个即可 | 错，必须使 $F'(\xi)=0$ **等价于**待证结论，且满足罗尔三条件 |
| 双中值题必须单独证明 $\xi\ne\eta$ | 错，用区间分割法时两区间不相交，自动保证 |
| 结论含 $f''(\xi)$ 就用泰勒 | 对，这是最可靠的识别信号 |
| 泰勒展开点随便选都一样 | 错，展开点决定能否算出来，应按题目给的条件选 |
| 含变限积分时不知道从何下手 | 把积分记作 $u(x)$，再套微分方程法 |
| 用中值定理证不等式时直接代端点 | 错，要先用 $f'$ 的单调性或上下界把 $f'(\xi)$ 夹住再放缩 |

::: tip 答题清单
**第一步**，把结论中的 $\xi$ 换成 $x$，判断属于第 3 节表中的哪一行，写出辅助函数。
**第二步**，逐条交代三个条件：闭区间连续、开区间可导、（柯西时）$g'\ne0$。
**第三步**，明确写出 $F(a)=F(b)$ 的位置和数值。
**第四步**，求导并代 $\xi$，说明 $F'(\xi)=0$ 如何还原成待证结论。

四步齐全，步骤分就稳了。
:::
