<h1><center>第一节 计算机网络概述</center></h1>

::: info 例 1
路由器属于互联网的边缘部分还是核心部分？
:::

::: details 解析
通常属于核心部分，负责在不同链路和网络之间转发分组。端系统及其应用构成边缘部分。
:::

::: info 例 2
比较电路交换与分组交换对突发数据的适应性。
:::

::: details 解析
电路交换需先建立并独占资源，突发间歇期间资源可能闲置；分组交换统计复用链路，无需为单个通信长期预留资源，更适合突发数据。
:::

::: info 例 3
星形网络中一条主机链路故障和中心节点故障的影响有何不同？
:::

::: details 解析
单条主机链路故障通常只影响该主机；中心节点故障可能导致整个星形网络无法通信，因此中心节点是单点故障。
:::

::: info 例 4
在 $10\text{ Mbps}$ 链路上发送一个 $1500\text{ B}$ 分组，求发送时延。
:::

::: details 解析
$$
d_{trans}=\frac{1500\times8}{10\times10^6}
=1.2\text{ ms}.
$$
:::

::: info 例 5
链路长 $2000\text{ km}$，传播速度为 $2\times10^8\text{ m/s}$，求传播时延。
:::

::: details 解析
$$
d_{prop}=\frac{2\times10^6}{2\times10^8}
=0.01\text{ s}=10\text{ ms}.
$$
:::

::: info 例 6
一条 $100\text{ Mbps}$ 链路的单程传播时延为 $20\text{ ms}$，求时延带宽积。
:::

::: details 解析
$$
100\times10^6\times20\times10^{-3}
=2\times10^6\text{ bit}.
$$
即链路中可以同时“飞行”约 $2$ Mbit 数据。
:::

::: info 例 7
两条串联链路的速率分别为 $100\text{ Mbps}$ 和 $10\text{ Mbps}$，忽略其他限制，稳定端到端吞吐量上限是多少？
:::

::: details 解析
端到端吞吐量受最慢瓶颈链路限制，因此不超过 $10\text{ Mbps}$。
:::

::: info 例 8
主机通过两台存储转发路由器发送一个长度为 $12000$ bit 的分组，三条链路速率均为 $2\text{ Mbps}$，忽略传播、排队和处理时延。求分组从开始发送到完整到达的时间。
:::

::: details 解析
每条链路的发送时延为：
$$
\frac{12000}{2\times10^6}=6\text{ ms}.
$$
分组经过三条链路，存储转发要求路由器完整接收后再发送，因此总时间为：
$$
3\times6=18\text{ ms}.
$$
:::

## 答题技巧

- 时延题先区分处理、排队、发送和传播时延。
- 多跳存储转发题要明确分组数和链路数。
- 发送时延与分组长度相关，传播时延与链路距离相关。
