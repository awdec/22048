<h1><center>第二节 计算机网络体系结构与参考模型</center></h1>

::: info 例 1
“规定确认报文中各字段的含义”属于协议三要素中的哪一个？
:::

::: details 解析
属于语义。字段的格式属于语法，发送与响应的先后次序以及速度匹配属于同步。
:::

::: info 例 2
协议、服务和接口三者之间是什么关系？
:::

::: details 解析
协议规定不同系统中对等实体之间如何通信；下层按照协议实现功能，并通过接口向上层提供服务。协议是水平关系，服务是垂直关系，接口是相邻层交换信息的位置和规则。
:::

::: info 例 3
交换机根据 MAC 地址转发帧，路由器根据 IP 地址转发分组，它们主要工作在哪一层？
:::

::: details 解析
二层交换机主要工作在数据链路层；路由器主要工作在网络层。
:::

::: info 例 4
应用报文从发送主机到接收主机时，封装和解封装方向如何？
:::

::: details 解析
发送端从应用层向下逐层添加控制信息，数据链路层还可能添加尾部；接收端从物理层向上逐层检查并去除相应控制信息，最终把应用数据交给目标进程。
:::

::: info 例 5
TCP/IP 的应用层大致对应 OSI 模型中的哪些层？
:::

::: details 解析
大致对应 OSI 的应用层、表示层和会话层。TCP/IP 没有单独设置表示层和会话层，这些功能由具体应用协议或应用程序实现。
:::

::: info 例 6
五层模型中，MAC 地址、IP 地址和端口号分别在哪一层使用？
:::

::: details 解析
MAC 地址用于数据链路层，IP 地址用于网络层，端口号用于传输层。端到端进程通信通常需要 IP 地址与端口号共同定位通信端点。
:::

::: info 例 7
为什么说分层体系结构既降低了复杂度，也会带来额外开销？
:::

::: details 解析
分层把复杂通信任务拆成职责清晰的模块，便于实现、维护和标准化；但数据需要逐层添加首部并经过多层处理，还可能出现功能重复，因此会增加传输和处理开销。
:::

## 答题技巧

- 设备题先判断它检查哪一层的首部或地址。
- 区分对等层之间的协议与相邻层之间的服务。
- 记忆各层时同时关联核心功能、地址和数据单元。
