<h1><center>第二节 域名系统</center></h1>

::: info 例 1
把域名映射到 IPv4 和 IPv6 地址分别使用什么记录？
:::

::: details 解析
IPv4 使用 A 记录，IPv6 使用 AAAA 记录。
:::

::: info 例 2
本地 DNS 缓存中已有有效记录，客户端解析域名还需要查询根服务器吗？
:::

::: details 解析
不需要。本地 DNS 可直接返回缓存结果，直到记录 TTL 到期或被更新清除。
:::

::: info 例 3
DNS 是否只使用 UDP 53？
:::

::: details 解析
不是。普通短查询通常使用 UDP 53；区域传送、响应过大或需要可靠传输时可使用 TCP 53。
:::

::: info 例 4
客户端请求本地 DNS 服务器代为完成解析，并返回最终答案或错误而不是转介，这属于递归还是迭代查询？
:::

::: details 解析
这属于对递归查询服务的请求。只有本地 DNS 服务器支持并允许递归时，它才会代客户端继续查询并返回最终答案或错误；本地 DNS 服务器查询其他服务器时通常采用迭代查询，逐步获得下一步转介。
:::
