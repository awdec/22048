<h1><center>第五节 万维网</center></h1>

::: info 例 1
忽略 DNS 和对象传输时间，使用非持续 HTTP 获取一个对象至少约需几个 RTT？
:::

::: details 解析
约需 $2RTT$：一个 RTT 建立 TCP 连接，一个 RTT 发送 HTTP 请求并收到响应首字节。
:::

::: info 例 2
HTTP 是无状态协议，为什么网站仍能保持登录状态？
:::

::: details 解析
网站可以通过 Cookie、会话标识或令牌把多个请求关联起来。无状态只表示 HTTP 核心请求—响应协议不会自动保存应用会话。
:::

::: info 例 3
缓存发送条件请求，资源未修改时服务器典型返回什么状态码？
:::

::: details 解析
返回 `304 Not Modified`，客户端继续使用缓存副本，无须重新传输完整对象。
:::

::: info 例 4
HTTP 请求报文和响应报文的首行分别叫什么？
:::

::: details 解析
请求报文首行称为请求行，包含方法、资源路径和 HTTP 版本；响应报文首行称为状态行，包含 HTTP 版本、状态码和原因短语。
:::

::: info 例 5
HTTP 持续连接与 Cookie 分别解决什么问题？
:::

::: details 解析
持续连接复用传输连接，减少握手和连接管理开销；Cookie 用于把不同请求关联到应用会话，帮助服务器实现状态管理。
:::

::: info 例 6
浏览器首次访问某域名，DNS 缓存均未命中；本地 DNS 解析耗时 $3RTT_{DNS}$，随后通过非持续 HTTP 获取一个对象。忽略传输时间，总时延近似是多少？
:::

::: details 解析
DNS 解析耗时 $3RTT_{DNS}$。非持续 HTTP 还需要一个 RTT 建立 TCP，并需要一个 RTT 从发送请求到收到响应首字节：
$$
T\approx3RTT_{DNS}+RTT_{TCP}+RTT_{HTTP}.
$$
若各 RTT 相同，可近似为 $5RTT$。
:::

## 答题技巧

- Web 时延题依次分析 DNS、连接建立、HTTP 请求和对象传输。
- 明确持续或非持续、串行或并行，以及题目是否忽略传输时间。
