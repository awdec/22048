<h1><center>第四节 电子邮件</center></h1>

::: info 例 1
用户向邮件服务器发送邮件，以及从服务器读取邮件，分别常用什么协议？
:::

::: details 解析
邮件提交和服务器之间转发通常使用 SMTP；用户从邮件服务器读取邮件可以使用 POP3。
:::

::: info 例 2
SMTP 与 POP3 的通信方向有何区别？
:::

::: details 解析
SMTP 用于把邮件推送到服务器或下一台邮件服务器；POP3 用于接收方客户端从自己的邮件服务器下载邮件。
:::

::: info 例 3
发送方邮件服务器如何找到接收域的邮件服务器？
:::

::: details 解析
它查询 DNS 中接收域的 MX 记录，获得负责接收邮件的服务器名称，再解析其地址并建立 SMTP 连接。
:::

::: info 例 4
MIME 的主要作用是什么？
:::

::: details 解析
MIME 为邮件定义内容类型、字符集和传输编码，使原本面向 ASCII 文本的邮件系统可以传输非 ASCII 文本、图片、音视频和附件。
:::

::: info 例 5
邮件首部中的 `To` 是否一定等于 SMTP 信封中的实际收件地址？
:::

::: details 解析
不一定。邮件首部属于展示给用户的内容格式，SMTP 信封地址用于实际投递；转发、密送等场景下二者可能不同。
:::
