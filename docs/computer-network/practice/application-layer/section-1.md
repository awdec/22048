<h1><center>第一节 网络应用模型</center></h1>

::: info 例 1
P2P 系统是否完全不存在服务器？
:::

::: details 解析
不一定。P2P 的核心是对等方直接提供和请求资源，实际系统仍可能使用中心服务器完成登录、索引或协调，但主要数据交换可在对等方之间进行。
:::

::: info 例 2
判断网络应用采用 C/S 还是 P2P 模型，关键是看参与主机的数量，还是看主机承担的通信角色？
:::

::: details 解析
关键是看通信角色。C/S 模型中的客户主要请求服务，服务器主要提供服务；P2P 模型中的对等方既可请求资源，也可直接向其他对等方提供资源。服务器使用多台主机或集群实现，并不会因此自动变成 P2P 模型。
:::
