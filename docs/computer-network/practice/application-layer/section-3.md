<h1><center>第三节 文件传输协议</center></h1>

::: info 例 1
FTP 为什么使用两条 TCP 连接？
:::

::: details 解析
控制连接长期传输命令和响应，数据连接按文件或目录传输任务建立并关闭。分离控制与数据后，一个控制会话可以连续组织多个独立传输任务。
:::

::: info 例 2
FTP 控制连接通常使用哪个服务器端口？
:::

::: details 解析
使用 TCP 端口 21。控制连接通常在整个 FTP 会话期间保持打开。
:::

::: info 例 3
为什么 FTP 被动模式更容易穿越客户端侧 NAT 和防火墙？
:::

::: details 解析
被动模式中的数据连接也由客户端主动发起，NAT 和防火墙通常允许内部发起的出站连接；主动模式要求服务器反向连接客户端端口，更容易被拦截。
:::

::: info 例 4
FTP 主动模式和被动模式的核心区别是什么？
:::

::: details 解析
核心区别是数据连接的发起方。主动模式由服务器主动连接客户端数据端口；被动模式由客户端连接服务器告知的临时数据端口。
:::

::: info 例 5
一次文件传输完成后，FTP 控制连接是否必须同时关闭？
:::

::: details 解析
不必。数据连接通常在一次传输完成后关闭，而控制连接可以继续保持，用于发起后续目录操作或文件传输，直到会话结束。
:::
