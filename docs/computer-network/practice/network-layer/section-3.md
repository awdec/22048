<h1><center>第三节 IPv6</center></h1>

::: info 例 1
IPv6 基本首部是否包含首部校验和？路由器能否对普通 IPv6 分组分片？
:::

::: details 解析
IPv6 基本首部不包含首部校验和；中间路由器不进行分片，必要的分片由源主机通过分片扩展首部完成。
:::

::: info 例 2
IPv6 地址中的 `::` 为什么在一个地址中只能出现一次？
:::

::: details 解析
`::` 表示一段或多段连续的零。若出现两次，就无法唯一判断每处应补多少个零段，地址会产生歧义。
:::

::: info 例 3
IPv6 为什么不需要广播地址？
:::

::: details 解析
IPv6 使用组播把数据发送给一组接口，使用任播把数据交付给多个接口中路由意义上最近的一个，因此没有定义 IPv4 式广播。
:::
