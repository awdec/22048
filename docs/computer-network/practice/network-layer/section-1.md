<h1><center>第一节 网络层的功能</center></h1>

::: info 例 1
网络层的路由选择和分组转发有什么区别？
:::

::: details 解析
路由选择属于控制平面，计算到目的网络的路径并生成路由信息；分组转发属于数据平面，根据转发表为每个到达分组选择输出接口和下一跳。
:::

::: info 例 2
互联网网络层的“尽最大努力交付”意味着什么？
:::

::: details 解析
IP 尝试把数据报送到目的地，但不保证可靠、按序、无重复或固定时延。需要可靠性时通常由传输层或应用层提供。
:::

::: info 例 3
网络层拥塞控制与流量控制保护的对象有何不同？
:::

::: details 解析
网络层拥塞控制防止链路、路由器和缓存等网络资源过载，保护网络整体；流量控制限制发送速度以适应接收端的处理与缓存能力。
:::

::: info 例 4
SDN 为什么被概括为“控制平面与数据平面分离”？
:::

::: details 解析
逻辑集中的控制器掌握网络状态、计算路径并下发转发规则；转发设备的数据平面按照规则高速处理分组，不需要每台设备独立完成全部控制决策。
:::

::: info 例 5
数据报服务发生中间路由器故障时，为什么通常比虚电路服务更容易适应？
:::

::: details 解析
数据报可以为后续分组重新选择可用路径；虚电路依赖建立时确定的状态和路径，路径中设备故障后通常需要重新建立虚电路。
:::
