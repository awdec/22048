<h1><center>第六节 移动 IP</center></h1>

::: info 例 1
移动节点离开归属网络后，通信对端是否必须改用它的转交地址发送分组？
:::

::: details 解析
不必。通信对端仍向归属地址发送，归属代理截获分组并通过隧道转发到已注册的转交地址，使上层连接继续使用固定归属地址。
:::

::: info 例 2
归属地址与转交地址分别表示什么？
:::

::: details 解析
归属地址是移动节点长期使用的身份地址；转交地址反映移动节点当前所在网络的位置，用于把分组转发到当前位置。
:::

::: info 例 3
移动节点进入外地网络后为什么需要向归属代理注册？
:::

::: details 解析
注册使归属代理建立“归属地址 → 转交地址”的绑定，之后才能把发往归属地址的分组正确隧道转发到移动节点当前位置。
:::

::: info 例 4
什么是移动 IP 中的三角路由？
:::

::: details 解析
通信对端发出的分组先到归属网络，再经归属代理绕行到移动节点；移动节点的返回分组可能直接发往通信对端，往返路径形成三角形。
:::

::: info 例 5
移动节点回到归属网络后应做什么？
:::

::: details 解析
它应注销转交地址或让绑定失效，停止归属代理的隧道转发，恢复在归属网络中的普通直接交付。
:::
