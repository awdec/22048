<h1><center>第二节 IPv4</center></h1>

::: info 例 1
IPv4 首部长度字段为 6，总长度字段为 1000，求首部和数据长度。
:::

::: details 解析
首部长度字段以 4 字节为单位：
$$
H=6\times4=24\text{ B}.
$$
数据长度为 $1000-24=976\text{ B}$。
:::

::: info 例 2
一个总长 $4000\text{ B}$、首部 $20\text{ B}$ 的 IPv4 数据报经过 MTU 为 $1500\text{ B}$ 的链路，最大分片数据长度是多少？
:::

::: details 解析
每片最多携带 $1500-20=1480\text{ B}$ 数据，且 1480 是 8 的倍数，适合作为非最后分片的数据长度。
:::

::: info 例 3
求地址 `192.168.10.130/26` 的网络地址、广播地址和传统可用主机范围。
:::

::: details 解析
`/26` 每个地址块有 64 个地址，130 位于 128～191：

- 网络地址：`192.168.10.128`。
- 广播地址：`192.168.10.191`。
- 可用范围：`192.168.10.129`～`192.168.10.190`。
:::

::: info 例 4
路由表同时有 `10.0.0.0/8`、`10.1.0.0/16` 和默认路由，目的地址 `10.1.2.3` 选择哪一条？
:::

::: details 解析
前两条都匹配，选择最长前缀 `/16`，因为它描述的目的范围更具体。
:::

::: info 例 5
将连续的 `192.168.0.0/24` 与 `192.168.1.0/24` 聚合，结果是什么？
:::

::: details 解析
两个地址块连续、大小相同且边界对齐，可以聚合为 `192.168.0.0/23`。
:::

::: info 例 6
主机 A 向不同子网的主机 B 发送数据，第一个以太网帧的目的 MAC 和 IP 数据报目的地址分别是谁？
:::

::: details 解析
帧目的 MAC 是 A 的默认网关接口 MAC；IP 目的地址仍是最终主机 B 的 IP 地址，无 NAT 时跨越各跳通常保持不变。
:::

::: info 例 7
写出 DHCP 四步交互顺序。
:::

::: details 解析
```text
Discover → Offer → Request → ACK
```
客户端通常使用 UDP 68，服务器使用 UDP 67。
:::

::: info 例 8
`traceroute` 为什么能够发现路径上的路由器？
:::

::: details 解析
它发送 TTL 逐步增加的探测分组。TTL 在某台路由器减为 0 时，路由器返回 ICMP 时间超过报文，源主机据此获得该跳地址。
:::

::: info 例 9
两个内网主机使用相同源端口访问同一公网服务器，NAPT 如何区分连接？
:::

::: details 解析
NAPT 为不同内部地址与端口组合分配不同的公网源端口并维护映射。返回报文到达后，再根据公网端口映射回相应内部连接。
:::

::: info 例 10
地址块 `10.0.0.0/24` 要划分至少 6 个等长子网，每个子网至少容纳 25 台主机，应使用什么前缀？
:::

::: details 解析
至少 6 个子网需要借 3 位，得到 $2^3=8$ 个子网，前缀为 `/27`。每个子网有 32 个地址，传统可用主机地址 30 个，满足要求。
:::

## 答题技巧

- 子网题先由主机数确定主机位，再检查子网数量。
- 分片题注意片偏移以 8 字节为单位。
- 跨网封装要区分最终目的 IP 与下一跳 MAC。
