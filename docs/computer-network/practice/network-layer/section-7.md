<h1><center>第七节 网络层设备</center></h1>

::: info 例 1
说明路由表与转发表的区别，并指出输入端口收到分组后主要查询哪一个。
:::

::: details 解析
路由表属于控制平面，保存路由协议学习到的网络可达信息；转发表由路由信息生成，属于数据平面，保存目的前缀对应的下一跳和输出接口。输入端口转发分组时主要查询转发表。
:::

::: info 例 2
路由器的输入端口、交换结构和输出端口分别承担什么任务？
:::

::: details 解析
输入端口完成物理层和链路层处理并查询转发表；交换结构把分组送到选定输出端口；输出端口负责排队、重新进行链路层封装并发送。
:::

::: info 例 3
路由器转发 IP 数据报时，为什么要重新封装链路层帧？
:::

::: details 解析
每一跳可能采用不同的数据链路层协议和链路地址。路由器去除入站帧后，需要按下一条链路的协议，使用新的源、目的链路层地址重新封装。
:::

::: info 例 4
二层交换机与路由器隔离广播域的能力有何不同？
:::

::: details 解析
普通二层交换机默认转发同一 VLAN 内的广播帧，不能隔离广播域；路由器不同接口属于不同广播域，不会直接转发链路层广播。
:::

## 答题技巧

- 控制平面形成路由信息，数据平面使用转发表处理分组。
- 路由器每转发一跳都会重新封装链路层帧，但通常保持最终源、目的 IP 地址不变。
