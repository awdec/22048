<h1><center>第二节 传输介质</center></h1>

::: info 例 1
为什么长距离高速骨干链路更常使用单模光纤而不是多模光纤？
:::

::: details 解析
单模光纤只有主要传播模式，模间色散小、衰减低，适合高速远距离传输；多模光纤成本较低，但更适合较短距离。
:::

::: info 例 2
屏蔽双绞线 STP 与非屏蔽双绞线 UTP 的主要区别是什么？
:::

::: details 解析
STP 增加了金属屏蔽层，抗电磁干扰能力更强，但成本和安装要求较高；UTP 成本低、布线方便，是普通局域网中更常见的介质。
:::

::: info 例 3
为什么光纤适合强电磁干扰环境？
:::

::: details 解析
光纤使用光信号传输数据，不依靠金属导体中的电信号，因此不受外界电磁场直接干扰，也不会产生电磁辐射泄漏。
:::

::: info 例 4
卫星通信覆盖范围广，但为什么交互应用仍可能感觉延迟明显？
:::

::: details 解析
信号需要传播到卫星再返回地面，路径很长。即使电磁波接近光速传播，较大的传播距离仍会造成显著传播时延，往返通信时更明显。
:::

::: info 例 5
无线介质与导向介质相比，主要优势和限制是什么？
:::

::: details 解析
无线介质部署灵活并支持移动通信，不需要铺设连续线缆；但信号更容易受到干扰、遮挡、窃听和共享信道竞争的影响。
:::

## 答题技巧

- 介质比较通常从带宽、衰减、距离、抗干扰、成本和部署方式六个方面作答。
- 单模与多模光纤的核心差异是传播模式和模间色散。
