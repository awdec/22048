<h1><center>第一节 通信基础</center></h1>

::: info 例 1
某系统码元率为 $2400$ Baud，每个码元有 $8$ 种状态，求数据率。
:::

::: details 解析
每个码元携带 $\log_2 8=3$ bit，因此：
$$
R_b=2400\times3=7200\text{ bit/s}.
$$
:::

::: info 例 2
对讲机双方都能发送但不能同时发送，属于哪种通信方式？
:::

::: details 解析
属于半双工通信。单工通信只能单向传输，全双工通信允许双方同时发送。
:::

::: info 例 3
无噪声低通信道带宽为 $3\text{ kHz}$，采用 $16$ 种码元状态，按奈奎斯特定理求最高数据率。
:::

::: details 解析
$$
R_b^{max}=2W\log_2M
=2\times3000\times4
=24\text{ kbit/s}.
$$
:::

::: info 例 4
信道带宽为 $1\text{ MHz}$，信噪比为 $30\text{ dB}$，按香农定理估算信道容量。
:::

::: details 解析
先把分贝换算成功率比：
$$
S/N=10^{30/10}=1000.
$$
因此：
$$
C=10^6\log_2(1001)\approx9.97\text{ Mbit/s}.
$$
:::

::: info 例 5
某无噪声低通信道带宽为 $4\text{ kHz}$，要求数据率达到 $24\text{ kbit/s}$，至少需要多少种码元状态？
:::

::: details 解析
由奈奎斯特公式：
$$
24000\le2\times4000\log_2M,
$$
可得 $\log_2M\ge3$，因此至少需要 $M=8$ 种状态。
:::

::: info 例 6
传输 $10\text{ Mbit/s}$ 数据采用曼彻斯特编码，所需码元速率是多少？
:::

::: details 解析
曼彻斯特编码的每个比特包含两个信号状态间隔，因此码元速率是数据率的两倍，即 $20$ Mbaud。
:::

::: info 例 7
4B/5B 编码传输 $80\text{ Mbit/s}$ 有效数据时，线路编码速率是多少？
:::

::: details 解析
编码效率为 $4/5$，因此：
$$
R=80\times\frac54=100\text{ Mbit/s}.
$$
:::

::: info 例 8
某模拟语音信号的最高频率为 $4\text{ kHz}$，采用 PCM 编码，每个样本量化为 $256$ 个等级。求最低采样率和相应的数据率。
:::

::: details 解析
根据采样定理，最低采样率为：
$$
f_s=2f_{max}=8\text{ kHz}.
$$
$256=2^8$，所以每个样本使用 $8$ bit，PCM 数据率为：
$$
R_b=8000\times8=64\text{ kbit/s}.
$$
:::

::: info 例 9
某系统采用 16-QAM，码元率为 $2400$ Baud，忽略编码开销，求数据率。
:::

::: details 解析
每个码元携带 $\log_2 16=4$ bit，因此：
$$
R_b=2400\times4=9600\text{ bit/s}.
$$
:::

::: info 例 10
比较电路交换与分组交换对突发数据的适应性。
:::

::: details 解析
电路交换需要先建立通路并预留资源，突发间歇期间资源可能闲置；分组交换采用统计复用，通常不为单个通信预留固定的独占资源，因此更适合突发数据。
:::

::: info 例 11
主机通过两台存储转发路由器发送一个长度为 $12000$ bit 的分组，三条链路速率均为 $2\text{ Mbit/s}$，忽略传播、排队和处理时延。求分组从开始发送到完整到达的时间。
:::

::: details 解析
每条链路的发送时延为：
$$
\frac{12000}{2\times10^6}=6\text{ ms}.
$$
分组经过三条链路，存储转发要求路由器完整接收后再发送，因此总时间为：
$$
3\times6=18\text{ ms}.
$$
:::

::: info 例 12
分组交换中的数据报服务与虚电路服务在连接建立、路由选择和故障适应方面有何区别？
:::

::: details 解析
数据报服务无须建立连接，每个分组独立选择路由；发生故障后，后续分组可以改走其他可用路径。虚电路服务需要先建立逻辑连接，同一虚电路中的分组通常沿既定路径传输；原路径发生故障时，虚电路通常失效并需要重新建立。虚电路建立逻辑连接不等于独占链路资源。
:::

## 答题技巧

- Baud 与 bit/s 转换时，先确定每个码元携带的比特数。
- 奈奎斯特公式使用频率带宽和码元状态数；香农公式使用频率带宽和无量纲信噪比。
- PCM 题按“最高频率 → 最低采样率 → 每样本位数 → 数据率”依次计算。
- 曼彻斯特编码属于基带编码，ASK、FSK、PSK 和 QAM 属于载波调制。
- 交换题要同时区分“是否建立连接”和“是否预留、独占资源”。
- 多跳存储转发题要明确分组数、链路数和每个分组的长度。
