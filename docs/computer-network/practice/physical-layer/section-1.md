<h1><center>第一节 通信基础</center></h1>

::: info 例 1
某系统码元率为 $2400$ Baud，每个码元有 $8$ 种状态，求数据率。
:::

::: details 解析
每码元携带 $\log_2 8=3$ bit：
$$
R_b=2400\times3=7200\text{ bit/s}.
$$
:::

::: info 例 2
传输 $10\text{ Mbps}$ 数据采用曼彻斯特编码，所需码元速率是多少？
:::

::: details 解析
曼彻斯特编码的每个比特包含两个信号状态间隔，因此码元速率是数据率的两倍，即 $20$ Mbaud。
:::

::: info 例 3
4B/5B 编码传输 $80\text{ Mbps}$ 有效数据时，线路编码速率是多少？
:::

::: details 解析
编码效率为 $4/5$：
$$
R=80\times\frac54=100\text{ Mbps}.
$$
:::

::: info 例 4
无噪声信道带宽为 $3\text{ kHz}$，采用 16 种码元状态，按奈奎斯特定理求最高数据率。
:::

::: details 解析
$$
R_b=2W\log_2M
=2\times3000\times4
=24\text{ kbps}.
$$
:::

::: info 例 5
信道带宽为 $1\text{ MHz}$，信噪比为 $30\text{ dB}$，按香农定理估算信道容量。
:::

::: details 解析
先把分贝换算成功率比：
$$
S/N=10^{30/10}=1000.
$$
因此：
$$
C=10^6\log_2(1001)\approx9.97\text{ Mbps}.
$$
:::

::: info 例 6
对讲机双方都能发送但不能同时发送，属于哪种通信方式？
:::

::: details 解析
属于半双工。单工只能单向传输，全双工允许双方同时发送。
:::

::: info 例 7
四个用户采用同步 TDM 共享一条 $8\text{ Mbps}$ 链路，每个用户固定获得相同时隙，单用户平均分配速率是多少？
:::

::: details 解析
忽略控制开销，每个用户固定得到：
$$
8/4=2\text{ Mbps}.
$$
即使某用户没有数据，其时隙也可能闲置。
:::

::: info 例 8
某无噪声信道带宽为 $4\text{ kHz}$，要求数据率达到 $24\text{ kbps}$，至少需要多少种码元状态？
:::

::: details 解析
由奈奎斯特公式：
$$
24000\le2\times4000\log_2M,
$$
可得 $\log_2M\ge3$，因此至少需要 $M=8$ 种状态。
:::

::: info 例 9
通信接口规定“连接器有 25 个引脚”“某引脚表示发送数据”“逻辑 1 对应某电压范围”“先建立连接再传输数据”，分别属于哪种接口特性？
:::

::: details 解析
引脚数量属于机械特性；信号线的作用属于功能特性；电压范围属于电气特性；操作的先后步骤属于规程特性。
:::

## 答题技巧

- Baud 与 bit/s 转换时先求每个码元携带的比特数。
- 奈奎斯特公式使用带宽和码元状态数，香农公式使用无量纲信噪比。
- 复用题要先判断用户由频率、时间、波长还是码片序列区分。
- 接口题按“外形—电平—含义—时序”依次对应机械、电气、功能和规程特性。
