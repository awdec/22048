<h1><center>第三节 物理层设备</center></h1>

::: info 例 1
中继器能否根据目的 MAC 地址决定是否转发数据？
:::

::: details 解析
不能。中继器工作在物理层，只对比特信号进行再生和转发，不识别帧结构或 MAC 地址。
:::

::: info 例 2
中继器连接两个网段后，是否划分了冲突域和广播域？
:::

::: details 解析
没有。中继器两侧仍属于同一个冲突域，中继器也不能隔离广播域。它只扩展物理传输距离，不改变数据链路层及以上的逻辑结构。
:::

::: info 例 3
为什么说数字中继器不是简单的信号放大器？
:::

::: details 解析
中继器对接收到的数字信号进行判决、整形并重新生成接近原始形状的信号；简单放大器会把信号与叠加的噪声一起放大。
:::

::: info 例 4
连接在同一集线器上的两个主机能否同时无冲突地发送数据？
:::

::: details 解析
不能。集线器的所有端口处于同一个冲突域并共享介质，两个主机同时发送会发生冲突。传统共享式以太网通过 CSMA/CD 处理这种竞争。
:::

::: info 例 5
八台主机连接到一个 $100\text{ Mbit/s}$ 集线器，每台主机是否都能独享 $100\text{ Mbit/s}$ 带宽？
:::

::: details 解析
不能。集线器的所有端口共享总带宽；任一时刻通常只有一个站点能够成功发送。不能把集线器的端口速率理解为每台主机同时独享的带宽。
:::

::: info 例 6
为什么二层交换机可以隔离冲突域，而集线器不能？
:::

::: details 解析
二层交换机能够识别帧，并根据 MAC 地址把帧转发到特定端口，每个端口可以独立收发；集线器只在端口间复制比特流，所有端口共同竞争同一介质。
:::

::: info 例 7
物理星形连接的网络一定采用星形逻辑拓扑吗？
:::

::: details 解析
不一定。使用集线器时，线缆在物理上以集线器为中心形成星形，但所有站点共享同一介质，逻辑上相当于总线形。使用交换机时，各端口链路彼此独立，逻辑结构才不同。
:::

## 答题技巧

- 中继器和集线器都只处理比特，不识别 MAC 地址。
- 两者都不能隔离冲突域或广播域，集线器只是多端口中继器。
- “共享带宽、半双工、一个冲突域”是集线器的高频判断点。
- 区分集线器与交换机时，重点看设备是否具有 MAC 地址表并能定向转发帧。
