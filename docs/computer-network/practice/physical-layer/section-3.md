<h1><center>第三节 物理层设备</center></h1>

::: info 例 1
集线器的两个端口能否同时无冲突地发送数据？
:::

::: details 解析
不能。传统共享式集线器的所有端口处于同一个冲突域并共享介质，两个端口同时发送会发生冲突。集线器不学习地址，也不定向转发。
:::

::: info 例 2
中继器能否根据目的 MAC 地址决定是否转发数据？
:::

::: details 解析
不能。中继器工作在物理层，只对比特信号进行再生和转发，不识别帧结构或 MAC 地址。
:::

::: info 例 3
中继器连接两个网段后，是否划分了冲突域和广播域？
:::

::: details 解析
没有。中继器扩大了同一个冲突域，也不能隔离广播域。连接后的网段在逻辑上仍属于同一个共享网络。
:::

::: info 例 4
为什么交换机可以隔离冲突域，而集线器不能？
:::

::: details 解析
交换机工作在数据链路层，可以识别帧并根据 MAC 地址在特定端口转发，每个端口可独立收发；集线器只在所有端口间复制比特流，所有端口共同竞争同一介质。
:::

::: info 例 5
物理层设备和数据链路层设备最关键的判断依据是什么？
:::

::: details 解析
判断设备是否识别帧结构或链路层地址。只处理比特信号的是物理层设备；能够检查 MAC 地址并按帧转发的是数据链路层设备。
:::

## 答题技巧

- 中继器和集线器均不识别地址，也不隔离冲突域和广播域。
- “能否按地址过滤流量”是区分物理层设备与链路层设备的关键。
