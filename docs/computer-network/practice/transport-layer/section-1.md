<h1><center>第一节 传输层提供的服务</center></h1>

::: info 例 1
传输层与网络层分别实现什么范围的通信？
:::

::: details 解析
网络层实现主机到主机的分组交付；传输层通过端口号在此基础上实现应用进程到应用进程的逻辑通信。
:::

::: info 例 2
同一 Web 服务器的 80 端口能否同时服务多个客户端？
:::

::: details 解析
可以。不同 TCP 连接由源 IP、源端口、目的 IP、目的端口四元组区分，服务器目的端口相同并不会造成连接混淆。
:::

::: info 例 3
传输层的复用和分用分别是什么？
:::

::: details 解析
复用是发送端把多个应用进程的数据交给传输层，并通过网络层统一发送；分用是接收端根据端口和连接标识，把数据交付给正确的应用进程或套接字。
:::

::: info 例 4
为什么只知道目的主机 IP 地址还不能把数据交付给具体应用？
:::

::: details 解析
IP 地址只能定位主机或网络接口，主机上可能同时运行多个应用。传输层还需要使用目的端口号选择正确的接收进程。
:::

::: info 例 5
TCP 与 UDP 的端口号是否属于各自独立的命名空间？
:::

::: details 解析
是。TCP 端口和 UDP 端口由不同传输协议分用，同一个数值可以分别被一个 TCP 服务和一个 UDP 服务使用。
:::
