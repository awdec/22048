<h1><center>第六节 局域网</center></h1>

::: info 例 1
以太网帧的数据字段不足 46 字节时为什么需要填充？
:::

::: details 解析
经典以太网要求从目的地址到 FCS 的帧长至少为 64 字节。填充可使帧达到最短长度，从而满足传统 CSMA/CD 的冲突检测要求。
:::

::: info 例 2
一个 IP 数据报经过路由器转发时，源和目的 MAC 地址是否保持不变？
:::

::: details 解析
不保持不变。路由器会去除入站链路层首部，并按下一跳重新封装新的帧，因此每一跳的源、目的 MAC 地址都会随链路改变。
:::

::: info 例 3
VLAN 的主要作用是什么？不同 VLAN 中的主机如何通信？
:::

::: details 解析
VLAN 用于在交换网络中逻辑划分广播域。不同 VLAN 之间的通信必须经过路由器等网络层设备转发。
:::

::: info 例 4
基础设施模式的 IEEE 802.11 无线局域网中，AP 的作用是什么？
:::

::: details 解析
AP 组织一个基本服务集 BSS，供无线站点关联，并在无线站点之间或无线站点与分配系统之间转发帧。
:::

::: info 例 5
交换机之间的 trunk 链路为什么需要 VLAN 标记？
:::

::: details 解析
trunk 链路可以同时承载多个 VLAN 的帧，802.1Q 标记用于指出帧属于哪个 VLAN，使接收交换机能够把帧放入正确的广播域。
:::
