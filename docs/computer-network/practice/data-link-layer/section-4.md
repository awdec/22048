<h1><center>第四节 流量控制与可靠传输机制</center></h1>

::: info 例 1
停止—等待协议中，数据帧发送时延为 $1\text{ ms}$，单程传播时延为 $9\text{ ms}$，忽略确认发送时延，求信道利用率。
:::

::: details 解析
$$
U=\frac1{1+2\times9}=\frac1{19}\approx5.26\%.
$$
:::

::: info 例 2
GBN 使用 3 位序号，发送窗口最大是多少？
:::

::: details 解析
$$
W_T\le2^3-1=7.
$$
GBN 的接收窗口为 1。
:::

::: info 例 3
SR 使用 4 位序号且发送、接收窗口相等，窗口最大是多少？
:::

::: details 解析
为了避免新旧帧序号混淆：
$$
W_T=W_R\le2^{4-1}=8.
$$
:::

::: info 例 4
GBN 中帧 3 丢失，而帧 4、5 已发送，超时后重传哪些帧？
:::

::: details 解析
接收方不缓存失序帧，发送方重传帧 3 及其后的所有未确认帧，即帧 3、4、5。
:::

::: info 例 5
发送窗口为 4，数据帧发送时延为 $2\text{ ms}$，单程传播时延为 $3\text{ ms}$，忽略 ACK 发送时延，求最大信道利用率。
:::

::: details 解析
$$
U=\min\left(1,\frac{WT_d}{T_d+2T_p}\right)
=\min\left(1,\frac{4\times2}{2+6}\right)=1.
$$
发送方连续发送 4 帧，恰好可以填满等待周期。
:::

## 答题技巧

- 先根据序号位数确定发送和接收窗口上限。
- 再判断接收方是否缓存失序帧，以及超时后的重传范围。
