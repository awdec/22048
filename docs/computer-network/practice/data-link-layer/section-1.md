<h1><center>第一节 数据链路层的功能</center></h1>

::: info 例 1
数据链路层实现的是端到端传输还是相邻节点之间的传输？
:::

::: details 解析
通常是相邻节点之间的一段链路传输。端到端的进程通信由传输层负责，跨网络的分组交付由网络层负责。
:::

::: info 例 2
物理链路与数据链路有什么区别？
:::

::: details 解析
物理链路是实际存在的传输介质；数据链路是在物理链路基础上加入链路层协议控制后形成的逻辑通信通道。
:::

::: info 例 3
流量控制和拥塞控制的作用范围有何不同？
:::

::: details 解析
流量控制协调发送方与接收方的速度，防止接收方缓冲区溢出；拥塞控制关注整个网络中的通信负载，防止网络内部资源过载。
:::

::: info 例 4
无确认的无连接服务为什么仍可能适用于误码率较低的链路？
:::

::: details 解析
这类链路发生错误的概率较低，链路层逐帧确认会增加控制开销。若端到端可靠性由上层协议提供，链路层可以直接发送并在出错时丢弃帧。
:::
