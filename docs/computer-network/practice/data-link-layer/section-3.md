<h1><center>第三节 差错控制</center></h1>

::: info 例 1
数据为 `1101`，生成多项式比特串为 `1011`。CRC 计算时应先补几个 `0`？余数是多少位？
:::

::: details 解析
生成串长度为 4，最高次数为 3，因此数据后补 3 个 `0`，最终余数也是 3 位。
:::

::: info 例 2
CRC 接收端计算出的余数为 0，能否证明传输绝对没有错误？
:::

::: details 解析
不能。余数为 0 只表示没有检测到错误，仍可能存在超出该生成多项式检错能力的错误模式。
:::

::: info 例 3
需要传输 $k=8$ 个信息位，使用可纠正一位错误的海明码，至少需要多少校验位？
:::

::: details 解析
要求：
$$
2^r\ge k+r+1.
$$
$r=3$ 时 $8<12$，不满足；$r=4$ 时 $16\ge13$，因此至少需要 4 位校验位。
:::

::: info 例 4
奇偶校验能够检测两个比特同时翻转吗？
:::

::: details 解析
不一定。普通奇偶校验只能保证检测奇数个位错误；两个比特同时翻转后，码字中 `1` 的奇偶性可能不变，因此无法检测。
:::
