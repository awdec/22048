<h1><center>第八节 数据链路层设备</center></h1>

::: info 例 1
交换机端口 1 收到源 MAC 为 A、目的 MAC 为 B 的帧，表中没有 A 和 B。交换机如何处理？
:::

::: details 解析
交换机先学习 `A → 端口1`，再因目的 B 未知，向除端口 1 以外的同 VLAN 端口泛洪。
:::

::: info 例 2
交换机表中目的 B 也位于入端口 1，收到发往 B 的帧后如何处理？
:::

::: details 解析
交换机过滤该帧，不向其他端口转发，因为源站和目的站位于同一个端口方向。
:::

::: info 例 3
一个 8 端口二层交换机的所有端口属于同一 VLAN，共有多少个冲突域和广播域？
:::

::: details 解析
每个端口形成独立冲突域，因此共有 8 个冲突域；所有端口属于同一 VLAN，因此只有 1 个广播域。
:::

::: info 例 4
网桥和二层交换机在基本工作原理上有什么关系？
:::

::: details 解析
二层交换机本质上是多端口高速网桥，二者都根据 MAC 地址学习、过滤和转发帧，并能够隔离冲突域。
:::

## 答题技巧

- 固定按“学习源地址—查询目的地址—转发、泛洪或过滤”分析交换机行为。
- 统计冲突域时看交换端口，统计广播域时看路由器接口或 VLAN 划分。
