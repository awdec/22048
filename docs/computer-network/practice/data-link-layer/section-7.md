<h1><center>第七节 广域网</center></h1>

::: info 例 1
PPP 是否使用确认和重传实现可靠传输？
:::

::: details 解析
基本 PPP 不对数据帧使用 ARQ。它用 FCS 检错并丢弃错误数据帧，不为这些数据帧提供序号、确认、重传和流量控制；LCP、NCP 配置过程有控制应答，不能据此说 PPP 保证数据可靠交付。
:::

::: info 例 2
PPP 中 LCP 和 NCP 分别负责什么？
:::

::: details 解析
LCP 负责建立、配置、测试和终止数据链路；NCP 为不同网络层协议配置参数，使 PPP 链路可以承载相应的网络层数据报。
:::

::: info 例 3
PPP 为什么不需要 CSMA/CD 或 CSMA/CA？
:::

::: details 解析
PPP 使用全双工点对点链路，不存在多个站点竞争同一共享介质的问题，因此不需要 CSMA/CD 或 CSMA/CA。
:::

::: info 例 4
PPP 异步链路中数据字段出现 `0x7E` 时如何实现透明传输？
:::

::: details 解析
发送方将 `0x7E` 转换为 `0x7D 0x5E`，即先插入转义字节，再把原字节与 `0x20` 异或；接收方删除转义字节并执行逆变换，恢复 `0x7E`。
:::

::: info 例 5
广域网与局域网在建设和关注重点上有何典型区别？
:::

::: details 解析
局域网通常由单一组织建设，重点是站点接入和介质共享；广域网覆盖范围大，常依赖运营商链路或交换网络，重点是远距离分组交付。
:::
