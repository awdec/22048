<h1><center>第七节 广域网</center></h1>

::: info 例 1
PPP 是否使用确认和重传实现可靠传输？
:::

::: details 解析
不使用。PPP 使用 FCS 检测帧差错，但差错帧直接丢弃，不提供序号、确认、重传和流量控制；需要可靠性时由上层协议负责。
:::

::: info 例 2
PPP 中 LCP 和 NCP 分别负责什么？
:::

::: details 解析
LCP 负责建立、配置、测试和终止数据链路；NCP 为不同网络层协议配置参数，使 PPP 链路可以承载相应的网络层数据报。
:::

::: info 例 3
PPP 为什么不需要 CSMA/CD 或 CSMA/CA？
:::

::: details 解析
PPP 用于点到点链路，链路上不存在多个站点竞争同一共享介质的问题，因此不需要冲突检测或冲突避免协议。
:::

::: info 例 4
PPP 异步链路中数据字段出现 `0x7E` 时如何实现透明传输？
:::

::: details 解析
发送方使用字节填充，在特殊字节前插入转义字节并进行规定变换；接收方执行相反操作，恢复原始数据，避免把数据误认为帧标志。
:::

::: info 例 5
广域网与局域网在建设和关注重点上有何典型区别？
:::

::: details 解析
局域网通常由单一组织建设，重点是站点接入和介质共享；广域网覆盖范围大，常依赖运营商链路或交换网络，重点是远距离分组交付。
:::
