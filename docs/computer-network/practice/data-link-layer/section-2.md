<h1><center>第二节 组帧</center></h1>

::: info 例 1
比特填充中，数据为 `01111110`，填充后的数据是什么？
:::

::: details 解析
发送方每出现连续 5 个 `1` 就插入一个 `0`：

```text
011111010
```

接收方发现连续 5 个 `1` 后的 `0` 时会将其删除。
:::

::: info 例 2
字节填充中，数据字段出现标志字节时应如何处理？
:::

::: details 解析
发送方在标志字节前插入转义字节；若数据本身出现转义字节，也要进行转义。接收方识别并删除转义字节，恢复原始数据。
:::

::: info 例 3
字符计数法的长度字段出错为什么可能影响后续帧？
:::

::: details 解析
接收方依靠长度字段定位帧结束位置。长度出错会使当前帧边界判断错误，接收方可能从错误位置继续解析，导致后续帧也失去同步。
:::

::: info 例 4
透明传输的含义是什么？
:::

::: details 解析
无论上层数据包含何种字符或比特组合，链路层都能把它作为普通数据传输，不会误判为帧边界或控制信息。填充机制正是实现透明传输的方法。
:::
