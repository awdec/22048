<h1><center>第五节 介质访问控制</center></h1>

::: info 例 1
共享以太网单程最大传播时延为 $25.6\,\mu\mathrm{s}$，速率为 $10\text{ Mbps}$，保证检测冲突的最短帧是多少比特？
:::

::: details 解析
帧发送时间至少等于往返传播时延：
$$
L_{min}=R\times2\tau
=10^7\times51.2\times10^{-6}=512\text{ bit}.
$$
即 64 字节。
:::

::: info 例 2
为什么无线局域网使用 CSMA/CA 而不是 CSMA/CD？
:::

::: details 解析
无线站点的发送信号远强于接收信号，难以边发送边检测碰撞，并且存在隐蔽站。因此使用监听、退避、确认和可选 RTS/CTS 来尽量避免冲突。
:::

::: info 例 3
全双工交换式以太网需要执行二进制指数退避吗？
:::

::: details 解析
不需要。每条链路都是点到点连接，收发方向相互独立，没有共享介质冲突，因此不使用 CSMA/CD 和退避算法。
:::

::: info 例 4
1-坚持 CSMA 在信道忙时如何处理？它有什么潜在问题？
:::

::: details 解析
站点持续监听，信道一空闲就立即发送。若多个站点都在等待，它们可能同时检测到空闲并一起发送，从而产生冲突。
:::

::: info 例 5
RTS/CTS 主要缓解无线局域网中的什么问题？
:::

::: details 解析
主要缓解隐蔽站问题。发送方和接收方交换 RTS/CTS 后，听到控制帧的邻近站点会在预约时间内保持静默。
:::

::: info 例 6
四个用户采用同步 TDM 共享一条 $8\text{ Mbps}$ 链路，每个用户固定获得相同时隙，单用户平均分配速率是多少？
:::

::: details 解析
忽略控制开销，每个用户固定得到：
$$
8/4=2\text{ Mbps}.
$$
即使某个用户没有数据，其时隙也会保留，可能造成链路资源闲置。
:::
