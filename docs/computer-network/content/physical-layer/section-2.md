<h1><center>第二节 传输介质</center></h1>

本节先比较双绞线、同轴电缆、光纤及常见无线传输介质，再归纳物理层接口的机械、电气、功能和规程特性。

## 1. 双绞线、同轴电缆、光纤与无线传输介质

传输介质是发送设备与接收设备之间的物理通路，可分为**导向传输介质**和**非导向传输介质**。

- 导向传输介质利用有形介质引导信号传播，包括双绞线、同轴电缆和光纤。
- 非导向传输介质通过自由空间传播电磁波，也称无线传输介质。

传输介质本身通常视为位于物理层之下，但其特性直接影响带宽、衰减、传输距离、抗干扰能力和误码率。

### 1.1 双绞线

双绞线由两根相互绝缘的铜导线按一定规则绞合而成。绞合可以使两根导线受到的外界电磁干扰趋于抵消，并减少线对之间的串扰。

- **非屏蔽双绞线 UTP**：没有额外金属屏蔽层，成本较低、重量轻、布线方便，广泛用于以太网和电话线路。
- **屏蔽双绞线 STP**：在线对或线缆外增加金属屏蔽层，抗电磁干扰能力更强，但成本、接地和安装要求更高。

双绞线价格低、连接方便，适合局域网接入；与同轴电缆和光纤相比，其传输距离、带宽和抗干扰能力通常较有限。

### 1.2 同轴电缆

同轴电缆由中心导体、绝缘层、金属屏蔽层和外部保护层组成，各层共享同一中心轴线。金属屏蔽层能够减少电磁干扰和信号向外辐射。

同轴电缆的屏蔽能力和可用频带通常优于普通双绞线，但线缆较粗、安装和维护不如双绞线方便。它常用于有线电视、宽带接入和早期总线形以太网。

### 1.3 光纤

光纤由纤芯和折射率较低的包层组成，利用光在纤芯与包层界面处的全反射传播信号。光纤通常还具有涂覆层和外部护套，用于保护纤芯。

按照传播模式可分为：

- **多模光纤**：允许多种传播模式，模间色散较大，适合较短距离传输。
- **单模光纤**：主要传输单一模式，模间色散小，适合高速、远距离传输。

光纤具有以下特点：

- 频带宽、通信容量大。
- 衰减小，适合长距离传输。
- 不受常规电磁干扰，向外辐射和信号泄漏较小。
- 重量轻、直径小，保密性较好。
- 光纤熔接、检测和光电转换设备要求较高。

常见的全双工光纤链路使用两根光纤分别承载两个方向；也可以利用波分复用，在同一根光纤中使用不同波长实现双向传输。光纤本身并非只能单向传播。

### 1.4 无线传输介质

无线传输使用自由空间传播电磁波，部署灵活并支持移动通信，但更容易受到干扰、遮挡、窃听和共享信道竞争的影响。

#### 1.4.1 无线电波

无线电波的传播特性随频率和环境而变化。相对较低频率的无线电波通常具有较强的绕射或穿透能力，可以采用全向传播；频率升高后，方向性和视距传播特征通常更明显。无线电波常用于广播、移动通信和无线局域网，传播质量可能受到其他无线设备、多径效应和环境变化影响。

#### 1.4.2 微波

微波频率较高，通常沿直线传播，适合定向通信：

- **地面微波通信**：使用相隔一定距离的中继站延长传输距离，天线之间通常需要保持视距。
- **卫星通信**：使用通信卫星作为微波中继，覆盖范围广；传播距离较长，因此传播时延可能较大。

#### 1.4.3 红外线与可见光

红外线和可见光适合近距离、视距通信，方向性较强，通常不能穿透墙壁，因此不同房间之间干扰较小，但容易受到遮挡和环境光影响。

### 1.5 传输介质对比

| 介质 | 主要优点 | 主要局限 | 典型场景 |
| --- | --- | --- | --- |
| 双绞线 | 成本低、连接和布线方便 | 距离、带宽和抗干扰能力有限 | 电话线路、局域网接入 |
| 同轴电缆 | 屏蔽较好、可用频带较宽 | 线缆较粗、布线不便 | 有线电视、宽带接入 |
| 光纤 | 带宽大、衰减小、抗电磁干扰 | 熔接、检测和光电转换要求较高 | 高速骨干、远距离链路 |
| 无线介质 | 部署灵活、支持移动 | 易受干扰和窃听，信道需要共享 | 无线局域网、移动与卫星通信 |

::: tip 选择思路
比较传输介质时，通常从带宽、衰减、传输距离、抗干扰能力、成本、部署难度和移动性等方面分析，不能只凭“有线”或“无线”判断性能高低。
:::

## 2. 物理层接口的特性

物理层接口位于通信设备与传输介质或相邻通信设备的连接边界。为了使不同设备能够正确连接并传输比特，接口标准需要规定机械、电气、功能和规程四类特性。

| 接口特性 | 规定内容 | 典型示例 |
| --- | --- | --- |
| 机械特性 | 连接器的形状、尺寸、引脚数量、排列和固定方式 | 插头外形、接口尺寸、引脚布局 |
| 电气特性 | 信号电压范围、阻抗、传输速率和最大传输距离等 | 逻辑 1 的电压范围、允许的数据率 |
| 功能特性 | 各引脚、信号线或电路所代表的功能 | 某引脚用于发送数据或提供时钟 |
| 规程特性 | 使用各信号线完成操作时的时序和步骤 | 连接建立、数据传输和连接释放的顺序 |

### 2.1 四类特性的辨析

- 题目询问接口“长什么样、怎样插接”，通常属于机械特性。
- 题目涉及“电平、阻抗、速率、距离”，通常属于电气特性。
- 题目询问“某根线或某个引脚做什么”，属于功能特性。
- 题目询问“先做什么、后做什么、何时发送”，属于规程特性。

::: warning 易错点
功能特性说明信号线“表示什么”，规程特性说明这些信号线“按什么顺序使用”；两者不能混淆。传输介质的材料和结构也不等于物理层接口的机械特性。
:::
