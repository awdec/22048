<h1><center>第三节 物理层设备</center></h1>

## 1. 中继器

中继器工作在物理层，用于连接两个网段。它接收衰减或失真的数字信号，对信号进行再生、整形和放大后转发，以延长网络的物理传输距离。

中继器只处理比特和信号，不识别帧、MAC 地址或 IP 地址，也不进行差错检测和流量过滤。

## 2. 集线器

集线器是多端口中继器。某端口收到比特流后，集线器将信号再生并转发到除接收端口以外的其他端口。

集线器具有以下特点：

- 所有端口共享总带宽。
- 所有端口位于同一个冲突域。
- 同一时刻通常只能有一个站点成功发送。
- 不学习 MAC 地址，也不能根据地址定向转发。
- 不能隔离广播域。

## 3. 冲突域与广播域

中继器和集线器扩大了同一个冲突域，不能隔离冲突；它们也不检查链路层广播帧，因此不能划分广播域。

二层交换机的每个端口可以形成独立冲突域，但默认仍属于同一广播域；路由器能够隔离广播域。这一区别是判断网络设备层次的重要依据。

## 4. 设备对比

| 设备 | 主要层次 | 转发依据 | 冲突域 | 广播域 |
| --- | --- | --- | --- | --- |
| 中继器 | 物理层 | 比特信号 | 不隔离 | 不隔离 |
| 集线器 | 物理层 | 比特信号 | 不隔离 | 不隔离 |
| 二层交换机 | 数据链路层 | MAC 地址 | 每端口隔离 | 默认不隔离 |
| 路由器 | 网络层 | IP 地址 | 隔离 | 隔离 |

::: warning 易错点
中继器和集线器只能扩展同类物理网络的覆盖范围，不能根据地址过滤流量，也不能连接采用不同链路层协议的网络。
:::
