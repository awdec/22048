<h1><center>第三节 物理层设备</center></h1>

物理层设备只处理信号和比特，不理解帧、MAC 地址或 IP 地址。408 重点掌握中继器和集线器的工作原理，以及它们对冲突域、广播域和带宽的影响。

## 1. 中继器

### 1.1 中继器的作用

中继器工作在物理层，用于连接两个物理网段。信号在传输过程中会发生衰减和失真，中继器接收信号后进行**再生、整形和转发**，使信号恢复到接近原来的数字波形，从而延长网络的物理传输距离。

中继器对数字信号进行判决和重新生成，不是简单地把输入信号连同噪声一起线性放大。

### 1.2 中继器的工作特点

- 只处理比特流和物理信号，不识别帧边界。
- 不检查 MAC 地址或 IP 地址，不能根据地址选择是否转发。
- 不进行差错检测、流量过滤、路径选择或存储转发。
- 只能连接数据率相同且物理层信号、编码和定时兼容的网段；有些设备可以连接不同传输介质，但不能借此连接不同速率的以太网或完成协议转换。
- 中继器不能识别错误数据；由噪声造成的错误比特以及冲突影响也可能被继续转发到另一网段。

### 1.3 中继器对网络范围的影响

中继器只延长物理传输距离，不改变网络在数据链路层及以上各层的逻辑结构：

- 中继器两侧仍处于同一个冲突域。
- 中继器不能隔离广播域。
- 中继器产生的处理和传播时间会计入网络时延，因此不能无限串联；共享式以太网还必须满足冲突检测所需的往返时延限制。

::: warning 易错点
中继器扩大的是网络的物理覆盖范围，不是网络层的互连范围。它既不是网桥，也不是路由器，不能依据地址过滤流量或连接采用不同链路层协议的网络。
:::

## 2. 集线器

### 2.1 集线器的本质与工作过程

集线器（Hub）本质上是**多端口中继器**，同样工作在物理层。某个端口收到比特流后，集线器对信号进行再生，并转发到除接收端口以外的所有其他端口。

集线器不判断哪个端口连接着目的主机，也不学习 MAC 地址。目的主机是否接收数据，由各主机的网卡在数据链路层检查帧地址后决定。

### 2.2 集线器的主要特点

- **共享带宽**：所有端口共同使用集线器的总带宽，不是每个端口独享一份带宽。
- **半双工通信**：传统共享式以太网通过集线器连接时，同一时刻通常只能有一个站点成功发送。
- **一个冲突域**：所有端口共同竞争传输介质，两个站点同时发送可能产生冲突。
- **一个广播域**：集线器不能隔离广播域。
- **物理星形、逻辑总线形**：线缆以集线器为中心连接，但各站点在逻辑上共享同一传输介质。
- **不具备交换功能**：集线器没有 MAC 地址表，不能定向转发、过滤帧或实现全双工交换。

使用集线器的共享式以太网需要采用 CSMA/CD 处理介质竞争。交换式全双工以太网的端口彼此独立，不使用集线器，也不需要 CSMA/CD。

### 2.3 集线器与二层交换机（关联知识）

| 对比项 | 集线器 | 二层交换机 |
| --- | --- | --- |
| 工作层次 | 物理层 | 数据链路层 |
| 处理单位 | 比特 | 帧 |
| 转发方式 | 向其他所有端口复制信号 | 根据 MAC 地址选择端口转发 |
| MAC 地址表 | 无 | 有，通过自学习建立 |
| 端口带宽 | 所有端口共享 | 每个端口通常独享 |
| 冲突域 | 所有端口属于同一个 | 每个端口形成独立冲突域 |
| 双工方式 | 通常半双工 | 通常支持全双工 |
| 广播域 | 默认一个 | 默认一个，配置 VLAN 后可划分 |

### 2.4 中继器与集线器小结

| 设备 | 端口形式 | 核心作用 | 是否识别地址 | 是否隔离冲突域 | 是否隔离广播域 |
| --- | --- | --- | --- | --- | --- |
| 中继器 | 通常连接两个网段 | 再生并转发信号 | 否 | 否 | 否 |
| 集线器 | 多端口 | 向其他端口再生并复制信号 | 否 | 否 | 否 |

::: tip 判断方法
只要设备只处理比特信号、没有 MAC 地址表且不能定向转发，就应首先判断它属于物理层设备。
:::
