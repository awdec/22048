<h1><center>第一节 传输层提供的服务</center></h1>

## 1. 传输层的功能

传输层为不同主机上的应用进程提供端到端的逻辑通信。网络层实现主机到主机的交付，传输层通过端口号进一步把数据交付给具体应用进程。

主要功能包括：

- 进程到进程的逻辑通信。
- 复用与分用。
- 对报文进行差错检测。
- 根据协议提供可靠传输、流量控制和拥塞控制。

传输层只存在于通信端系统中，路由器通常只负责到网络层的分组转发。

## 2. 复用与分用

- **复用**：发送端多个应用进程可以同时使用传输层协议，再由网络层统一传输。
- **分用**：接收端传输层根据目的端口等信息，把收到的数据交付给正确的应用进程或套接字。

UDP 分用主要依据目的 IP 和目的端口；TCP 连接通常由源 IP、源端口、目的 IP、目的端口四元组区分。

## 3. 端口号

TCP 和 UDP 端口号均为 16 位，范围为 $0$～$65535$：

- **熟知端口**：$0$～$1023$。
- **注册端口**：$1024$～$49151$。
- **动态或私有端口**：$49152$～$65535$。

常见端口包括 HTTP 80、HTTPS 443、DNS 53、SMTP 25、POP3 110 和 FTP 控制连接 21。

端口号只在本主机中标识应用进程，不是全网唯一的进程编号。

## 4. 套接字

通信端点通常用“IP 地址 + 端口号”表示，这一组合称为套接字地址。一个 TCP 连接由四元组唯一标识：

$$
(\text{源 IP, 源端口, 目的 IP, 目的端口}).
$$

因此，同一服务器可以在固定端口上同时服务多个客户端连接，只要四元组不同即可区分。

## 5. 无连接与面向连接服务

- **无连接服务**：发送数据前不建立传输连接，各报文独立处理，开销小，但协议本身通常不保证可靠性。
- **面向连接服务**：通信前建立连接，维护连接状态，并可提供可靠、按序的字节流传输。

UDP 提供无连接数据报服务；TCP 提供面向连接的可靠字节流服务。

## 6. 传输层与网络层的关系

网络层提供的服务影响传输协议的实现，但传输层可以在不可靠网络层之上，通过序号、确认、重传和窗口机制建立可靠的端到端服务。

传输层的可靠性是端到端实现的，中间路由器不需要维护每条 TCP 连接的可靠传输状态。

::: tip 区分方法
IP 地址把分组送到主机，端口号把数据交给主机中的进程；“IP 地址 + 端口号”共同定位一个通信端点。
:::
