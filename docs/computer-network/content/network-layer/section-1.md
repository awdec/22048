<h1><center>第一节 网络层的功能</center></h1>

## 1. 网络层的任务

网络层负责把分组从源主机跨越多个网络交付到目的主机，主要功能包括：

- **异构网络互联**：使用统一的网络层协议连接不同类型的链路和网络。
- **路由选择**：根据网络拓扑和代价计算端到端路径。
- **分组转发**：查询转发表，把到达的分组送往正确的输出接口。
- **拥塞控制**：调节进入网络的负载，避免链路和路由器过载。
- **差错报告与网络探测**：报告部分转发异常并支持诊断。

互联网网络层提供无连接、尽最大努力交付的数据报服务，不保证可靠、按序、无重复或固定时延。

## 2. 路由选择与分组转发

- **路由选择**属于控制平面，计算到各目的网络的可达路径并生成路由信息。
- **分组转发**属于数据平面，依据转发表逐个处理到达的分组。

路由选择关注“形成什么路径”，分组转发关注“当前分组从哪个接口送出”。

## 3. 数据报服务与虚电路服务

| 项目 | 数据报 | 虚电路 |
| --- | --- | --- |
| 建立连接 | 不需要 | 需要 |
| 路由选择 | 每个分组可独立选择 | 建立时确定路径 |
| 分组首部 | 携带完整目的地址 | 携带较短的虚电路号 |
| 顺序 | 可能失序 | 通常按序到达 |
| 故障适应 | 可重新选择路径 | 通常需要重建虚电路 |

互联网 IP 提供数据报服务；虚电路网络则需要维护连接状态。

## 4. 网络互联

互联网络允许采用不同物理介质和链路层协议的网络通过路由器连接。IP 层向上提供统一的数据报格式，路由器在每一跳去除入站链路层帧，再按下一条链路重新封装。

网络互联不要求底层网络具有相同的帧格式、速率或介质访问方式。

## 5. 网络层拥塞控制

当进入网络的流量超过链路、路由器处理能力和缓冲容量时，会出现排队时延增加、缓存溢出和分组丢失。

- **开环控制**：在拥塞发生前通过接纳控制、流量整形、资源预留等策略预防。
- **闭环控制**：根据丢包、时延或显式通知等反馈降低发送负载。

拥塞控制面向整个网络；流量控制主要用于使发送速度适应接收端处理能力。

## 6. SDN 基本概念

软件定义网络 SDN 将控制平面与数据平面分离：逻辑集中的控制器掌握网络状态、计算路径并生成规则，转发设备按照下发的规则高速处理分组。

控制器通过南向接口管理转发设备，并通过北向接口向网络应用提供编程能力。相比每台传统路由器独立运行全部控制协议，SDN 更便于集中配置和统一实施策略。

::: tip 主线
网络层先通过路由算法生成可达路径，再由转发设备按目的地址逐跳转发；IP 提供统一的无连接数据报服务。
:::
