<h1><center>第六节 移动 IP</center></h1>

## 1. 移动 IP 的目标

移动 IP 允许移动节点改变接入网络时仍保留固定的归属地址，使上层连接不必因当前位置变化而改用新的永久地址。

普通 IP 地址同时具有身份和位置含义；移动 IP 使用归属地址标识节点身份，使用转交地址反映节点当前所在网络。

## 2. 基本术语

- **移动节点**：可以改变接入网络但希望保持归属地址的主机。
- **归属网络**：移动节点永久地址所属的网络。
- **归属代理**：位于归属网络，负责截获并转发发往移动节点的分组。
- **外地网络**：移动节点当前访问的非归属网络。
- **转交地址**：反映移动节点当前位置的临时地址。
- **通信对端**：与移动节点通信的其他主机。

## 3. 注册过程

移动节点进入外地网络后获得转交地址，并向归属代理注册当前位置。归属代理建立“归属地址 → 转交地址”的绑定，注册信息需要进行身份验证并具有有效期。

移动节点返回归属网络后注销转交地址，恢复普通直接交付。

## 4. 数据转发过程

1. 通信对端仍把分组发送到移动节点的归属地址。
2. 归属代理在归属网络截获该分组。
3. 归属代理把原分组封装到新的 IP 数据报中，通过隧道发送到转交地址。
4. 外地代理或移动节点解封装并接收原分组。

移动节点发往通信对端的数据可以直接发送，也可以通过反向隧道经过归属代理。

## 5. 三角路由

通信对端发往移动节点的分组先到归属代理，再绕行到当前位置，而返回分组可能直接到达通信对端，路径形成三角形，称为三角路由。

三角路由保持了通信透明性，但可能增加时延和网络开销。路由优化可以让通信对端获知绑定并更直接地发送，但需要额外安全和状态管理。

::: warning 易错点
移动节点离开归属网络后，通信对端仍可使用其归属地址；转交地址用于定位当前位置，通常由归属代理通过隧道转发分组。
:::
