<h1><center>第七节 网络层设备</center></h1>

## 1. 路由器的功能

路由器连接不同网络，工作在网络层。它根据目的 IP 地址选择下一跳和输出接口，并在不同链路之间重新封装分组。

路由器能够隔离广播域和冲突域，连接采用不同数据链路层协议的网络，并通过路由协议学习网络可达信息。

## 2. 路由器的组成

路由器主要由输入端口、交换结构、输出端口和路由处理器组成：

- **输入端口**：完成物理层、数据链路层处理，并查询转发表。
- **交换结构**：把分组从输入端口送到选定的输出端口。
- **输出端口**：完成排队、链路层封装和发送。
- **路由处理器**：运行路由协议，维护路由信息并生成转发规则。

交换结构可以基于内存、总线或互联网络实现。输入或输出速率超过处理能力时，分组需要排队并可能因缓冲区溢出而丢失。

## 3. 路由表与转发表

- **路由表**属于控制平面，保存路由协议获得的网络可达信息、度量和下一跳等内容。
- **转发表**属于数据平面，保存目的前缀对应的输出接口和下一跳，用于高速逐分组查找。

路由表用于生成转发表，但二者的结构、内容和使用位置并不完全相同。

## 4. 路由器转发过程

1. 输入端口接收链路层帧并检查其目的链路地址。
2. 去除链路层首部和尾部，取得 IP 数据报。
3. 检查首部并减少 TTL 或跳数限制。
4. 按目的 IP 地址进行最长前缀匹配。
5. 将数据报送往选定输出端口。
6. 使用下一条链路的协议重新封装并发送。

::: warning 易错点
路由器依据 IP 地址选择下一跳，但实际通过一条链路发送时仍需要相应的链路层地址和帧封装。
:::
