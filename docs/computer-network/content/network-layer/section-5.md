<h1><center>第五节 IP 多播</center></h1>

## 1. IP 多播的概念

IP 多播允许发送方把同一份数据发送给一组接收者。发送方只发送一次，网络在适当的分支复制分组，比为每个接收者分别单播更节省带宽。

多播组成员可以动态加入或离开，发送方不必属于该组，也不必知道所有接收者的位置。

## 2. IPv4 多播地址

IPv4 多播地址范围为 `224.0.0.0/4`。多播地址标识一组接收者，不能作为普通单播源地址使用。

## 3. 单播、广播与多播

| 方式 | 接收者 | 网络中的复制方式 |
| --- | --- | --- |
| 单播 | 一个指定接口 | 为每个接收者分别发送 |
| 广播 | 广播域内全部接口 | 向广播范围内所有节点交付 |
| 多播 | 加入特定组的接口 | 在分发树分支处按需复制 |

::: warning 易错点
多播地址表示一组接收接口，通常作为目的地址使用；发送方不必属于该多播组。
:::
