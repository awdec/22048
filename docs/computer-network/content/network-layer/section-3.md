<h1><center>第三节 IPv6</center></h1>

## 1. IPv6 的特点

IPv6 使用 128 位地址，解决 IPv4 地址空间不足问题，并简化基本首部处理。主要特点包括：

- 地址空间更大。
- 基本首部固定为 40 字节。
- 基本首部不含首部校验和。
- 可选功能由扩展首部承载。
- 路由器不对普通 IPv6 分组进行中途分片。
- 不使用广播，改用组播和任播。

## 2. IPv6 地址表示

IPv6 地址写成 8 组十六进制数，每组 16 位。每组前导零可以省略；一段或多段连续全零可以压缩为 `::`，但一个地址中只能使用一次 `::`，否则无法确定每处省略的零段数量。

## 3. IPv6 地址类型

- **单播地址**：标识单个接口。
- **组播地址**：标识一组接口，分组交付给组内成员。
- **任播地址**：分配给多个接口，分组通常交付给路由意义上最近的一个。

IPv6 没有广播地址。链路本地地址用于同一链路范围内的通信。

::: warning 易错点
IPv6 基本首部没有首部校验和；中间路由器不对普通 IPv6 分组分片，必要的分片由源主机完成。
:::
