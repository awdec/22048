<h1><center>第八节 数据链路层设备</center></h1>

## 1. 网桥

网桥连接多个局域网网段，工作在数据链路层。它根据 MAC 地址选择转发或过滤帧，可以隔离冲突域，但默认不能隔离广播域。

网桥可以通过自学习建立转发表，并据此决定转发、过滤或泛洪收到的帧。

## 2. 以太网交换机

交换机本质上是多端口网桥。每个端口形成独立冲突域，可以并行转发多个帧。

## 3. 交换机自学习与转发

交换机收到帧时按以下顺序处理：

1. 根据源 MAC 地址学习“源地址 → 入端口”。
2. 查询目的 MAC 地址。
3. 目的地址已知且对应其他端口：定向转发。
4. 目的地址未知：向除入端口外的同 VLAN 端口泛洪。
5. 目的端口与入端口相同：过滤。
6. 广播帧：向除入端口外的同 VLAN 端口泛洪。

动态 MAC 表项会老化，以适应主机移动和拓扑变化。

## 4. 冲突域与广播域

- 集线器所有端口属于同一个冲突域和广播域。
- 网桥或交换机的每个端口形成独立冲突域。
- 普通二层交换机默认不隔离广播域，VLAN 可以划分广播域。
- 路由器的不同接口属于不同广播域。

## 5. 设备对比

| 设备 | 工作层次 | 转发依据 | 冲突域 | 广播域 |
| --- | --- | --- | --- | --- |
| 集线器 | 物理层 | 比特信号 | 不隔离 | 不隔离 |
| 网桥 | 数据链路层 | MAC 地址 | 隔离 | 默认不隔离 |
| 二层交换机 | 数据链路层 | MAC 地址 | 每端口隔离 | 默认不隔离 |
| 路由器 | 网络层 | IP 地址 | 隔离 | 每接口隔离 |

::: tip 做题顺序
交换机转发题固定按“学习源地址—查询目的地址—转发、泛洪或过滤”的顺序分析，再结合 VLAN 判断广播范围。
:::
