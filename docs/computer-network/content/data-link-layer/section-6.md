<h1><center>第六节 局域网</center></h1>

## 1. 局域网概述

局域网覆盖范围较小、传输速率较高、误码率较低，通常由一个组织建设和管理。局域网可以采用星形、总线形、环形等拓扑，以太网是最常见的有线局域网技术。

IEEE 802 把数据链路层划分为逻辑链路控制 LLC 子层和介质访问控制 MAC 子层。MAC 子层负责帧封装、物理地址和共享介质访问。

## 2. MAC 地址

以太网 MAC 地址通常为 48 位，用于标识局域网接口。全 `1` 地址为广播地址：

```text
FF-FF-FF-FF-FF-FF
```

MAC 地址用于一段链路内逐帧交付。IP 数据报跨越路由器时，链路层帧会在每一跳重新封装，源、目的 MAC 地址也会随下一跳改变。

## 3. 以太网帧

以太网帧主要包含：

- 目的 MAC 地址。
- 源 MAC 地址。
- 类型/长度字段。
- 数据字段。
- 帧校验序列 FCS。

经典以太网帧从目的地址到 FCS 的长度通常为 64～1518 字节，不包括前导码和帧开始定界符。数据不足 46 字节时需要填充，以满足最短帧长度。

## 4. 传统以太网与交换式以太网

传统共享以太网使用集线器连接站点，所有站点处于同一冲突域并使用 CSMA/CD。交换式以太网使用交换机为每个端口提供独立冲突域，全双工链路可以同时收发且不会产生冲突。

以太网在不同速率下保持相似的帧格式，便于网络技术演进和互操作。

## 5. VLAN

虚拟局域网 VLAN 在交换网络中逻辑划分广播域。不同 VLAN 即使连接在同一台交换机上，也需要三层设备转发才能通信。

IEEE 802.1Q 在以太网帧中加入 VLAN 标记。连接终端的 access 链路通常只承载一个 VLAN，交换机之间的 trunk 链路可以承载多个 VLAN 的帧。

## 6. IEEE 802.11 无线局域网

无线局域网由站点、基本服务集 BSS 和分配系统组成。在基础设施模式下，一个接入点 AP 及其覆盖范围内关联的站点构成一个 BSS。

站点通常先与 AP 关联，再通过 AP 与同一 BSS 中的其他站点或外部网络通信。802.11 使用 CSMA/CA、帧间间隔、随机退避、确认和可选 RTS/CTS。

无线帧可能同时包含接收方、发送方、源站和目的站相关地址，以适应经 AP 和分配系统转发的场景。

::: warning 易错点
普通二层交换机可以隔离冲突域，但默认不能隔离同一 VLAN 内的广播域；VLAN 的主要作用是逻辑划分广播域。
:::
