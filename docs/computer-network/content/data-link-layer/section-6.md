<h1><center>第六节 局域网</center></h1>

局域网把有限地理范围内的计算机和网络设备连接起来。IEEE 802 系列标准规定了多种局域网的体系结构、介质访问控制和帧格式，其中 IEEE 802.3 以太网与 IEEE 802.11 无线局域网是 408 的重点。

## 1. 局域网的基本概念和体系结构

### 1.1 局域网的基本特点

局域网 LAN 通常具有以下特点：

- 覆盖范围较小，常见于房间、楼宇或园区。
- 数据传输速率较高，传播时延和误码率通常较低。
- 通常由一个单位拥有、建设和管理。
- 可以采用双绞线、光纤或无线信道等传输介质。
- 传统局域网可能共享传输介质，现代交换式局域网通常使用点对点链路连接交换机。

局域网常见的拓扑结构包括总线形、星形和环形。物理拓扑描述设备和线缆的实际连接方式，逻辑拓扑描述帧在网络中的传输关系，两者不一定相同。例如，使用集线器的传统双绞线以太网在物理上是星形，在逻辑上仍是共享总线形。

### 1.2 IEEE 802 局域网体系结构

局域网主要涉及 OSI 参考模型的物理层和数据链路层。IEEE 802 将数据链路层进一步划分为两个子层：

| 子层 | 位置 | 主要功能 |
| --- | --- | --- |
| 逻辑链路控制 LLC | 数据链路层上部 | 向网络层提供统一接口，标识和复用上层协议，并可提供逻辑链路控制功能 |
| 介质访问控制 MAC | 数据链路层下部 | 规定 MAC 帧格式、物理地址、介质访问规则和差错检测等 |

LLC 子层使不同的 IEEE 802 局域网能够向网络层提供相对统一的服务；MAC 子层与具体局域网技术关系更紧密，例如以太网使用 IEEE 802.3 MAC，无线局域网使用 IEEE 802.11 MAC。

### 1.3 MAC 地址

以太网和 IEEE 802.11 通常使用 48 位 MAC 地址标识局域网接口。MAC 地址长度为 6 B，常写成 6 组十六进制数，例如：

```text
00-1A-2B-3C-4D-5E
```

MAC 地址是平面地址，没有类似 IP 地址的层次结构。它标识的是网络接口，而不是抽象意义上的整台设备；一台具有多个网络接口的设备可以拥有多个 MAC 地址。

按接收范围，目的 MAC 地址可以分为：

- **单播地址**：标识一个局域网接口。
- **组播地址**：标识一组局域网接口。
- **广播地址**：48 位全部为 `1`，表示同一广播域内的所有接口。

```text
FF-FF-FF-FF-FF-FF
```

MAC 地址用于当前链路内的帧交付。IP 数据报经过路由器转发到下一段链路时，需要重新封装成新的链路层帧，帧中的源、目的 MAC 地址通常随下一跳改变。

::: warning 易错点
MAC 地址标识接口，不标识整个设备；广播 MAC 地址只能作为目的地址。交换机依据 MAC 地址转发帧，路由器依据 IP 地址转发网络层数据报。
:::

## 2. 以太网与 IEEE 802.3

以太网是应用最广泛的有线局域网技术。IEEE 802.3 规定了以太网的 MAC 子层和多种物理层实现。不同速率、不同介质的以太网保持兼容的基本 MAC 帧格式，使交换和互连较为方便。

### 2.1 以太网提供的服务

以太网向网络层提供**无连接、无确认**的服务：发送帧之前不建立数据链路连接，接收方收到正确帧后通常不返回链路层确认。

接收方使用 FCS 检测帧是否出错，检测到错误的帧通常直接丢弃。经典以太网本身不在数据链路层重传错误帧，需要可靠交付时由上层协议或其他机制负责。

### 2.2 以太网 MAC 帧格式

典型以太网帧的字段如下：

| 字段 | 长度 | 作用 |
| --- | ---: | --- |
| 前导码 | 7 B | 使接收方时钟与发送方同步，属于物理层开销 |
| 帧开始定界符 SFD | 1 B | 表示 MAC 帧即将开始，属于物理层开销 |
| 目的 MAC 地址 | 6 B | 标识帧的接收接口 |
| 源 MAC 地址 | 6 B | 标识帧的发送接口 |
| 类型/长度 | 2 B | 标识上层协议或表示数据字段长度 |
| 数据和填充 | 46～1500 B | 承载上层数据；不足 46 B 时进行填充 |
| 帧校验序列 FCS | 4 B | 使用 CRC-32 检测帧中的位错 |

前导码和 SFD 由物理层添加，不计入以太网 MAC 帧长度。从目的地址到 FCS，普通以太网 MAC 帧的长度为：

$$
64\ \text{B}\le L_{frame}\le1518\ \text{B}.
$$

其中数据字段的最大长度 1500 B 通常称为以太网 MTU。数据不足 46 B 时必须填充，以满足 64 B 的最小帧长；填充内容不属于上层原始数据。

Ethernet II 使用该 2 B 字段表示上层协议类型；原始 IEEE 802.3 帧使用它表示数据长度。字段值不大于 1500 时解释为长度，不小于 1536 时解释为类型，1501～1535 为保留范围。

::: warning 易错点
以太网的 64～1518 B 指从目的 MAC 地址到 FCS 的 MAC 帧长度，不包括 7 B 前导码、1 B SFD 和帧间间隔。FCS 计入帧长，前导码和 SFD 不计入。
:::

### 2.3 传统共享式以太网

传统以太网使用总线或集线器连接站点，所有站点共享总带宽并处于同一个冲突域，通常采用半双工通信和 CSMA/CD。

- 同一时刻通常只能有一个站点成功发送。
- 站点越多、负载越高，冲突概率越大。
- 集线器只在物理层复制信号，不能根据 MAC 地址定向转发。

经典以太网把争用期规定为 512 bit 时间，因此 MAC 帧最小长度为 64 B。CSMA/CD、争用期和二进制指数退避见[第五节“介质访问控制”](./section-5)。

### 2.4 交换式以太网

交换式以太网使用二层交换机连接各站点。交换机根据 MAC 地址选择转发端口，其每个端口形成独立的冲突域，并通常为所连接的站点提供独享带宽。

点对点全双工链路可以同时发送和接收，不存在共享介质冲突，因此不使用 CSMA/CD。全双工链路虽然不再依靠最短帧长检测冲突，但仍遵守以太网 MAC 帧最小长度为 64 B 的格式要求。

交换机默认不能隔离广播域；在没有划分 VLAN 时，广播帧仍会被转发到同一广播域中的其他相关端口。交换机的自学习和转发过程见[第八节“数据链路层设备”](./section-8)。

| 对比项 | 传统共享式以太网 | 交换式以太网 |
| --- | --- | --- |
| 典型设备 | 总线、集线器 | 二层交换机 |
| 端口带宽 | 多个站点共享 | 每个端口通常独享 |
| 冲突域 | 所有站点处于同一个 | 每个端口独立 |
| 双工方式 | 半双工 | 通常全双工 |
| CSMA/CD | 使用 | 全双工时不使用 |

## 3. IEEE 802.11 无线局域网

IEEE 802.11 规定无线局域网 WLAN 的 MAC 层和物理层。无线局域网使用无线电波传输，支持终端移动，但信道容易受到干扰、衰减、多径传播和隐蔽站问题影响。

### 3.1 无线局域网的组成

- **站点 STA**：具有 IEEE 802.11 无线接口的终端或设备。
- **接入点 AP**：在基础设施网络中协调无线站点接入，并连接无线局域网与分配系统。
- **基本服务集 BSS**：IEEE 802.11 网络的基本组成单元。
- **分配系统 DS**：连接不同 AP 或 BSS 的骨干系统，常由以太网实现。
- **扩展服务集 ESS**：由分配系统连接的一个或多个基础设施 BSS，对上层表现为一个更大的无线局域网。

根据是否使用 AP，BSS 可以分为：

- **基础设施 BSS**：包含 AP。站点先与 AP 建立关联，并通过 AP 与同一 BSS 中的其他站点或外部网络通信。
- **独立 BSS（IBSS）**：不使用 AP，站点之间直接通信，也称自组织网络或 Ad Hoc 网络。

多个通过同一分配系统连接、并配置为同一 ESS 的 AP 通常使用相同的网络名称，使站点能够在不同 BSS 之间移动和重新关联。

### 3.2 IEEE 802.11 的介质访问

无线站点难以在发送的同时有效检测冲突，因此 IEEE 802.11 使用 CSMA/CA，而不是传统共享式以太网的 CSMA/CD。其主要机制包括：

- 发送前进行物理载波监听。
- 使用帧间间隔和随机退避竞争信道。
- 信道转忙时冻结退避计数，重新空闲后继续倒计时。
- 接收方正确收到单播数据帧后返回 ACK。
- 必要时使用 RTS/CTS 和网络分配向量 NAV 进行虚拟载波监听，缓解隐蔽站问题。

具体过程见[第五节“介质访问控制”](./section-5)。

### 3.3 IEEE 802.11 帧与地址

IEEE 802.11 MAC 帧可以分为管理帧、控制帧和数据帧：

- **管理帧**：用于信标、认证、关联和解除关联等管理操作。
- **控制帧**：包括 RTS、CTS、ACK 等，用于控制无线介质访问。
- **数据帧**：承载上层数据。

由于帧可能经过 AP 和分配系统转发，IEEE 802.11 数据帧最多包含 4 个地址。帧控制字段中的 `To DS` 和 `From DS` 决定各地址字段的含义：

| To DS | From DS | 地址 1 | 地址 2 | 地址 3 | 地址 4 | 典型场景 |
| ---: | ---: | --- | --- | --- | --- | --- |
| 0 | 0 | DA/RA | SA/TA | BSSID | 无 | IBSS 或同一无线链路直接传输 |
| 1 | 0 | BSSID/RA | SA/TA | DA | 无 | 站点发送给 AP |
| 0 | 1 | DA/RA | BSSID/TA | SA | 无 | AP 发送给站点 |
| 1 | 1 | RA | TA | DA | SA | 无线分配系统中的 AP 间转发 |

其中，RA 和 TA 是当前无线链路上的接收方与发送方地址，DA 和 SA 是数据的最终目的地址与原始源地址，BSSID 标识所在的基本服务集。

::: warning 易错点
802.11 帧可能同时需要“当前无线发送方/接收方”和“原始源/最终目的”地址，因此最多有 4 个地址；以太网帧通常只有源 MAC 地址和目的 MAC 地址两个地址字段。
:::

## 4. VLAN 基本概念与基本原理

### 4.1 VLAN 的概念

虚拟局域网 VLAN 在交换式局域网中把站点逻辑划分为不同的广播域。属于同一 VLAN 的站点在逻辑上处于同一个二层网络，即使它们连接在不同交换机上；属于不同 VLAN 的站点即使连接在同一台交换机上，也不能直接进行二层通信。

VLAN 的主要作用包括：

- 限制广播帧的传播范围，减小广播流量。
- 根据部门、业务或安全要求灵活组织网络，而不必完全依赖物理位置。
- 提高不同用户组之间的二层隔离性，但 VLAN 本身不能替代完整的安全控制。

VLAN 划分的是广播域，不是冲突域。交换机的每个端口本来就形成独立冲突域，而每个 VLAN 形成一个独立广播域。不同 VLAN 之间通信必须经过路由器或三层交换机进行网络层转发。

### 4.2 接入链路与干道链路

- **接入链路 Access Link**：通常连接终端与交换机，一个接入端口属于一个 VLAN。终端收发的普通以太网帧通常不携带 VLAN 标记，交换机根据接入端口确定其所属 VLAN。
- **干道链路 Trunk Link**：通常连接交换机、路由器或其他网络设备，可以同时承载多个 VLAN 的帧。不同 VLAN 的帧通常使用 IEEE 802.1Q 标记加以区分；采用本征 VLAN 的配置时，本征 VLAN 的帧也可能不携带标记。

当同一 VLAN 跨越多台交换机时，交换机之间的干道链路负责传递带有相应 VLAN 标识的帧。广播帧和未知目的单播帧只在所属 VLAN 内泛洪，不会被二层交换机转发到其他 VLAN。

### 4.3 IEEE 802.1Q 标记

IEEE 802.1Q 在以太网帧的源 MAC 地址与类型/长度字段之间插入一个 4 B 标记：

| 字段 | 长度 | 作用 |
| --- | ---: | --- |
| TPID | 16 bit | 标记帧使用 IEEE 802.1Q，常用值为 `0x8100` |
| PCP | 3 bit | 表示帧的优先级 |
| DEI | 1 bit | 表示拥塞时是否适合优先丢弃 |
| VLAN ID | 12 bit | 标识帧所属的 VLAN |

PCP、DEI 和 VLAN ID 共同组成 16 bit 的标记控制信息 TCI。VLAN ID 有 12 bit，可表示 4096 个数值，其中 0 和 4095 保留，因此通常可用的 VLAN ID 为 1～4094。

插入 802.1Q 标记后，普通最大以太网 MAC 帧可由 1518 B 增加到 1522 B。帧内容发生改变后，发送设备还需要重新计算 FCS。

::: warning 易错点
VLAN 是数据链路层的广播域划分，IP 子网是网络层的地址与路由概念。实际网络通常让一个 VLAN 对应一个 IP 子网，但二者不是同一个概念；不同 VLAN 之间仍需通过三层设备通信。
:::

::: tip 判断方法
看到“每端口独立”通常是在讨论冲突域；看到“广播只在某个逻辑组内传播”是在讨论 VLAN 和广播域；看到“同一链路承载多个 VLAN”应判断为 Trunk，其帧通常使用 802.1Q 标记区分 VLAN。
:::
