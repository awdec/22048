<h1><center>第五节 介质访问控制</center></h1>

## 1. 介质访问控制的目的

广播链路由多个站点共享，如果多个站点同时发送，信号可能相互干扰。介质访问控制协议决定站点何时可以使用共享信道，主要分为信道划分、随机访问和轮询访问三类。

## 2. 信道划分协议

- **频分复用 FDM**：不同站点占用不同频带。
- **时分复用 TDM**：不同站点占用不同时间片。
- **波分复用 WDM**：不同站点使用不同光波长。
- **码分复用 CDM**：不同站点使用相互正交的码片序列。

信道划分没有随机冲突，负载稳定时性能可预测，但站点暂时没有数据时，预留资源可能闲置。

## 3. ALOHA

- **纯 ALOHA**：站点有帧就立即发送，发生冲突后随机等待再重传。
- **时隙 ALOHA**：只允许在时隙开始处发送，把冲突危险期缩短为一个帧时长。

时隙 ALOHA 的最高吞吐量高于纯 ALOHA，但需要全网时隙同步。

## 4. CSMA

CSMA 在发送前监听信道：

- **1-坚持 CSMA**：信道空闲就立即发送，信道忙时持续监听。
- **非坚持 CSMA**：信道忙时随机等待一段时间再监听。
- **$p$-坚持 CSMA**：时隙信道空闲时以概率 $p$ 发送，以概率 $1-p$ 推迟。

载波监听可以减少冲突，但传播时延使多个站点仍可能同时判断信道空闲。

## 5. CSMA/CD

CSMA/CD 用于传统半双工共享以太网。站点发送时继续检测冲突，发现冲突后立即停止发送、发出强化信号，并使用二进制指数退避算法随机等待。

争用期为往返传播时延 $2\tau$。为保证发送方在帧发送完毕前检测到最远端冲突，最短帧发送时间必须满足：

$$
T_{frame}\ge2\tau.
$$

全双工交换式以太网没有共享介质冲突，不使用 CSMA/CD。

## 6. CSMA/CA

无线局域网难以边发送边检测冲突，且存在隐蔽站问题，因此使用 CSMA/CA：

- 发送前监听信道。
- 等待规定的帧间间隔。
- 执行随机退避。
- 接收方返回确认帧。
- 必要时使用 RTS/CTS 预约信道。

RTS/CTS 可以缓解隐蔽站问题，但会增加控制开销。

## 7. 轮询访问

- **轮询协议**：主节点依次询问各从节点是否有数据，控制明确，但有轮询开销和主节点单点故障。
- **令牌传递**：只有持有令牌的站点可以发送，没有冲突，重负载时性能稳定，但需要维护令牌。

::: warning 易错点
有载波监听并不代表一定无冲突；传播时延会使远端站点尚未听到正在发送的信号。无线局域网采用冲突避免而非直接冲突检测。
:::
