<h1><center>第二节 组帧</center></h1>

## 1. 字符计数法

字符计数法在帧首部设置一个计数字段，用它表示帧的长度。接收方读取计数字段后，按照给定长度接收当前帧，并由此确定下一帧的起始位置。

计数字段的单位通常是字节；它表示整个帧的长度还是其后字段的长度，由具体协议规定。

- **优点**：不需要使用特殊的帧定界符，数据内容不会与边界标志发生冲突，实现简单。
- **缺点**：计数字段一旦出错，接收方就会判断出错误的帧边界，并可能继续把后续数据划分错误，造成连续多个帧失去同步。

## 2. 字节填充法

字节填充法也称字符填充法，适用于以字节为基本处理单位的协议。协议使用特殊的**标志字节**表示帧的开始和结束。

如果数据部分也出现标志字节，接收方可能把它误认为帧边界。为了实现透明传输，协议还规定一个特殊的**转义字节**：

1. 发送方遇到数据中的标志字节时，在其前面插入一个转义字节。
2. 发送方遇到数据中的转义字节时，也在其前面插入一个转义字节。
3. 接收方在帧内部遇到转义字节时，删除该转义字节，并把其后的字节作为普通数据接收。


## 3. 零比特填充法

零比特填充法适用于面向比特的协议，常使用比特串 `01111110` 作为帧的开始和结束标志。

为了避免帧内部的数据产生相同的比特模式，发送方和接收方执行相反的操作：

- **发送方**：扫描需要透明传输的帧内容，每遇到连续 5 个 `1`，立即插入一个 `0`。
- **接收方**：在帧内部每遇到连续 5 个 `1`，若下一位是 `0`，就删除这个由发送方插入的 `0`。


## 4. 违规编码法

某些物理层线路编码只使用全部信号组合中的一部分来表示普通数据，剩余组合在正常编码中不会出现。违规编码法使用这些未被采用的“违规”信号组合表示帧的开始和结束。

例如，若某种线路编码规定每个码元中间必须发生电平跳变，那么不发生规定跳变的信号组合就不能表示普通数据，可以被选作特殊的帧定界信号。

- **优点**：帧边界不会与普通数据混淆，通常不需要额外插入转义字节或填充比特。
- **缺点**：依赖物理层编码存在未使用的信号组合，不适用于所有线路编码，并且需要数据链路层与物理层配合。

四种组帧方法的核心区别如下：

| 方法 | 确定边界的依据 | 是否填充 | 主要局限 |
| --- | --- | --- | --- |
| 字符计数法 | 首部中的长度字段 | 否 | 计数字段出错可能导致连续失步 |
| 字节填充法 | 特殊标志字节 | 插入转义字节 | 额外开销随特殊字节出现次数增加 |
| 零比特填充法 | 特殊标志比特串 | 连续 5 个 `1` 后插入 `0` | 额外开销随数据比特模式变化 |
| 违规编码法 | 正常数据不用的信号组合 | 通常不需要 | 依赖物理层编码具有冗余组合 |
