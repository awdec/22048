<h1><center>第七节 广域网</center></h1>

## 1. 广域网概述

广域网覆盖较大的地理范围，通常利用运营商提供的点到点链路或交换网络连接不同地区的局域网。局域网侧重站点接入和共享介质，广域网侧重远距离链路上的分组交付。

广域网的通信子网通常由交换节点和连接这些节点的链路组成，端系统通过接入链路进入广域网。

## 2. 广域网与局域网的区别

| 项目 | 局域网 | 广域网 |
| --- | --- | --- |
| 覆盖范围 | 较小 | 较大 |
| 管理主体 | 通常由单一组织管理 | 常依赖运营商设施 |
| 关注重点 | 介质访问、帧交换 | 远距离传输与分组交付 |
| 常见技术 | 以太网、WLAN | 点到点链路、运营商网络 |

局域网和广域网都可能使用数据链路层协议，但帧格式、介质访问方式和管理目标可以不同。

## 3. PPP 协议

PPP 是面向字节的点到点链路协议，可以在串行链路等多种物理网络上封装网络层数据报。PPP 提供：

- 组帧和透明传输。
- 帧检错。
- 链路建立、配置、测试和终止。
- 对多种网络层协议的复用与参数配置。

PPP 帧包含标志字段、地址字段、控制字段、协议字段、信息字段和 FCS。标志字节为 `0x7E`，异步链路使用字节填充实现透明传输。

## 4. LCP 与 NCP

- **链路控制协议 LCP**：建立、配置、测试和终止 PPP 数据链路，并协商最大接收单元、认证方式等参数。
- **网络控制协议 NCP**：为不同网络层协议配置相关参数，使一条 PPP 链路能够承载多种网络层协议。

PPP 链路通常经历链路静止、建立、认证、网络层协议配置、数据通信和终止等阶段。

## 5. PPP 的可靠性

PPP 使用 FCS 检测帧差错，但不提供序号、确认、重传和流量控制。检测到错误的帧会被丢弃，需要可靠交付时由上层协议负责。

::: warning 易错点
PPP 是点到点链路协议，不需要解决多站点共享介质冲突；它具有检错功能，但不是可靠传输协议。
:::
