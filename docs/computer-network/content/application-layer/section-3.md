<h1><center>第三节 文件传输协议</center></h1>

## 1. FTP 的功能

文件传输协议 FTP 用于在不同主机之间传输文件，并支持目录浏览、文件重命名和删除等远程文件操作。FTP 屏蔽不同操作系统在文件命名、目录结构和数据表示方面的部分差异。

FTP 采用客户—服务器模型并使用 TCP，以保证命令和文件数据可靠、按序到达。

## 2. 控制连接与数据连接

FTP 同时使用两条相互独立的 TCP 连接：

- **控制连接**：客户端连接服务器 TCP 端口 21，传输用户登录、目录操作和文件传输命令，在整个会话期间保持。
- **数据连接**：用于传输文件内容或目录列表，每次传输任务通常单独建立，完成后关闭。

控制信息和文件数据分离使服务器可以在控制连接保持期间建立多个数据传输任务。

## 3. 主动模式

主动模式中，客户端通过控制连接告诉服务器自己的数据端口，服务器通常从 TCP 端口 20 主动连接客户端指定端口。

由于连接由外部服务器主动发往客户端，客户端侧 NAT 或防火墙可能阻止该连接。

## 4. 被动模式

被动模式中，服务器通过控制连接告知一个临时数据端口，客户端主动连接该端口建立数据连接。

控制连接和数据连接都由客户端发起，因此被动模式通常更容易穿越客户端侧 NAT 和防火墙，也是现代网络中常用的模式。

## 5. FTP 传输过程

典型流程为：

1. 客户端与服务器端口 21 建立控制连接。
2. 客户端发送用户名、口令和操作命令。
3. 双方根据主动或被动模式建立数据连接。
4. 在数据连接上传输文件或目录列表。
5. 关闭数据连接，控制连接仍可继续接受命令。
6. 会话结束时关闭控制连接。

::: warning 易错点
FTP 的控制连接和数据连接相互独立：控制连接长期保持，数据连接通常按传输任务建立；主动与被动模式的核心区别是由哪一方发起数据连接。
:::
