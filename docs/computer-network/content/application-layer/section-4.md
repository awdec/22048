<h1><center>第四节 电子邮件</center></h1>

## 1. 电子邮件系统的组成

电子邮件系统主要由用户代理、邮件服务器和邮件协议组成：

- **用户代理**：供用户编写、阅读和管理邮件。
- **邮件服务器**：保存用户邮箱，并负责邮件的发送、接收和转发。
- **邮件协议**：规定邮件提交、服务器间传输和用户读取邮件的方式。

## 2. 邮件发送过程

典型邮件传输过程为：

1. 发送方用户代理把邮件提交给发送方邮件服务器。
2. 发送方邮件服务器通过 DNS 查询接收域的 MX 记录。
3. 发送方邮件服务器使用 SMTP 把邮件推送到接收方邮件服务器。
4. 接收方服务器把邮件保存到用户邮箱。
5. 接收方使用 POP3 或 Web 邮件方式读取邮件。

## 3. SMTP

简单邮件传输协议 SMTP 用于客户端向服务器提交邮件以及邮件服务器之间转发邮件，使用 TCP，传统服务器端口为 25。

SMTP 采用命令—响应交互，并具有“推送”特点。传统 SMTP 主要处理 ASCII 文本，邮件正文结束使用特定行结束规则。

## 4. POP3

POP3 常用于把邮件从服务器下载到客户端，协议简单，传统端口为 TCP 110。

SMTP 用于发送和转发邮件，POP3 用于接收方访问邮箱，作用方向不同。

## 5. 电子邮件格式

电子邮件由首部和主体组成，二者之间使用空行分隔。首部通常包含：

- `From`：发件人。
- `To`：收件人。
- `Subject`：主题。
- `Date`：日期。

邮件首部中的 `From`、`To` 属于邮件内容格式，不等同于 SMTP 信封命令中的实际投递地址。

## 6. MIME

多用途互联网邮件扩展 MIME 增加内容类型、字符集、内容传输编码和多部分消息等信息，使原本面向 ASCII 文本的邮件系统能够传输：

- 非 ASCII 文本。
- 图片、音频和视频。
- 二进制附件。
- 包含多个不同部分的复合邮件。

::: warning 易错点
SMTP 用于推送邮件，POP3 用于用户读取邮件；MIME 扩展的是邮件内容表示能力，不负责邮件服务器之间的传输。
:::
