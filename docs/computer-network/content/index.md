## 三、各题型特点

### 单项选择题（40 × 2 = 80 分）

- 每题 2 分，答错或不答均为 0 分，没有过程分。
- 覆盖面广：四门课各章都会出题，以概念辨析、性质判断和小型计算为主。
- 常用做法：排除法、代入特殊值、画图或列小表验证、抓题干中「一定」「最多」「至少」这类限定词。
- 主要失分点：概念细节（存储结构差异、协议特点、调度算法性质）和边界条件（位序与下标、是否含取指、单位换算）。

### 综合应用题（7 题 = 70 分）

- 按步骤给分，需要写出完整的推导、计算过程或算法。
- 单题分值不等（按题目难度分配），一道题做不出来对总分影响很大。
- 四门课通常各自固定占位（见第四节），题目内部常把多个知识点串在一起考。
- 书写规范很重要：公式、代入过程、算法思路、复杂度分析都要落到纸面。

## 五、计算机网络专项分析

### 分值构成

| 题型 | 题量 | 分值 | 近年常见题号 |
| --- | ---: | ---: | --- |
| 单项选择题 | 约 9 题 | 约 18 分 | 约第 32—40 题 |
| 综合应用题 | 1 题 | 约 7 分 | 约第 47 题 |
| **合计** | | **25 分** | |

计算机网络是四门课中分值最低的一门（占 16.7%），但结构很特殊：**18 分来自选择题，只有 1 道综合应用题**。这意味着它的分数高度集中在「覆盖面广、计算不难」的选择题上，属于投入产出比很高的科目，「能拿的分不要丢」。

### 各章大致分值

| 章节 | 近年大致分值 | 主要落点 |
| --- | ---: | --- |
| 第一章 计算机网络概述 | 2—4 分 | 性能指标（时延、带宽、吞吐量）、体系结构与分层 |
| 第二章 物理层 | 2—4 分 | 奈奎斯特与香农定理、编码与调制、传输介质与设备 |
| 第三章 数据链路层 | 4—7 分 | 差错控制、流量控制、介质访问控制、以太网与设备 |
| 第四章 网络层 | 5—8 分 | IPv4 与子网划分、路由协议、IP 分片、网络层设备 |
| 第五章 传输层 | 4—7 分 | TCP 连接管理与可靠传输、拥塞控制、UDP |
| 第六章 应用层 | 2—4 分 | DNS、FTP、电子邮件、万维网 |
