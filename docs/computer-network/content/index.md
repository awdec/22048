## 三、各题型特点

### 单项选择题（40 × 2 = 80 分）

- 每题 2 分，答错或不答均为 0 分，没有过程分。
- 覆盖面广：四门课均会涉及，以概念辨析、性质判断和小型计算为主；不保证每年每章都有独立题目。
- 常用做法：排除法、代入特殊值、画图或列小表验证、抓题干中「一定」「最多」「至少」这类限定词。
- 主要失分点：概念细节（存储结构差异、协议特点、调度算法性质）和边界条件（位序与下标、是否含取指、单位换算）。

### 综合应用题（通常 7 题，共 70 分）

- 按步骤给分，需要写出完整的推导、计算过程或算法。
- 单题分值不等（按题目难度分配），一道题做不出来对总分影响很大。
- 四门课按大纲规定的分值组织考查，题目内部常把多个知识点串在一起考；具体题数和题号以当年试卷为准。
- 书写规范很重要：公式、代入过程、算法思路、复杂度分析都要落到纸面。

## 五、计算机网络专项分析

### 分值构成

计算机网络占 25 分，约为全卷的 16.7%。选择题侧重概念辨析和局部计算，综合应用题可以串联编址、转发、传输控制及应用访问过程。不能把“选择题固定 18 分、综合题固定 7 分”当作大纲规定。

复习应兼顾完整覆盖与跨层分析：既能判断各协议解决什么问题，也能沿一次通信过程说明地址、首部、窗口和时延如何变化。

### 各章复习重点

| 章节 | 主要落点 |
| --- | --- |
| 第一章 计算机网络概述 | 网络组成与分类、交换方式、性能指标、分层、协议与服务、OSI 与 TCP/IP 参考模型 |
| 第二章 物理层 | 通信基础、奈奎斯特与香农定理、编码与调制、传输介质及接口、中继器与集线器 |
| 第三章 数据链路层 | 组帧、检错与纠错、停止—等待与滑动窗口、介质访问、以太网、无线局域网、VLAN、PPP 与交换机 |
| 第四章 网络层 | 异构互连、路由与转发、SDN、拥塞控制、IPv4/IPv6、子网与聚合、ARP/DHCP/ICMP、路由协议、多播、移动 IP、路由器 |
| 第五章 传输层 | 端口与复用分用、UDP 与校验和、TCP 首部、连接管理、可靠传输、流量控制与拥塞控制 |
| 第六章 应用层 | C/S 与 P2P、DNS、FTP、电子邮件格式与 MIME、SMTP/POP3、WWW 与 HTTP |
