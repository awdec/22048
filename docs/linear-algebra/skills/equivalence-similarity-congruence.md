<h1><center>矩阵等价、相似、合同的对比总结</center></h1>

三种关系容易混：都写作"两个矩阵有关系"，都保持秩，都对应一套"化标准形"的操作。分辨它们只需问三个问题——**要求什么形状**、**不变量是什么**、**怎么判定**。

定义分别见[矩阵第三节](../content/matrices/section-3)（等价）、[特征值与特征向量第二节](../content/eigenvalues-eigenvectors/section-2)（相似）、[二次型第一节](../content/quadratic-forms/section-1)（合同）。

## 1. 定义对照

| | 等价 | 相似 | 合同 |
| --- | --- | --- | --- |
| 关系式 | $B=PAQ$ | $B=P^{-1}AP$ | $B=C^TAC$ |
| 变换矩阵 | $P,Q$ 均可逆 | $P$ 可逆 | $C$ 可逆 |
| 适用范围 | 同型矩阵 $A_{m\times n},B_{m\times n}$ | 同阶**方阵** | 同阶**方阵**（教材只对实对称矩阵定义） |
| 核心不变量 | 秩 | 特征值 | 正、负惯性指数 |
| 标准形 | $\begin{pmatrix}I_r&O\\O&O\end{pmatrix}$ | Jordan 标准形（或对角阵） | 规范形 $\operatorname{diag}(I_p,-I_q,O)$ |
| 主要用途 | 化行最简形、求秩 | 相似对角化 | 二次型化标准形 |

三者的标准形**都唯一**（相似情形唯一到 Jordan 块的排列），因此判定关系就是**比较标准形对应的参数**：

$$
\text{等价比秩}\qquad\text{相似比特征值}\qquad\text{合同比惯性指数}
$$

## 2. 谁强谁弱：包含关系

先记住两条无条件成立的方向：

$$
\text{相似}\Rightarrow\text{等价},\qquad \text{合同}\Rightarrow\text{等价}.
$$

- 相似保持秩（$r(P^{-1}AP)=r(A)$），故必等价；
- 合同 $B=C^TAC$ 中 $C$ 可逆，保持秩，故必等价。

反方向都不成立：等价只看秩，条件最弱。

对**实对称矩阵**（考研数二的主战场），关系链变得非常清晰：

$$
\boxed{\text{相似}\Longrightarrow\text{正交相似}\Longrightarrow\text{合同}\Longrightarrow\text{等价}}
$$

含意是：两个实对称矩阵相似时，一定存在**正交**矩阵 $Q$ 使 $B=Q^TAQ$，此时 $Q^{-1}=Q^T$，相似与合同同时成立。

::: warning 非对称矩阵不要套用这条链
"相似 $\Rightarrow$ 合同"只对**实对称**矩阵成立。若 $A$ 实对称而 $A\sim B$ 中的 $P$ 不是正交矩阵，则 $B$ 可能连对称都不是。例如

$$
A=\begin{pmatrix}1&0\\0&2\end{pmatrix},\quad
P=\begin{pmatrix}1&1\\0&1\end{pmatrix}
\ \Rightarrow\
B=P^{-1}AP=\begin{pmatrix}1&-1\\0&2\end{pmatrix},
$$

$B$ 特征值仍为 $1,2$，但与 $A$ 相似而不对称；而 $C^TAC$ 恒为对称矩阵，所以此时根本谈不上合同。换句话说，**合同比相似的适用范围窄得多**。
:::

## 3. 不变量对照

| 性质 | 等价 | 相似 | 合同 |
| --- | --- | --- | --- |
| 秩 | ✓ | ✓ | ✓ |
| 是否可逆 | ✓ | ✓ | ✓ |
| 特征多项式 | ✗ | ✓ | ✗ |
| 特征值（含重数） | ✗ | ✓ | ✗ |
| 行列式的**值** | ✗ | ✓ | ✗（但**符号**保持） |
| 迹 | ✗ | ✓ | ✗ |
| 对称性 | ✗ | ✗ | ✓ |
| 正、负惯性指数（实对称） | ✗ | ✓ | ✓ |

两点说明：

- **合同保持行列式的符号**。由 $|C^TAC|=|C|^2|A|$ 且 $|C|^2>0$，所以 $|B|$ 与 $|A|$ 同号，但数值一般不同。这是"合同不能保特征值"的直接体现。
- **相似与合同都不保秩以外的一般信息，但相似保得多**。例如 $\operatorname{diag}(1,1)$ 与 $\operatorname{diag}(2,3)$ 合同（正惯性指数都是 $2$），但迹 $2\ne5$，故不相似。

## 4. 判定方法对照

| | 判定思路 |
| --- | --- |
| **等价** | 化为行阶梯形，比较秩：$r(A)=r(B)$（前提同型） |
| **相似** | ① 直接找可逆 $P$ 使 $B=P^{-1}AP$；② 证明**两者都可对角化**且**特征值（含重数）相同**；③ 特征多项式相同且都能对角化 |
| **合同** | 实对称前提下，比较正、负特征值**个数**是否分别相同；或用配方法比较正、负平方项个数 |

对**实对称矩阵**，判定可以简化成一句口诀：

$$
\boxed{
\begin{aligned}
&\text{相似}\iff\text{特征值完全相同（含重数）}\\
&\text{合同}\iff\text{正、负特征值个数分别相同}\\
&\text{等价}\iff\text{秩相同}
\end{aligned}}
$$

因为实对称矩阵一定能正交对角化，所以"能否对角化"不是障碍，相似的门槛只剩特征值。

::: tip 高频套路
要证 $A,B$ 相似：先看是否都实对称/都可对角化，再比特征多项式。
要证 $A,B$ 合同：先确认都实对称，再数**正特征值个数**和**负特征值个数**——不用管具体数值。
要证 $A,B$ 等价：只比秩。三者中它最容易证，也最容易由此推出其他结论（例如先证合同得到秩相同）。
:::

## 5. 典型例题

::: info 例 1：用不变量快速判断
设 $A=\begin{pmatrix}1&0\\0&1\end{pmatrix}$，$B=\begin{pmatrix}2&0\\0&3\end{pmatrix}$。判断两者的等价、相似、合同关系。
:::

::: details 解析
$r(A)=r(B)=2$，同型，故**等价**。

特征值分别为 $\{1,1\}$ 与 $\{2,3\}$，不相同，故**不相似**（注意：两者其实都可对角化，问题只出在特征值）。

正惯性指数均为 $2$，负惯性指数均为 $0$，故**合同**。也可直接写出 $C=\operatorname{diag}(\sqrt2,\sqrt3)$，验证 $C^TAC=B$。

结论：等价且合同，但不相似。
:::

::: info 例 2：合同但不相似
设 $A=\operatorname{diag}(1,-1)$，$B=\operatorname{diag}(2,-3)$。求可逆矩阵 $C$ 使 $B=C^TAC$，并判断两者是否相似。
:::

::: details 解析
取 $C=\operatorname{diag}(\sqrt2,\sqrt3)$，则

$$
C^TAC=\operatorname{diag}(\sqrt2,\sqrt3)\operatorname{diag}(1,-1)\operatorname{diag}(\sqrt2,\sqrt3)
=\operatorname{diag}(2,-3)=B.
$$

两者正惯性指数均为 $1$、负惯性指数均为 $1$，故**合同**。

但特征值为 $\{1,-1\}$ 与 $\{2,-3\}$，不相同，故**不相似**。这也印证了"合同只保惯性指数，不保特征值"。
:::

::: info 例 3：由相似求参数
设 $A=\begin{pmatrix}1&2\\2&1\end{pmatrix}$ 与 $B=\begin{pmatrix}3&0\\0&c\end{pmatrix}$ 相似，求 $c$。
:::

::: details 解析
相似矩阵的迹相等：

$$
\operatorname{tr}A=1+1=2,\qquad \operatorname{tr}B=3+c,
$$

故 $c=-1$。

用行列式复核：$|A|=1-4=-3$，$|B|=3c=-3$，一致。此时 $A$ 的特征值为 $3,-1$，与 $B$ 的对角元相同。

一般做法：**先列迹，再列行列式**，两个方程即可定出两个参数。
:::

::: info 例 4：证明实对称矩阵相似必合同
设 $A,B$ 均为 $n$ 阶实对称矩阵，且 $A$ 与 $B$ 相似。证明 $A$ 与 $B$ 合同。
:::

::: details 解析
实对称矩阵可正交对角化，设

$$
A=Q_1\Lambda Q_1^T,\qquad B=Q_2\Lambda Q_2^T,
$$

其中 $Q_1,Q_2$ 为正交矩阵。由于 $A\sim B$，两者特征值完全相同，故可把特征值按同一顺序排列，使两式共用同一个对角阵 $\Lambda=\operatorname{diag}(\lambda_1,\ldots,\lambda_n)$。

由 $A=Q_1\Lambda Q_1^T$ 得 $\Lambda=Q_1^TAQ_1$，代入 $B$ 的表达式：

$$
B=Q_2\Lambda Q_2^T=Q_2Q_1^TAQ_1Q_2^T=(Q_1Q_2^T)^TA(Q_1Q_2^T).
$$

取 $C=Q_1Q_2^T$。正交矩阵的乘积仍正交，故 $C$ 可逆，且 $B=C^TAC$，即 $A$ 与 $B$ 合同。

进一步，因为 $A=Q_1\Lambda Q_1^T,\ B=Q_2\Lambda Q_2^T$ 可以共用同一个 $\Lambda$，所以 $A$ 与 $B$ **正交相似**：

$$
B=(Q_1Q_2^T)^TA(Q_1Q_2^T),\qquad Q_1Q_2^T\text{ 正交}.
$$

这正是第 2 节那条关系链的来源。
:::

::: info 例 5：由特征值反求参数
设 $A=\begin{pmatrix}1&-2&-4\\-2&a&-2\\-4&-2&1\end{pmatrix}$ 的特征值为 $5,5,-4$，求 $a$。
:::

::: details 解析
$A$ 为实对称矩阵，相似于 $\operatorname{diag}(5,5,-4)$。用迹相等：

$$
\operatorname{tr}A=1+a+1=a+2,\qquad \operatorname{tr}\operatorname{diag}(5,5,-4)=5+5-4=6,
$$

故 $a=4$。

代回验证：$A-5I=\begin{pmatrix}-4&-2&-4\\-2&-1&-2\\-4&-2&-4\end{pmatrix}$ 三行成比例，秩为 $1$，故 $\lambda=5$ 至少是二重特征值，与题设吻合。

此题只用到"相似保持迹"，不必求特征多项式。**只要题目给出特征值，第一反应就是列迹、列行列式、列 $\operatorname{tr}(A^2)$。**
:::

::: info 例 6：综合判断（等价却不合同）
设 $A=\operatorname{diag}(1,1)$，$B=\operatorname{diag}(1,-1)$。判断两者的等价、相似、合同关系。
:::

::: details 解析
$r(A)=r(B)=2$，同型，故**等价**。

特征值为 $\{1,1\}$ 与 $\{1,-1\}$，不相同，故**不相似**。

正惯性指数分别为 $2$ 与 $1$，不相同，故**不合同**。

结论：只等价。这说明**等价是最弱的关系**——秩相同并不能保证合同，判合同必须再数一次惯性指数。
:::

## 6. 易错结论速查

| 说法 | 判断与说明 |
| --- | --- |
| 秩相同就能推出相似 | 错，例如 $I_2$ 与 $\operatorname{diag}(2,3)$，秩都为 $2$ 但特征值不同 |
| 秩相同就能推出合同 | 错，例如 $\operatorname{diag}(1,1)$ 与 $\operatorname{diag}(1,-1)$，惯性指数不同 |
| 特征值相同就能推出相似 | 错，一般矩阵还需都能对角化；**实对称矩阵**才是等价的 |
| 相似一定合同 | 错，一般情形不成立；**实对称**矩阵才成立 |
| 合同一定相似 | 错，$\operatorname{diag}(1,1)$ 与 $\operatorname{diag}(2,3)$ 合同但不相似 |
| 相似或合同一定等价 | 对，两者都保持秩 |
| 等价一定相似或合同 | 错，等价只看秩，条件最弱 |
| 合同保持行列式的值 | 错，只保持符号：$\lvert C^TAC\rvert=\lvert C\rvert^2\lvert A\rvert$ |
| 合同保持特征值 | 错，只保持正、负特征值的**个数** |
| 相似保持对称性 | 错，$P$ 非正交时对称性会被破坏；合同才保持对称性 |
| 等价、相似、合同都要求同阶方阵 | 错，**等价只要求同型**（可以不是方阵），相似与合同要求同阶方阵 |
| 实对称矩阵相似 $\iff$ 正交相似 | 对，因为两者都正交对角化到同一个对角阵 |

::: tip 一句话分辨
看到"秩"想等价，看到"特征值"想相似，看到"二次型 / 正负平方项个数"想合同；**实对称**是相似通向合同的桥梁。
:::
