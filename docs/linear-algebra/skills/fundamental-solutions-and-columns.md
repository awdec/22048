<h1><center>基础解系和列向量之间的关系</center></h1>

齐次方程组 $Ax=0$ 的**解向量**，本质上是系数矩阵**各列之间的一个线性关系**；而**基础解系**就是这些线性关系中最“本质”的一组。把“解方程”翻译成“找列向量组的全部线性关系”，许多结论（解的个数、非主元列、$AB=0$、由解反推矩阵）就不再需要死记。

设系数矩阵按列分块为

$$
A=(\alpha_1,\ldots,\alpha_n)\in\mathbb R^{m\times n},
$$

其中 $\alpha_j$ 是 $A$ 的第 $j$ 个**列向量**，未知量个数 $n$ 恰好等于**列数**。对任意 $x=(x_1,\ldots,x_n)^T$，

$$
Ax=x_1\alpha_1+x_2\alpha_2+\cdots+x_n\alpha_n.
$$

本文只讨论实矩阵与实向量。下文用“列向量”指 $A$ 的列，用“基础解系向量”指把解竖起来写成的向量，两者不要混淆。

## 1. 本质：一个解就是一个列之间的线性关系

$$
x\text{ 是 }Ax=0\text{ 的解}\iff x_1\alpha_1+x_2\alpha_2+\cdots+x_n\alpha_n=0.
$$

因此“解”就是用 $x$ 的分量把 $n$ 个列向量线性组合成零向量的一组系数。由此可读出：

- **零解**对应“系数全为零”的平凡关系；
- $Ax=0$ 有**非零解** $\iff$ 列向量 $\alpha_1,\ldots,\alpha_n$ **线性相关** $\iff r(A)<n$；
- 当 $A$ 为 $n$ 阶方阵时，非零解 $\iff \det A=0$（列相关 $\iff$ 行列式为零）。

于是“求基础解系”这件事可以换一种说法：**找出列向量组全部线性关系的一组基**。基础解系中每个向量给出一条“独立”的关系，任一解（即任一关系）都能唯一写成它们的线性组合。

::: tip 快速核验“某个向量是不是解”
计算 $A\xi$ 即可：$A\xi=0$ 等价于 $\xi$ 与 $A$ 的**每一行**对应分量乘积之和为零（逐行点积为 $0$）。所以给出行向量的具体数值时，往往用眼睛扫一遍就能排除选项，不必真做矩阵乘法。
:::

## 2. 解的个数：$n-r(A)$，只由列数与列秩决定

$$
\boxed{\ \text{基础解系所含解向量的个数}=n-r(A)=(\text{列数})-(\text{列向量组的秩})\ }
$$

**理由**：解空间 $\{x:Ax=0\}$ 是 $\mathbb R^n$ 的子空间，其维数为 $n-r(A)$；基础解系就是解空间的一组基，故含 $n-r(A)$ 个向量。

两个极端情形要脱口而出：

- 若 $r(A)=n$（$n$ 个列向量线性无关，即列满秩），则只有零解，**无基础解系**；
- $r(A)$ 越小，解空间越大。特别地，当 $m<n$（方程个数少于未知量个数）时，因 $r(A)\le m<n$，齐次方程**必有非零解**。

::: tip 判断“给定的 $s$ 个向量是否构成基础解系”的三步法
设给出 $\xi_1,\ldots,\xi_s$：

1. **每个** $\xi_i$ 都是 $Ax=0$ 的解；
2. **个数** $s=n-r(A)$；
3. $\xi_1,\ldots,\xi_s$ **线性无关**。

三条同时满足即为基础解系（$s$ 个无关向量落在 $s$ 维空间里，必然张成整个解空间）。常见失误是只验“都是解 + 线性无关”而忘记个数差一个，或只看个数而忘了验证无关。
:::

## 3. 具体求解里隐含的“列”对应：非主元列 ↔ 自由未知量 ↔ 基础解系向量

对 $A$ 作初等行变换化为**行最简形**，列号不动。此时：

- **主元列**对应**基本未知量**，主元列个数 $=r(A)$；主元列的**编号**就是 $A$ 中极大线性无关列（即一个极大线性无关组）的编号，因为初等行变换不改变各列之间的线性关系及表示系数；
- **非主元列**对应**自由未知量**，非主元列个数 $=n-r(A)$，恰好等于基础解系向量个数。

对每个非主元列 $k$：令 $x_k=1$、其余自由未知量为 $0$，由行最简形解出各基本未知量，就得到一个基础解系向量 $\xi^{(k)}$。它的一般形状是

$$
\xi^{(k)}=
\big(\underbrace{-c_{1k}}_{\text{基本未知量}},\ldots,
\underbrace{1}_{\substack{\text{第 }k\text{ 位}}},\ldots\big)^T,
$$

其中 $c_{ik}$ 是行最简形第 $k$ 列中主元行的分量。**列上的解读**：非主元列 $\alpha_k$ 必能被主元列线性表示，而 $\xi^{(k)}$ 正是把等式

$$
\alpha_k=c_{1k}\alpha_{i_1}+\cdots+c_{rk}\alpha_{i_r}
$$

改写成“$\alpha\cdot\xi^{(k)}=0$”的关系式：主元位取表示系数的相反数、第 $k$ 位取 $1$。所以**非主元列与基础解系向量一一对应**，每多一个“被其他列线性表示”的列，就多一个基础解系向量。具体数值流程见下文例 1。

## 4. 把若干向量“打包”成矩阵：利用 $AB=0$

验证“一串向量是否为基础解系”时，逐个验证很繁琐。把它们按**列**拼成矩阵 $B=(\xi_1,\ldots,\xi_s)\in\mathbb R^{n\times s}$，有

$$
\boxed{\ AB=0\iff B\text{ 的每一列都是 }Ax=0\text{ 的解}\ }
$$

因为 $(AB)_{i}$ 恰是 $A\xi_i$。进一步，由 $AB=0$ 得到秩不等式（本题最值钱的结论）：

$$
\boxed{\ A\in\mathbb R^{m\times n},\ B\in\mathbb R^{n\times s},\ AB=0
\ \Longrightarrow\ r(A)+r(B)\le n\ }
$$

**理由**：$B$ 的各列都是解，故列空间 $\operatorname{col}(B)$ 含于解空间，而解空间维数为 $n-r(A)$，故 $r(B)=\dim\operatorname{col}(B)\le n-r(A)$。

若 $B$ 恰含 $s=n-r(A)$ 列，则上一步的三条件可合并为更省事的判据：

$$
\boxed{\ s=n-r(A)\text{ 且 }AB=0\text{ 时，}B\text{ 的列构成基础解系}\iff r(B)=s\iff r(A)+r(B)=n\ }
$$

因为 $B$ 的列都是解且个数已满，只需再保证它们线性无关（$r(B)=s$），就张成整个解空间。

**两条典型用法**

- **选项判定**：把待检向量按列拼成 $B$，只需算一次 $AB$（或逐列 $A\xi_i$）是否为 $0$，再看秩。
- **由秩反推**：已知 $AB=0$，立即有 $r(B)\le n-r(A)$。若题目再给出 $r(A)$ 或 $r(B)$，可据此判断 $B$ 的列能否充当基础解系、能含多少个独立解向量，见下文例 2。

## 5. 由解反推 $A$：行向量与基础解系正交

把“解”的视角反过来用。设 $\xi_1,\ldots,\xi_t$ 是 $Ax=0$ 的基础解系（$t=n-r(A)$），则对任意行向量 $R^T$ 和任意 $j$ 都有

$$
R\cdot \xi_j=0,
$$

即 $A$ 的**每个行向量都与全部基础解系向量正交**。反过来说，若一个向量与所有 $\xi_j$ 都正交，它就能作为 $A$ 的一行。更精确地，两边的维数同为 $n-t=r(A)$，故

$$
\boxed{\ A\text{ 的行空间}=
\big\{\text{与全部基础解系向量正交的向量}\big\}
=\big(\operatorname{span}\{\xi_1,\ldots,\xi_t\}\big)^{\perp}\ }
$$

**用途**：

- **求含参矩阵**：把已知解代入 $Ax=0$，等价于“每一行与已知解点积为零”，据此定参数；
- **构造 $A$**：取正交补空间的一组基作行向量，得到的矩阵与原 $A$ 有相同的基础解系；
- **定秩**：仅“已知 $k$ 个解”只能得到 $r(A)\le n-k$，若要它们恰为基础解系还需补上秩条件，见下文例 3。

::: tip 最常见的特例
若 $\xi=(1,1,\ldots,1)^T$ 是 $Ax=0$ 的解，则 $A$ 的**每行元素之和为 $0$**（即各行系数之和为零）；等价地从列看，是**全部列向量之和为零向量** $\alpha_1+\cdots+\alpha_n=0$。这类条件在含参数题里直接写成“每行求和 $=0$”即可。
:::

## 6. 方阵下的两条跨章节快捷结论

### 6.1 秩为 $n-1$：用伴随矩阵 $A^*$ 直接写基础解系

设 $A$ 为 $n\ (n\ge2)$ 阶方阵且 $r(A)=n-1$，则 $\det A=0$，由 $AA^*=|A|I=0$ 知 $A^*$ 的**每一列都是 $Ax=0$ 的解**。又 $r(A)=n-1$ 时 $r(A^*)=1$，而基础解系此时只含 $n-r(A)=1$ 个向量，故

$$
\boxed{\ r(A)=n-1\ \Longrightarrow\ A^*\text{ 的任一非零列就是一个基础解系向量}\ }
$$

例如 $A=\begin{pmatrix}1&2&3\\4&5&6\\7&8&9\end{pmatrix}$ 有三阶子式为零、且前两行不成比例，故 $r(A)=2$，$Ax=0$ 的基础解系可取 $(1,-2,1)^T$（该向量恰可由 $A^*$ 的非零列得到）。不必完整求 $A^*$，只需一个非零列，或直接解方程更快。

### 6.2 非零解 = 特征值 $0$ 的特征向量

$A$ 为 $n$ 阶方阵时，$A\xi=0=0\cdot\xi$，故 $Ax=0$ 的非零解恰是 $A$ 对应**特征值 $0$** 的特征向量。于是

$$
\boxed{\ “Ax=0\text{ 的基础解系含 }k\text{ 个向量}”
\ \iff\ “0\text{ 是特征值，且其几何重数（特征子空间维数）为 }k”\ }
$$

且 $k$ 不超过特征值 $0$ 的代数量数。这条口径把它与特征向量、相似对角化题目接通：例如“$A$ 不可逆”就是“$0$ 是特征值”，“$A$ 可对角化”要求几何重数等于代数量数等。

## 7. 典型例题

::: info 例 1：数值求解，并读出列关系
设
$$
A=\begin{pmatrix}
1&1&1&4\\
2&-1&5&-1\\
-1&2&-4&5
\end{pmatrix}.
$$
求 $Ax=0$ 的基础解系，并说明每个基础解系向量对应的列关系。
:::

::: details 解析
对 $A$ 作初等行变换（$R_2-2R_1,\ R_3+R_1,\ \cdots$）得行最简形

$$
\begin{pmatrix}
1&1&1&4\\
2&-1&5&-1\\
-1&2&-4&5
\end{pmatrix}
\longrightarrow
\begin{pmatrix}
1&0&2&1\\
0&1&-1&3\\
0&0&0&0
\end{pmatrix}.
$$

主元列为第 $1,2$ 列，故 $r(A)=2$，基础解系含 $4-2=2$ 个向量；自由未知量为 $x_3,x_4$。

- 取 $x_3=1,x_4=0$：由 $x_1=-2x_3-x_4,\ x_2=x_3-3x_4$ 得 $\xi_3=(-2,\ 1,\ 1,\ 0)^T$；
- 取 $x_3=0,x_4=1$：得 $\xi_4=(-1,\ -3,\ 0,\ 1)^T$。

通解为 $X=c_1\xi_3+c_2\xi_4$。写成列关系：

$$
\alpha_3=2\alpha_1-\alpha_2\qquad(\text{来自 }\xi_3：-2\alpha_1+\alpha_2+\alpha_3=0),\\
\alpha_4=\alpha_1+3\alpha_2\qquad(\text{来自 }\xi_4：-\alpha_1-3\alpha_2+\alpha_4=0).
$$

非主元列 $\alpha_3,\alpha_4$ 各自“对应”一个基础解系向量，且基础解系向量主元位的分量正是这两种表示的系数取相反数。用 $A\xi_3$、$A\xi_4$ 逐列验算可快速确认两向量确为解。
:::

::: info 例 2：用 $AB=0$ 打包判定哪些向量组是基础解系
沿用例 1 的 $A$（$r(A)=2$，应含 $2$ 个解向量）。判断下列各组能否作为 $Ax=0$ 的基础解系：
$$
\begin{aligned}
&\text{①}\ (-2,1,1,0)^T,\ (-1,-3,0,1)^T;\\
&\text{②}\ (-2,1,1,0)^T,\ (2,-1,-1,0)^T;\\
&\text{③}\ (-2,1,1,0)^T,\ (1,1,1,0)^T;\\
&\text{④}\ (1,0,0,0)^T,\ (0,1,0,0)^T.
\end{aligned}
$$
:::

::: details 解析
把每组的两个向量按列拼成矩阵 $B$，逐个检查“$AB$ 是否为零”与“$r(B)$ 是否为 $2$”。

- **组③、④**：先验解。$A(1,1,1,0)^T=\alpha_1+\alpha_2+\alpha_3\ne0$，$A(1,0,0,0)^T=\alpha_1\ne0$，均不是解，故排除。③中的后一向量甚至不是解。
- **组②**：两向量均为解（$AB=0$），但 $(2,-1,-1,0)^T=-\xi_3$，$r(B)=1\ne2$，线性相关，排除。
- **组①**：两向量为 $AB=0$（即 $A\xi_3=A\xi_4=0$），且 $r(B)=2=n-r(A)$，故 $B$ 的列构成基础解系。

三步里“都是解、个数满、线性无关”缺一不可：②错在无关、③④错在非解。
:::

::: info 例 3：由已知解反推含参矩阵
设
$$
A=\begin{pmatrix}1&2&a\\2&b&6\\c&2&3\end{pmatrix},
$$
且 $(1,1,1)^T$ 是齐次方程 $Ax=0$ 的解。求 $a,b,c$，并写出 $Ax=0$ 的通解。
:::

::: details 解析
$A(1,1,1)^T=0$ 等价于**每一行元素之和为零**：

$$
1+2+a=0\Rightarrow a=-3,\qquad
2+b+6=0\Rightarrow b=-8,\qquad
c+2+3=0\Rightarrow c=-5.
$$

于是 $A=\begin{pmatrix}1&2&-3\\2&-8&6\\-5&2&3\end{pmatrix}$。由左上二阶子式 $\begin{vmatrix}1&2\\2&-8\end{vmatrix}=-12\ne0$ 知 $r(A)\ge2$；又 $(1,1,1)^T$ 是解使 $r(A)\le3-1=2$，故 $r(A)=2$，基础解系只含一个向量，就是 $(1,1,1)^T$。通解

$$
X=t(1,\ 1,\ 1)^T.
$$

**注意题目措辞的差别**：若题设只说“$(1,1,1)^T$ 是解”，只能推出每行和为 $0$、$r(A)\le2$；要断言它就是基础解系（$r(A)=2$），还需补充“某个二阶子式非零”之类的秩信息。本题恰好由参数后的具体矩阵给出该信息。从列看，条件等价于三列之和为零向量 $\alpha_1+\alpha_2+\alpha_3=0$。
:::

## 8. 易错结论速查

| 说法 | 判断与说明 |
| --- | --- |
| 基础解系含 $n-r(A)$ 个向量，与方程个数 $m$ 无关 | 对；$m$ 只通过 $r(A)\le m$ 影响个数 |
| $Ax=0$ 有非零解 $\iff\det A=0$ | 只对**方阵**成立；一般矩阵的条件是 $r(A)<n$，即列向量线性相关 |
| 方程个数 $m<$ 未知量个数 $n$ 时，$Ax=0$ 必有非零解 | 对，因 $r(A)\le m<n$ |
| $s$ 个线性无关的解向量就构成基础解系 | 错，还须 $s=n-r(A)$；向量个数不满则不能张成整个解空间 |
| 列向量线性相关时，其中任一列都可由其余列表示 | 错，只能保证**存在**至少一列被其余列表示 |
| 基础解系向量必须线性无关且都是解 | 对，这是定义的一部分 |
| 基础解系唯一 | 错，不唯一，但任意两个基础解系张成同一解空间，所含向量个数相同 |
| 初等行变换后，原矩阵列之间的线性关系及系数不变 | 对；但变换后得到的列向量本身不是原矩阵的列 |
| 非主元列个数、自由未知量个数、基础解系向量个数三者相等 | 对，都等于 $n-r(A)$ |
| 若 $AB=0$，则 $r(A)+r(B)\le n$ | 对；$B$ 的列都是 $Ax=0$ 的解是原因 |
| 若 $\xi$ 是解，则 $\xi$ 与 $A$ 的每个行向量正交 | 对；$\xi=(1,\ldots,1)^T$ 时即“每行元素和为零” |
| $A$ 为 $n$ 阶方阵且 $r(A)=n-1$ 时，$A^*$ 的任一非零列即基础解系向量 | 对，因为 $AA^*=|A|I=0$ 且 $r(A^*)=1$ |

::: tip 一句话串主线
先算 $r(A)$ 定“应有多少个”解向量（$n-r(A)$），再验“每个是不是解”（等价于与各行正交，或打包成 $B$ 看 $AB=0$），最后看“线性无关”（$r(B)=$ 向量个数）。这三件事分别对应列向量组的**个数、关系、独立**三个层面。
:::

::: tip 链接到非齐次方程组
对非齐次 $Ax=b$，任意两解之差是 $Ax=0$ 的解，因此非齐次通解＝一个特解＋$Ax=0$ 的通解（基础解系的线性组合）。基础解系弄扎实了，非齐次“解的结构”题就只剩加特解这一步。
:::
