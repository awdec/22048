<h1><center>第五节 操作系统引导</center></h1>

## 1. 操作系统引导

::: info 例 1
计算机通电后，CPU 执行的第一段程序来自哪里？它是不是操作系统内核？
:::

::: details 解析
来自主板 ROM 中的 BIOS。CPU 上电后从规定位置取指，执行 BIOS 程序；BIOS 初始化基本硬件并建立中断向量表，为引导阶段的设备访问提供支持。BIOS 属于固件，不是操作系统内核，完整的进程、内存和设备管理要在内核运行后才建立。
:::

::: info 例 2
通电自检（POST）检测哪些部件？如果自检不通过，引导过程会怎样？
:::

::: details 解析
POST 检测 CPU、内存以及外设是否正常。若自检不通过，说明基本硬件存在故障，引导不会继续进入后续的启动设备选择和 MBR 加载阶段。
:::

::: info 例 3
BIOS 依据什么确定从哪台设备启动？该信息保存在哪里？
:::

::: details 解析
依据 CMOS 设置中的启动设备优先级。CMOS 是主板上由电池供电的配置存储器，用于保存启动顺序、系统时间等参数；BIOS 按启动顺序依次检查，并选择首个有效的启动设备。
:::

::: info 例 4
主引导记录（MBR）位于启动设备的什么位置？它包含哪两部分核心内容？
:::

::: details 解析
MBR 是所选启动设备的首扇区，由 BIOS 装入内存。它包含两部分核心内容：引导代码与硬盘分区表。
:::

::: info 例 5
一台硬盘可以有多个分区，MBR 中的引导代码如何确定应该继续引导哪个分区？
:::

::: details 解析
MBR 中的引导代码解析分区表，识别其中被标记为“活动”的分区，再装入该分区的首扇区，即分区引导记录（PBR）。因此需要先定位活动分区，才能继续引导。
:::

::: info 例 6
MBR 与 PBR 都位于磁盘的首类扇区，二者的作用和位置有何区别？
:::

::: details 解析
MBR 位于启动设备的首扇区，含引导代码与分区表，负责定位活动分区；PBR 位于活动分区的首扇区，负责加载该分区内的启动管理器。二者处于不同的层次，作用不能互换。
:::

::: info 例 7
开机后出现的多操作系统或内核版本选择菜单由哪个阶段提供？它由谁加载？
:::

::: details 解析
选择菜单由启动管理器提供，例如 Linux 的 GRUB、Windows 的 Bootmgr。启动管理器位于活动分区内，由 PBR 中的代码负责加载。
:::

::: info 例 8
内核映像被装入内存并跳转执行后，为什么说它“不再依赖 BIOS”？
:::

::: details 解析
内核跳转执行后完全接管系统控制权，并重建中断处理机制，此后不再使用 BIOS 提供的中断服务。需要注意的是，在跳转之前，读取内核映像仍然依赖 BIOS 或引导程序建立的设备访问能力。
:::

::: info 例 9
“BIOS 在引导阶段建立了中断向量表，所以内核运行期间继续使用 BIOS 的中断服务。”这一说法是否正确？
:::

::: details 解析
不正确。中断向量表是 BIOS 为引导阶段的设备访问建立的临时支持。内核接管控制权后会重建自己的中断处理机制，不再依赖 BIOS 提供的服务。
:::

::: info 例 10
内核初始化阶段，内存管理、进程调度和设备驱动三个模块各自建立哪些结构？
:::

::: details 解析
- 内存管理模块构建内核页表及用户进程地址空间框架。
- 进程调度模块初始化进程控制块（PCB）链表、就绪队列与阻塞队列。
- 设备驱动模块建立设备控制块、设备分配表以及 I/O 缓冲区管理结构。
:::

::: info 例 11
把“加载 PBR、执行 BIOS 初始化、加载启动管理器、执行 POST、加载 MBR”按正确顺序排列。
:::

::: details 解析
正确顺序为：

1. 执行 BIOS 初始化（CPU 从 ROM 读取并执行 BIOS）。
2. 执行 POST 并选择启动设备。
3. 加载 MBR。
4. 加载 PBR。
5. 加载启动管理器。
:::

::: info 例 12
“内核已装入内存”与“用户操作环境可用”之间还需要完成哪些工作？
:::

::: details 解析
内核还需完成核心子系统初始化：建立内存管理、进程调度和设备驱动所需的数据结构；初始化完成后启动首个用户态进程（如 Linux 的 init），由它逐步构建完整的用户操作环境。因此“内核已装入”“内核已接管”和“系统已可用”是三个不同阶段。
:::

### 答题技巧

- 记忆引导主线：通电 → BIOS 初始化 → POST 与选择启动设备 → MBR → PBR → 启动管理器 → 内核 → 首个用户态进程。
- 区分 MBR 与 PBR：MBR 在启动设备首扇区，含引导代码和分区表；PBR 在活动分区首扇区，负责加载启动管理器。
- CMOS 保存的是启动顺序、系统时间等配置参数，不是引导代码，也不是 MBR 的组成部分。
- 判断“是否还依赖 BIOS”时，看内核是否已跳转执行并重建中断处理机制。
