<h1><center>第五节 操作系统引导</center></h1>

## 1. 操作系统引导

::: info 例 1
计算机启动时，是操作系统内核先运行还是引导程序先运行？
:::

::: details 解析
固件最先执行并完成早期硬件初始化，随后装入引导程序；引导程序再把内核装入内存并移交控制权。内核完成初始化后才启动用户态服务。
:::

::: info 例 2
为什么最初执行的引导代码通常保存在 ROM 或闪存中？
:::

::: details 解析
主存断电后内容会丢失，开机时其中没有可直接执行的操作系统代码。ROM 或闪存属于非易失性存储器，可以保存固件，使处理器复位后有一段确定的代码可执行。
:::

::: info 例 3
引导程序为什么经常被划分为多个阶段？
:::

::: details 解析
固件最初能直接装入的代码大小和功能通常受限，因此先装入一个较小的引导阶段，再由它识别存储设备和文件系统、读取配置，并装入功能更完整的后续引导程序和内核。
:::

::: info 例 4
操作系统内核被装入内存后，系统是否已经可以直接运行普通用户程序？
:::

::: details 解析
通常还不可以。内核还需要初始化中断、内存管理、设备驱动和文件系统，创建首批系统进程并启动用户态服务，之后系统才进入正常可用状态。
:::

::: info 例 5
把“固件选择启动设备、内核创建首批系统进程、引导程序装入内核、CPU 从复位地址取指”按先后顺序排列。
:::

::: details 解析
正确顺序为：

1. CPU 从规定的复位地址取指并开始执行固件。
2. 固件初始化基本硬件并选择启动设备。
3. 引导程序定位并装入内核。
4. 内核完成必要初始化后创建首批系统进程。
:::

::: info 例 6
固件位于闪存、引导程序位于磁盘、内核运行于主存。三者中哪些必须断电后仍能保存？
:::

::: details 解析
固件和磁盘上的引导程序必须保存在非易失性介质中，断电后仍需存在；内核映像也通常长期保存在磁盘等非易失性设备上，但运行时的内核副本位于易失性主存，关机后可以丢失，下次启动时重新装入。
:::

::: info 例 7
为什么第一阶段引导程序通常不能像完整操作系统一样使用任意设备驱动和复杂文件系统功能？
:::

::: details 解析
此时内核尚未运行，完整驱动、内存管理和文件系统服务还不存在；固件能直接装入的初始代码空间也常受限制。因此第一阶段只能依靠固件服务或少量自带代码找到后续阶段，再由功能更完整的引导程序识别文件系统并装入内核。
:::

::: info 例 8
一台计算机安装了两个操作系统。用户开机后看到的系统选择菜单通常由哪个阶段提供？选择之后还要完成哪些主要步骤？
:::

::: details 解析
选择菜单通常由引导程序提供。用户选定系统后，引导程序读取相应配置，把所选内核及启动参数装入主存并移交控制权；内核随后初始化中断、内存、驱动和文件系统，创建系统进程并启动用户态服务。
:::

::: info 例 9
若引导程序已把完整内核映像读入主存，却在移交控制权前断电；再次开机时能否从主存中的该副本继续启动？说明完整恢复路径。
:::

::: details 解析
不能。普通主存是易失性的，断电后其中的内核副本丢失。再次开机时 CPU 仍从规定复位地址执行非易失性固件，由固件重新初始化硬件、选择启动设备并装入引导程序，再由引导程序重新读取内核，不能依赖上一次主存中的状态。
:::

### 答题技巧

- 启动顺序始终先判断“固件—引导程序—内核—首个用户态进程—系统服务”的控制权传递关系。
- 固件负责早期硬件环境，引导程序负责定位和装入内核，内核负责建立完整资源管理机制。
- “内核已经装入”“内核已经运行”和“系统已经可用”是三个不同阶段。
