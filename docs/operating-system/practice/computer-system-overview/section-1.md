<h1><center>第一节 操作系统的基本概念</center></h1>

::: info 例 1
单核计算机的两个进程能否并发？能否并行？
:::

::: details 解析
可以并发：两个进程在一段时间内交替推进。不能在同一时刻真正并行执行两条用户指令，因为单核同一时刻只能运行一个执行流。
:::

::: info 例 2
多个进程可以同时读取同一只读文件，这属于互斥共享还是同时共享？
:::

::: details 解析
属于同时共享。多个进程的读取操作在宏观上一段时间内共同发生，不要求对整个文件实行排他访问。
:::

::: info 例 3
时间片轮转主要体现操作系统的哪些基本特征？
:::

::: details 解析
首先体现并发：多个进程交替推进；也体现虚拟：每个进程都产生仿佛独占处理器的效果。时间片的分配还建立在处理器共享的基础上。
:::

::: info 例 4
操作系统作为资源管理者，主要管理哪几类资源？
:::

::: details 解析
主要管理处理机、存储器、文件和 I/O 设备，并通过进程管理、内存管理、文件管理和设备管理等功能协调这些资源的使用。
:::

::: info 例 5
调用 C 语言的数学库函数是否属于使用操作系统提供的程序接口？
:::

::: details 解析
不一定。操作系统的程序接口由系统调用组成。数学库函数如果只在用户态完成计算，就没有使用系统调用；只有库函数内部请求内核服务时，才通过程序接口进入操作系统。
:::
