<h1><center>第一节 操作系统的基本概念</center></h1>

::: info 例 1
为什么说操作系统既是系统软件，又是计算机系统的资源管理者？
:::

::: details 解析
操作系统为应用程序提供运行环境和公共服务，属于最基本的系统软件；它还要记录、分配、调度和回收处理机、存储器、文件及 I/O 设备等资源，并协调多个程序对资源的使用，因此也是系统资源的管理者。
:::

::: info 例 2
“操作系统就是内核”这一说法是否严谨？
:::

::: details 解析
不严谨。内核是操作系统的核心，通常包含中断处理、进程调度、内存管理和设备控制等特权功能；完整的操作系统还可能包含命令解释程序及其他配套系统程序。考试中应根据题目语境区分“内核功能”和“操作系统整体提供的功能”。
:::

::: info 例 3
从哪三个角度可以理解操作系统的作用？
:::

::: details 解析
1. 操作系统是处理机、存储器、文件和设备等资源的管理者。
2. 操作系统是用户、应用程序与计算机硬件之间的接口。
3. 操作系统隐藏硬件细节并提供更高级的抽象，是对裸机功能的扩充。
:::

::: info 例 4
进程调度、虚拟内存、目录管理和设备驱动分别属于操作系统的哪类资源管理功能？
:::

::: details 解析
- 进程调度属于处理机管理。
- 虚拟内存属于存储器管理。
- 目录管理属于文件管理。
- 设备驱动属于设备管理。

实际问题可能同时涉及多类功能，例如磁盘文件读写既涉及文件管理，也涉及设备管理和进程调度。
:::

::: info 例 5
用户在终端输入命令删除文件时，命令接口和程序接口分别在哪个环节发挥作用？
:::

::: details 解析
命令解释程序通过联机命令接口接收并解释用户命令；随后它通过文件删除相关的系统调用，请求内核修改目录和文件系统元数据。命令接口直接面向交互用户，程序接口面向请求操作系统服务的程序。
:::

::: info 例 6
调用 C 语言数学库函数是否一定使用了操作系统的程序接口？
:::

::: details 解析
不一定。操作系统的程序接口由系统调用组成。数学库函数如果只在用户态完成计算，就没有发出系统调用；只有库函数内部请求内核服务时，才会通过程序接口进入操作系统。因此，库函数、普通函数调用和系统调用不能画等号。
:::

::: info 例 7
单核计算机中的两个进程能否并发？能否并行执行处理器指令？
:::

::: details 解析
可以并发：两个进程在同一时间间隔内交替推进。不能在同一时刻并行执行两个处理器指令流，因为单核同一时刻只能执行一个指令流。若系统包含其他独立硬件，CPU 执行与设备 I/O 仍可能并行。
:::

::: info 例 8
打印机和可供多个进程读取的只读文件分别属于哪种共享方式？
:::

::: details 解析
一台未虚拟化的打印机在同一时刻通常只能由一个任务控制，属于互斥共享；多个进程读取只读文件不会相互修改数据，可以在同一时间段内共同访问，属于同时共享。
:::

::: info 例 9
时间片轮转主要体现了操作系统的哪些特征？
:::

::: details 解析
它首先体现并发：多个进程通过时间片交替推进；也体现共享：多个进程共同使用处理器；还体现虚拟：通过时分复用，每个进程都获得仿佛拥有独立处理器的效果。
:::

::: info 例 10
多个进程拥有彼此独立的虚拟地址空间，主要采用哪种复用思想？虚拟技术是否真正增加了物理内存？
:::

::: details 解析
虚拟地址空间主要体现空分复用和地址映射：系统把物理存储空间划分、组合并映射成各进程的逻辑地址空间。虚拟技术改变的是资源的组织和映射方式，不会凭空增加物理内存；需要的数据仍必须在物理内存与外存中保存。
:::

::: info 例 11
两个并发进程都执行 `x = x + 1`，共享变量 `x` 初值为 0，结果有时为 1、有时为 2。这体现了什么特征？为什么不能认为异步必然使结果不可重复？
:::

::: details 解析
两个进程以不可预知的速度推进，体现异步性。`x = x + 1` 通常包含读、修改和写回多个步骤，无同步保护时两次操作可能交叉，形成数据竞争，所以结果不确定。

异步只表示具体执行时序难以预知。若使用互斥锁保护更新，在相同输入下结果仍应稳定为 2；不确定结果来自错误的共享数据访问，而不是异步性的必然要求。
:::

::: info 例 12
为什么并发和共享被称为操作系统最基本、且互为存在条件的特征？
:::

::: details 解析
多个执行活动并发推进时，才产生协调共享资源的需要；反过来，处理机、内存和设备等资源能够被多个活动合理共享，多个活动才可能在同一系统中并发执行。虚拟通常以并发和共享为基础，异步则是多个活动并发推进时表现出的执行特征。
:::

## 答题技巧

- 回答操作系统作用时，可从“资源管理者、用户与硬件的接口、对硬件功能的扩充”三个角度组织。
- 区分接口时，用户通过命令或图形接口操作系统，应用程序通过系统调用请求内核服务。
- 区分并发与并行时，抓住“同一时间间隔”和“同一时刻”。
- 分析四个特征时，先判断是否有多个活动共同推进，再判断资源如何共享、是否使用虚拟技术以及执行时序是否可预测。
