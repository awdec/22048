<h1><center>第六节 虚拟机</center></h1>

## 1. 虚拟机的基本概念

::: info 例 1
第一类和第二类虚拟机监控程序的主要区别是什么？
:::

::: details 解析
第一类 VMM 直接运行在硬件上并管理客户操作系统；第二类 VMM 作为应用程序运行在宿主操作系统之上，需要通过宿主操作系统获得设备和资源服务。
:::

::: info 例 2
同一物理机上的多个虚拟机是否拥有完全独立的物理硬件？
:::

::: details 解析
不是。它们共享底层处理器、内存和 I/O 设备，但 VMM 为每个虚拟机提供相互隔离的虚拟硬件环境，使客户操作系统看到近似独立的计算机。
:::

::: info 例 3
虚拟机中的客户操作系统是否还需要经历引导过程？
:::

::: details 解析
需要。VMM 提供虚拟处理器、虚拟内存和虚拟设备，客户操作系统仍要在这套虚拟硬件上经过装入内核、内核初始化和启动用户态服务等过程。
:::

::: info 例 4
在第二类 VMM 中，“宿主操作系统”和“客户操作系统”分别扮演什么角色？
:::

::: details 解析
宿主操作系统直接管理物理机资源，并为作为应用程序运行的 VMM 提供服务；客户操作系统运行在 VMM 构造的虚拟硬件上，管理虚拟机内部的进程、内存和虚拟设备。客户操作系统不直接控制真实硬件。
:::

::: info 例 5
某虚拟化软件开机后直接管理硬件和多个客户系统；另一软件在桌面操作系统中以应用程序方式启动。二者分别属于哪一类 VMM？
:::

::: details 解析
前者直接运行在硬件上，属于第一类 VMM；后者依赖桌面宿主操作系统，属于第二类 VMM。分类依据是 VMM 与物理硬件之间是否存在通用宿主操作系统，而不是客户系统的种类。
:::

::: info 例 6
VMM 如何把一台物理机的处理器、内存和 I/O 设备提供给多个虚拟机使用？
:::

::: details 解析
VMM 调度各虚拟处理器使用物理处理器，并保存、恢复它们的运行状态；建立虚拟机内存到物理内存的映射并进行隔离；模拟或复用 I/O 设备，把客户系统的设备请求转换为对真实设备的受控访问。
:::

::: info 例 7
客户操作系统的内核认为自己处于特权状态，是否意味着它可以任意访问真实硬件和其他虚拟机的内存？
:::

::: details 解析
不能。客户内核的权限只适用于 VMM 提供的虚拟机环境；涉及受保护物理资源的操作仍由 VMM 截获或介入处理。VMM 维护资源映射和隔离边界，客户系统不能越过它访问其他虚拟机或任意控制真实硬件。
:::

::: info 例 8
虚拟机带来的主要优点和代价分别是什么？
:::

::: details 解析
主要优点是隔离不同运行环境、复用物理资源，并允许同一物理机运行多个客户操作系统；主要代价是处理器状态切换、内存映射和设备虚拟化会产生额外开销，多台虚拟机同时工作时还会竞争底层物理资源。
:::

### 答题技巧

- 判断第一类与第二类 VMM 时，只看 VMM 与硬件之间是否存在通用宿主操作系统。
- 区分宿主操作系统与客户操作系统：宿主系统服务于第二类 VMM，客户系统运行在虚拟硬件之上。
- 虚拟机在逻辑上相互隔离，但仍共享物理资源，因此“虚拟资源独立”不等于“物理硬件独占”。
