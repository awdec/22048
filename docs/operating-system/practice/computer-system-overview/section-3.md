<h1><center>第三节 操作系统的运行环境</center></h1>

::: info 例 1
缺页、时钟到时和系统调用分别属于哪类中断或异常？
:::

::: details 解析
- 缺页：由当前指令访存触发的故障，属于异常。
- 时钟到时：来自处理器外部的外中断。
- 系统调用：程序主动执行陷入指令，属于陷阱。
:::

::: info 例 2
应用程序能否直接执行关闭中断和设备 I/O 指令？
:::

::: details 解析
不能。这些是特权指令，只能在内核态执行。用户程序必须通过系统调用请求内核完成相关服务。
:::

::: info 例 3
发生外部中断后，处理器是否一定立即切换到另一个用户进程？
:::

::: details 解析
不一定。处理器先进入内核态执行中断处理程序，随后调度器根据事件和调度策略决定恢复原进程还是切换到其他进程。
:::

::: info 例 4
执行普通库函数一定会切换到内核态吗？
:::

::: details 解析
不一定。纯计算型库函数可以完全在用户态执行；只有库函数内部发起系统调用时，才会进入内核态。
:::

::: info 例 5
用户程序调用 `read` 读取磁盘文件，简述可能发生的模式和进程状态变化。
:::

::: details 解析
1. 用户程序执行封装 `read` 的库函数并发起系统调用。
2. 陷入指令使处理器由用户态进入内核态。
3. 若数据不在缓存，内核启动 I/O，当前进程由运行态转为阻塞态。
4. 磁盘完成后产生外中断，处理器进入内核态执行中断处理程序。
5. 原进程被唤醒进入就绪态，之后被调度运行并返回用户态。
:::

## 答题技巧

- 先判断事件来自当前指令内部还是处理器外部，再区分异常和外中断。
- 系统调用是程序接口，陷入指令是进入内核的实现机制。
- 处理器进入内核态不等于一定发生了进程切换。
