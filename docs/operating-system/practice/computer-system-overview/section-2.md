<h1><center>第二节 操作系统发展历程</center></h1>

::: info 例 1
单道批处理系统为什么不能充分利用处理机和外设的并行工作能力？
:::

::: details 解析
内存中只有一道作业。当该作业等待 I/O 时，没有其他作业可以占用处理机，处理机只能空闲，因此处理机和外设难以重叠工作。
:::

::: info 例 2
多道批处理系统的“多道、宏观并行、微观串行”分别表示什么？
:::

::: details 解析
“多道”表示内存中同时存放多道程序；“宏观并行”表示多道程序在一段时间内都在推进；单处理器上的“微观串行”表示每个时刻只能执行其中一道程序。
:::

::: info 例 3
多道批处理系统和分时系统的主要目标有何不同？
:::

::: details 解析
多道批处理系统主要追求资源利用率和系统吞吐量；分时系统主要追求交互性和及时响应，让多个终端用户感觉自己在独占计算机。
:::

::: info 例 4
分时系统能否替代硬实时系统完成必须在截止时间前结束的任务？
:::

::: details 解析
不能。分时系统追求平均意义上的及时响应，通常不保证严格截止时间；硬实时系统必须保证关键任务在规定时限内完成。
:::

::: info 例 5
多道程序技术为什么能够提高资源利用率？
:::

::: details 解析
不同作业对处理机和 I/O 设备的需求可以交错。当一道作业等待 I/O 时，处理机转去运行另一道作业，使处理机与外设并行工作，减少资源空闲时间。
:::
