<h1><center>第二节 操作系统的发展历程</center></h1>

::: info 例 1
手工操作阶段的主要矛盾是什么？为什么处理机利用率很低？
:::

::: details 解析
主要矛盾是人工操作速度远低于计算机处理速度。用户需要人工装入程序和数据、启动机器并取得结果，作业之间也要人工转换；处理机完成计算后经常等待人的下一步操作，因此大量时间处于空闲状态。
:::

::: info 例 2
脱机输入/输出为什么能提高主机利用率？它本身是否已经构成完整的操作系统？
:::

::: details 解析
外围机可以预先把程序和数据从低速设备送入磁带等高速介质，主机不必直接等待低速输入；输出也可先写入高速介质，再由外围机处理。这样把低速 I/O 与主机计算分离，提高了主机利用率。

脱机输入/输出只是一种组织 I/O 的技术，本身不具备完整的资源管理、调度和接口功能，因此不能等同于操作系统。
:::

::: info 例 3
单道批处理系统为什么仍不能充分发挥处理机与外设的并行工作能力？
:::

::: details 解析
内存中始终只有一道作业。当该作业等待 I/O 时，没有其他就绪作业可以占用处理机，处理机只能空闲。因此，虽然作业之间实现了自动转换，但一道作业内的计算与 I/O 等待仍使处理机利用率受到限制。
:::

::: info 例 4
多道批处理系统的“多道、宏观并行、微观串行”分别表示什么？
:::

::: details 解析
- 多道表示内存中同时驻留多道程序。
- 宏观并行表示多道程序在同一时间段内都在向前推进。
- 单处理器上的微观串行表示任一时刻只能执行其中一道程序。

“宏观并行”在这里描述的本质是并发，不代表单处理器能在同一时刻执行多道程序。
:::

::: info 例 5
一道作业独占系统时有 $80\%$ 的时间等待 I/O。若三个相互独立且等待比例相同的作业同时驻留内存，按理想概率模型估算处理器利用率。
:::

::: details 解析
只有三个作业同时等待 I/O 时，处理器才空闲。按独立性假设，处理器空闲概率为：

$$
0.8^3=0.512.
$$

因此处理器利用率约为：

$$
1-0.512=0.488=48.8\%.
$$

单道时利用率仅约为 $20\%$。该模型用于说明增加多道程序能够减少处理器空闲，实际结果还受调度、内存容量和资源竞争影响。
:::

::: info 例 6
多道批处理系统和分时系统都允许多道程序并发，它们的主要目标为什么不同？
:::

::: details 解析
多道批处理系统主要通过在作业间切换提高资源利用率和系统吞吐量，用户提交作业后通常不能直接交互；分时系统通过较短时间片轮流服务多个终端用户，主要追求交互性和较短响应时间。
:::

::: info 例 7
分时系统的同时性、交互性、独立性和及时性分别表示什么？
:::

::: details 解析
- 同时性：多个终端用户在同一时间段内共同使用系统。
- 交互性：用户能够输入命令并获得反馈。
- 独立性：各用户感觉自己独立使用计算机，彼此操作互不干扰。
- 及时性：系统在用户可以接受的时间内响应请求。
:::

::: info 例 8
分时操作系统能否替代硬实时系统完成必须在截止时间前结束的任务？
:::

::: details 解析
不能。分时系统追求一般意义上的较快响应，通常不提供严格的最坏响应时间保证；硬实时系统必须保证关键任务在截止时间前完成，否则可能造成系统失败或严重后果。
:::

::: info 例 9
视频播放偶尔出现一帧延迟与汽车安全气囊未在规定时间触发，分别属于哪类实时要求？
:::

::: details 解析
视频播放通常属于软实时场景，偶尔错过截止时间会降低体验，但一般不会导致整个系统失败；安全气囊控制属于硬实时场景，关键任务必须在截止时间前完成，否则可能造成严重后果。
:::

::: info 例 10
网络操作系统和分布式操作系统在用户看到的资源视图上有什么主要区别？
:::

::: details 解析
网络操作系统连接多台相对独立的计算机，用户通常知道远程资源所在的主机，并显式访问该资源；分布式操作系统统一或协同管理分散资源，尽量隐藏资源位置、迁移和复制等细节，对用户表现为一个整体系统。

因此，能够进行网络通信和远程文件访问，并不自动意味着系统具有分布透明性。
:::

::: info 例 11
单用户单任务、单用户多任务和多用户多任务微机操作系统有何区别？
:::

::: details 解析
- 单用户单任务系统一次只允许一个用户运行一个任务。
- 单用户多任务系统允许一个用户同时运行多个应用程序。
- 多用户多任务系统允许多个用户通过不同终端或会话共同使用系统，并让多项任务并发运行。

现代微机操作系统通常支持多任务，并可能同时具有多用户、网络和图形界面功能。
:::

::: info 例 12
多道批处理系统为什么被认为是现代操作系统并发管理的基础？
:::

::: details 解析
内存中同时存在多道程序后，系统必须决定何时切换程序、把处理机分给谁、如何分配内存和设备，以及怎样防止程序相互破坏。这促使处理机调度、内存管理、I/O 管理和资源保护等机制形成，也为分时和实时系统管理多个并发任务奠定了基础。
:::

::: info 例 13
医院批量影像处理、在线命令终端和汽车制动控制分别最重视哪类操作系统目标？
:::

::: details 解析
- 批量影像处理通常重视吞吐量和资源利用率，体现批处理思想。
- 在线命令终端重视交互性和响应时间，体现分时系统思想。
- 汽车制动控制必须满足严格截止时间，属于硬实时场景。

现实操作系统可以同时吸收多种系统形态的设计思想，分类表示主要目标，不表示功能必须互斥。
:::

::: info 例 14
某工业控制机既要保证制动任务在 $5\text{ ms}$ 内完成，又要为操作员提供交互界面。只采用普通分时轮转能否满足要求？
:::

::: details 解析
不能只依赖普通分时轮转。制动任务需要具有可分析最坏响应时间的硬实时调度机制，并获得足够高的优先级和所需资源；界面任务可以采用分时策略，但不得干扰制动任务的截止时间。该系统同时包含实时和分时需求，应按任务性质分别提供保证。
:::

## 答题技巧

- 判断发展阶段时，先看系统主要解决的是人工操作、资源利用率、交互响应还是截止时间问题。
- 单道与多道批处理的关键区别是内存中能否同时驻留多道作业。
- 分时与实时的关键区别是“用户可接受的及时响应”与“必须满足的时间约束”。
- 网络操作系统强调连接和共享，分布式操作系统强调统一管理与分布透明性。
- 微机操作系统的“微机”描述运行平台，不代表它只能是单用户单任务系统。
