<h1><center>第二节 CPU 调度</center></h1>

::: info 例 1：调度层次
高级调度、中级调度和低级调度分别负责什么？CPU 调度通常指哪一种？
:::

::: details 解析
高级调度从外存后备队列选择作业进入内存；中级调度通过挂起和激活调整内存中的进程数量；低级调度从就绪队列选择进程或线程使用 CPU。CPU 调度通常指低级调度。
:::

::: info 例 2：调度时机
哪些事件可能触发调度？运行进程主动请求 I/O 与时间片用完，哪个属于抢占？
:::

::: details 解析
进程终止、主动阻塞、I/O 完成使进程就绪、时间片用完、更高优先级进程到达等都可能触发调度。主动请求 I/O 是主动放弃 CPU，不属于抢占；时间片用完属于抢占式调度的典型时机。
:::

::: info 例 3：FCFS 指标计算
进程 $P_1,P_2,P_3$ 的到达时间分别为 $0,1,2$，服务时间分别为 $4,3,1$。按 FCFS 调度，求各进程的周转时间、等待时间及两项平均值。
:::

::: details 解析
执行序列为：
$$
P_1(0\sim4)\rightarrow P_2(4\sim7)\rightarrow P_3(7\sim8).
$$

| 进程 | 周转时间 | 等待时间 |
| --- | ---: | ---: |
| $P_1$ | $4-0=4$ | $4-4=0$ |
| $P_2$ | $7-1=6$ | $6-3=3$ |
| $P_3$ | $8-2=6$ | $6-1=5$ |

平均周转时间为 $16/3$，平均等待时间为 $8/3$。
:::

::: info 例 4：SJF
三个进程同时到达，服务时间分别为 $6,2,4$。按非抢占 SJF 调度，求平均周转时间。
:::

::: details 解析
执行顺序为 $2\rightarrow4\rightarrow6$。完成时间分别为 $2,6,12$，到达时间均为 $0$，平均周转时间为：
$$
\frac{2+6+12}{3}=\frac{20}{3}.
$$
:::

::: info 例 5：SRTF
进程 $P_1,P_2,P_3$ 的“到达时间/服务时间”分别为 $0/7,2/4,4/1$。采用 SRTF，画出执行序列并求平均等待时间。
:::

::: details 解析
$P_1$ 先运行；$t=2$ 时 $P_2$ 的服务时间 4 小于 $P_1$ 的剩余时间 5，发生抢占；$t=4$ 时 $P_3$ 的服务时间 1 小于 $P_2$ 的剩余时间 2，再次抢占。

$$
P_1(0\sim2)\rightarrow P_2(2\sim4)\rightarrow
P_3(4\sim5)\rightarrow P_2(5\sim7)\rightarrow P_1(7\sim12).
$$

等待时间分别为 $5,1,0$，平均等待时间为 $2$。
:::

::: info 例 6：HRRN
某次调度时，作业 A 已等待 8、服务时间为 4；B 已等待 4、服务时间为 1；C 已等待 10、服务时间为 10。HRRN 选择哪个作业？
:::

::: details 解析
$$
R_A=\frac{8+4}{4}=3,\qquad
R_B=\frac{4+1}{1}=5,\qquad
R_C=\frac{10+10}{10}=2.
$$
选择响应比最大的 B。HRRN 同时考虑等待时间和服务时间，等待过久的长作业响应比会逐渐上升。
:::

::: info 例 7：时间片轮转
进程 $P_1$ 在时刻 0 到达、服务时间为 5；$P_2$ 在时刻 1 到达、服务时间为 3。时间片为 2，忽略切换开销，求 RR 执行序列以及各进程的周转、等待和响应时间。
:::

::: details 解析
$$
P_1(0\sim2)\rightarrow P_2(2\sim4)\rightarrow
P_1(4\sim6)\rightarrow P_2(6\sim7)\rightarrow P_1(7\sim8).
$$

- $P_1$：周转时间 $8$，等待时间 $8-5=3$，响应时间 $0$。
- $P_2$：周转时间 $7-1=6$，等待时间 $6-3=3$，响应时间 $2-1=1$。

平均周转时间为 7，平均等待时间为 3，平均响应时间为 $0.5$。
:::

::: info 例 8：优先级与老化
为何优先级调度可能使低优先级进程饥饿？如何缓解？
:::

::: details 解析
若高优先级进程持续到达，低优先级进程可能一直无法获得 CPU。可使用老化机制：随着等待时间增长，逐步提高进程优先级，确保其最终能得到服务。
:::

::: info 例 9：多级反馈队列
两级反馈队列中，$Q_0$ 时间片为 2，$Q_1$ 时间片为 4；新进程进入 $Q_0$，用完整个时间片仍未完成则降入 $Q_1$。$P_1,P_2,P_3$ 同时到达，服务时间依次为 $1,5,8$。求完成时间。
:::

::: details 解析
$Q_0$ 中：$P_1$ 在 $0\sim1$ 完成；$P_2$ 在 $1\sim3$ 运行后剩余 3；$P_3$ 在 $3\sim5$ 运行后剩余 6。随后 $Q_1$ 中：$P_2$ 在 $5\sim8$ 完成，$P_3$ 在 $8\sim14$ 完成。因此完成时间依次为 $1,8,14$。
:::

::: info 例 10：进程切换
一次系统调用从用户态进入内核态，是否一定发生进程切换？进程切换的主要开销来自哪里？
:::

::: details 解析
不一定，系统调用后可能仍回到原进程继续执行。进程切换需保存和恢复寄存器、程序计数器、栈指针等上下文，更新 PCB 和队列，必要时更换地址空间；同时还会影响缓存和 TLB，因此会产生开销。
:::

::: info 例 11：多处理机调度
公共就绪队列与每处理器私有就绪队列各有什么主要优缺点？
:::

::: details 解析
公共队列让所有处理器共享任务来源，易于负载均衡，但并发访问队列会有锁竞争。私有队列本地访问快、处理器亲和性好，却可能出现某些处理器繁忙而另一些空闲，需要适时迁移任务来均衡负载。
:::

::: info 例 12：调度安全点
时钟中断到达时，内核正在修改必须保持一致的就绪队列。系统是否应在该修改过程中立即切换进程？
:::

::: details 解析
不应立即切换。就绪队列属于需要互斥保护的内核临界数据结构，在修改完成前切换可能破坏其一致性。内核应记录重新调度请求，完成原子操作或退出临界区后，再在安全调度点执行切换。
:::
