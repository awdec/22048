<h1><center>第一节 内存管理概念</center></h1>

::: info 例 1
某进程的基址寄存器为 $12000$，界限寄存器为 $4000$。逻辑地址 $3500$ 和 $4500$ 的访问结果分别是什么？
:::

::: details 解析
$3500<4000$，地址合法，物理地址为：
$$
12000+3500=15500.
$$
$4500\ge4000$，超出进程地址范围，触发越界异常。
:::

::: info 例 2
动态分区产生许多分散的小空闲区，属于什么碎片？如何缓解？
:::

::: details 解析
属于外部碎片。可通过紧凑移动已分配分区，把空闲空间合并为连续区域，但需要动态重定位支持并产生移动开销。
:::

::: info 例 3
最佳适应算法为什么不一定“最佳”？
:::

::: details 解析
它每次选择最小可满足空闲区，容易留下大量难以利用的小碎片；“最佳”只描述当次剩余空间最小，不保证长期整体利用率最佳。
:::

::: info 例 4
页面大小为 $1\text{ KB}$，逻辑地址为 $2500$，求页号和页内偏移。
:::

::: details 解析
$1\text{ KB}=1024$ 字节：
$$
p=\left\lfloor\frac{2500}{1024}\right\rfloor=2,
\qquad
w=2500-2\times1024=452.
$$
:::

::: info 例 5
上题中页 $2$ 位于页框 $7$，求物理地址。
:::

::: details 解析
$$
PA=7\times1024+452=7620.
$$
:::

::: info 例 6
TLB 查询时间为 $10\text{ ns}$，内存访问时间为 $100\text{ ns}$，命中率为 $90\%$。忽略缺页，求有效访问时间。
:::

::: details 解析
命中需 $10+100=110\text{ ns}$，未命中需 $10+200=210\text{ ns}$：
$$
EAT=0.9\times110+0.1\times210=120\text{ ns}.
$$
:::

::: info 例 7
分页和分段中，哪一种更方便按逻辑模块共享和保护？
:::

::: details 解析
分段。段由程序的逻辑模块构成，段表项可按模块设置长度与权限；页是系统等长划分的物理管理单位，对用户通常不可见。
:::

::: info 例 8
某分页系统逻辑地址为 $16$ 位，页面大小为 $1\text{ KB}$，页表项为 $4$ 字节。求逻辑页数和单级页表大小。
:::

::: details 解析
逻辑地址空间大小为 $2^{16}=64\text{ KB}$，每页 $2^{10}$ 字节，因此共有 $2^{16-10}=64$ 页，单级页表大小为：
$$
64\times4=256\text{ B}.
$$
:::

::: info 例 9
页面大小为 $4\text{ KB}$，一个进程大小为 $18\text{ KB}$，采用纯分页时实际产生多少内部碎片？
:::

::: details 解析
该进程需要 $5$ 页，共占用 $20\text{ KB}$，实际内部碎片为：
$$
20-18=2\text{ KB}.
$$
:::

## 答题技巧

- 地址题先统一字节单位，再拆分页号和页内偏移。
- 分清逻辑地址、页框号和最终物理地址。
- 多级页表题要明确各级索引位数和地址转换的访存次数。
