<h1><center>第一节 内存管理概念</center></h1>

::: info 例 1：动态重定位
某进程的基址寄存器为 $12000$，界限寄存器为 $4000$。逻辑地址 $3500$ 和 $4500$ 的访问结果分别是什么？
:::

::: details 解析
$3500<4000$，地址合法，物理地址为：
$$
12000+3500=15500.
$$
$4500\ge4000$，超出进程地址范围，触发越界异常。
:::

::: info 例 2：重定位方式
为什么静态重定位后的进程在运行期间通常不能移动，而动态重定位可以？
:::

::: details 解析
静态重定位在装入时一次性把逻辑地址修改为物理地址，运行过程中没有持续的地址转换机制；进程移动后，原地址将失效。动态重定位在每次访存时由 MMU 根据当前映射关系转换地址，只要更新基址寄存器或地址映射表，就可以把进程移动到新位置。
:::

::: info 例 3：连续分配与碎片
固定分区与动态分区分别主要产生什么碎片？动态分区的紧凑操作需要什么支持？
:::

::: details 解析
固定分区中，进程未用满分区的空间形成内部碎片；动态分区中，分散在已分配分区之间的小空闲区形成外部碎片。紧凑需要移动进程并更新地址映射，因此必须得到动态重定位支持。
:::

::: info 例 4：动态分区算法
空闲分区按地址递增排列，大小依次为 $100,500,200,300,600\text{ KB}$。现申请 $212\text{ KB}$，首次适应、最佳适应和最坏适应分别选择哪个分区？
:::

::: details 解析
- 首次适应选择第一个足够大的 $500\text{ KB}$ 分区。
- 最佳适应选择能够满足要求的最小分区，即 $300\text{ KB}$。
- 最坏适应选择最大的 $600\text{ KB}$ 分区。

算法名称描述的是本次选择规则，并不意味着长期内存利用率一定最优或最差。
:::

::: info 例 5：分页地址拆分
页面大小为 $1\text{ KB}$，逻辑地址为 $2500$，求页号和页内偏移。
:::

::: details 解析
$1\text{ KB}=1024$ 字节：
$$
p=\left\lfloor\frac{2500}{1024}\right\rfloor=2,
\qquad
w=2500-2\times1024=452.
$$
:::

::: info 例 6：分页地址转换
上题中的页 $2$ 位于页框 $7$，求物理地址。
:::

::: details 解析
页内偏移在地址转换中保持不变：
$$
PA=7\times1024+452=7620.
$$
:::

::: info 例 7：页表大小
某分页系统逻辑地址为 $16$ 位，页面大小为 $1\text{ KB}$，页表项为 $4$ 字节。求逻辑页数和单级页表大小。
:::

::: details 解析
页面大小为 $2^{10}$ 字节，页内偏移占 10 位，页号占 $16-10=6$ 位，因此共有 $2^6=64$ 页。单级页表大小为：
$$
64\times4=256\text{ B}.
$$
:::

::: info 例 8：分页内部碎片
页面大小为 $4\text{ KB}$，一个进程大小为 $18\text{ KB}$。采用基本分页时分配多少页框，实际产生多少内部碎片？
:::

::: details 解析
进程需要：
$$
\left\lceil\frac{18}{4}\right\rceil=5
$$
个页框，共占用 $20\text{ KB}$，内部碎片为：
$$
20-18=2\text{ KB}.
$$
:::

::: info 例 9：TLB 有效访问时间
TLB 查询时间为 $10\text{ ns}$，内存访问时间为 $100\text{ ns}$，命中率为 $90\%$。TLB 与内存串行查询，忽略缺页，求有效访问时间。
:::

::: details 解析
命中需要 $10+100=110\text{ ns}$，未命中需要 $10+2\times100=210\text{ ns}$：
$$
EAT=0.9\times110+0.1\times210=120\text{ ns}.
$$
若题目规定 TLB 与内存并行查询，则需使用题目对应的时间模型，不能直接套用该公式。
:::

::: info 例 10：二级页表
某系统采用 32 位逻辑地址、$4\text{ KB}$ 页面和二级页表，页表项为 $4$ 字节，每张下级页表恰好占一页。对地址 `0x12345678`，求一级索引、二级索引和页内偏移；TLB 未命中且页表均驻留内存时，取得数据需访存几次？
:::

::: details 解析
$4\text{ KB}=2^{12}\text{ B}$，页内偏移占 12 位。每页可容纳 $2^{12}/4=2^{10}$ 个页表项，因此两级索引各占 10 位。

$$
\text{一级索引}=VA\gg22=\texttt{0x48},
$$

$$
\text{二级索引}=(VA\gg12)\mathbin{\&}\texttt{0x3FF}
=\texttt{0x345},
$$

$$
\text{页内偏移}=VA\mathbin{\&}\texttt{0xFFF}
=\texttt{0x678}.
$$

需要依次访问一级页表、二级页表和目标数据，共 3 次访存。
:::

::: info 例 11：分段地址转换
某进程段表如下。逻辑地址 $\langle1,600\rangle$ 是否合法？若合法，求物理地址。

| 段号 | 段基址 | 段长 |
| --- | ---: | ---: |
| 0 | 1000 | 500 |
| 1 | 4000 | 800 |
| 2 | 9000 | 300 |
:::

::: details 解析
段号 1 合法，段内偏移满足 $600<800$，因此物理地址为：
$$
4000+600=4600.
$$
若逻辑地址为 $\langle1,800\rangle$，则偏移等于段长，已经越界；合法范围是 $0\le d<800$。
:::

::: info 例 12：分页与分段
分页和分段中，哪一种更方便按完整逻辑模块共享和保护？两者主要分别产生什么碎片？
:::

::: details 解析
分段更方便。段与程序的逻辑模块对应，可按段设置长度和访问权限。分页主要在最后一页产生内部碎片；分段由于各段长度可变、物理分区大小不等，主要产生外部碎片。
:::

::: info 例 13：段页式地址转换
某段页式系统页面大小为 $1\text{ KB}$。逻辑地址为 $\langle2,3,100\rangle$，表示段号 2、段内页号 3、页内偏移 100。查段表和该段页表得知该页位于页框 9，求物理地址。
:::

::: details 解析
段号和页号用于查表，页内偏移保持不变：
$$
PA=9\times1024+100=9316.
$$
地址转换前还必须检查段号、段内页号和访问权限是否合法。
:::

::: info 例 14：段页式访存次数
段页式系统没有 TLB，段表和页表均驻留内存。访问一个逻辑地址对应的数据通常需要几次访存？
:::

::: details 解析
通常需要 3 次：第一次访问段表，取得该段页表的起始地址；第二次访问页表，取得页框号；第三次访问目标数据。若使用快表并命中最终映射，可减少查表访存。
:::

::: info 例 15：动态分区回收与合并
某动态分区内存当前从低地址到高地址依次为：已分配区 A（起址 0、大小 100）、空闲区（起址 100、大小 100）、已分配区 B（起址 200、大小 200）、空闲区（起址 400、大小 200）、已分配区 C（起址 600、大小 200）、空闲区（起址 800、大小 200）。释放 B 后空闲分区如何变化？随后按首次适应算法申请 180 个地址单位，又如何分配？
:::

::: details 解析
释放 B 后，其前方空闲区 $[100,199]$ 和后方空闲区 $[400,599]$ 都与 B 的区域 $[200,399]$ 相邻，因此三者合并为：

```text
起始地址 100，大小 500
```

原来的高地址空闲区保持为：

```text
起始地址 800，大小 200
```

首次适应从低地址开始查找，申请 180 个地址单位时从起址 100 的空闲区中分配 $[100,279]$，剩余空闲区为：

```text
起始地址 280，大小 320
起始地址 800，大小 200
```

动态分区回收时要分别检查前邻接、后邻接和前后同时邻接三种合并情形。
:::

## 答题技巧

- 地址题先统一字节单位，再判断地址由哪几部分构成。
- 连续分配先做界限检查，再用基址加逻辑地址。
- 分页先拆分页号与页内偏移；分段必须同时检查段号和段内偏移。
- 多级页表和段页式题要明确查表层数、索引位数和访存次数。
- TLB 未命中不等于缺页，基本分页与请求分页不要混淆。
