<h1><center>第三节 文件系统</center></h1>

::: info 例 1：磁盘布局
超级块、inode 区和文件数据区分别保存什么？挂载时为什么通常要先读取超级块？
:::

::: details 解析
超级块保存文件系统类型、容量、块大小和关键区域位置等全局信息；inode 区保存文件元数据及数据块定位信息；数据区保存文件和目录的实际内容。挂载时必须先读取和验证超级块，才能识别文件系统并定位其他区域。
:::

::: info 例 2：外存与内存结构
超级块、系统打开文件表和进程文件描述符表中，哪些需要持久化，哪些属于运行时结构？
:::

::: details 解析
磁盘超级块是持久化结构；挂载后系统会在内存中建立超级块对象或缓存。系统打开文件表和进程文件描述符表属于运行时结构，只在文件被打开和进程运行期间存在。
:::

::: info 例 3：位示图大小
磁盘共有 $2^{20}$ 个块，位示图至少需要多少空间？
:::

::: details 解析
每个磁盘块需要一位：
$$
2^{20}\text{ bit}=2^{17}\text{ B}=128\text{ KB}.
$$
:::

::: info 例 4：位示图比例
一个容量为 $8\text{ GiB}$ 的卷采用 $4\text{ KiB}$ 磁盘块。位示图至少占多少空间？约占卷容量的百分之几？
:::

::: details 解析
磁盘块数为：
$$
\frac{2^{33}}{2^{12}}=2^{21}.
$$
位示图大小为：
$$
2^{21}\text{ bit}=2^{18}\text{ B}=256\text{ KiB}.
$$
占卷容量的比例约为：
$$
\frac{2^{18}}{2^{33}}\times100\%
=\frac{1}{2^{15}}\times100\%
\approx0.00305\%.
$$
:::

::: info 例 5：位示图定位
位示图按磁盘块号从 0 开始编号，每个机器字有 32 位。磁盘块 2050 对应第几个机器字和字内第几位？编号均从 0 开始。
:::

::: details 解析
$$
2050=64\times32+2.
$$
因此它位于第 64 个机器字的第 2 位。分配或回收该块时应原子地修改相应位，防止同一空闲块被重复分配。
:::

::: info 例 6：空闲空间管理方法
系统需要频繁寻找长度至少为 100 块的连续空闲区。空闲表法和按块空闲链表法中，哪一种通常更合适？
:::

::: details 解析
空闲表法通常更合适。每个表项直接记录连续空闲区的起始块号和长度，可以按长度查找满足要求的区间。按块空闲链表适合取得单个空闲块，但判断并取得大量连续块通常需要较多遍历和检查。
:::

::: info 例 7：成组链接法
成组链接法为什么比“把所有空闲块号都保存在内存中”更节省内存？取得下一组空闲块号时可能发生什么？
:::

::: details 解析
内存中只需保存当前一组空闲块号，而其余组的信息分散保存在特定空闲块中，因此无需让全部空闲块号长期驻留内存。当前组用完后，系统读取保存下一组信息的磁盘块，把新的空闲块号装入内存。
:::

::: info 例 8：VFS
为什么同一个 `open` 接口可以访问不同类型的本地或网络文件系统？
:::

::: details 解析
VFS 向系统调用层提供统一抽象，再根据路径和挂载信息把操作分派给具体文件系统。不同文件系统只需实现 VFS 约定的相应操作，应用程序不必了解其磁盘或网络格式。
:::

::: info 例 9：VFS 对象
目录项对象、inode/vnode 对象和文件对象分别表示什么？文件偏移通常保存在哪一类对象中？
:::

::: details 解析
目录项对象表示路径中的文件名及其与 inode/vnode 的关联；inode/vnode 表示具体文件对象的元数据和操作；文件对象表示一次打开实例。当前文件偏移属于打开实例的状态，通常保存在文件对象或系统打开文件表项中。
:::

::: info 例 10：挂载点
把一个文件系统挂载到非空目录后，访问该目录会看到什么？原有内容是否被删除？
:::

::: details 解析
路径解析到该目录时会进入被挂载文件系统，看到其根目录内容。挂载点原有内容只是暂时被遮蔽，没有被删除；卸载后通常可以再次访问。
:::

::: info 例 11：格式化、VFS 与挂载
格式化、VFS 和挂载分别解决什么问题？
:::

::: details 解析
- 格式化在卷上建立超级块、空闲空间结构、inode/FCB 区等文件系统布局。
- VFS 为不同具体文件系统提供统一接口和公共对象抽象。
- 挂载把某个已经存在的文件系统接入当前目录树中的挂载点。

三者分别属于“建立磁盘格式”“统一访问接口”和“接入命名空间”。
:::

## 答题技巧

- 位示图题先求磁盘块数，再由“每块一位”换算空间。
- 块号定位题注意题目规定机器字和位号是否从 0 编号。
- 超级块描述整个文件系统，inode/FCB 描述单个文件，打开文件表描述一次打开状态。
- VFS 解决统一接口，挂载解决接入目录树，格式化负责建立磁盘布局。
