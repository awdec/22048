<h1><center>第三节 文件系统</center></h1>

::: info 例 1
磁盘共有 $2^{20}$ 个块，位示图至少需要多少空间？
:::

::: details 解析
每个磁盘块占一位：
$$
2^{20}\text{ bit}=2^{17}\text{ B}=128\text{ KB}.
$$
:::

::: info 例 2
为什么同一个 `open` 接口可以访问不同类型的文件系统？
:::

::: details 解析
VFS 向系统调用层提供统一抽象，再把操作转发给具体文件系统的实现。不同文件系统只需按照 VFS 约定实现相应操作，应用程序不必了解其磁盘布局。
:::

::: info 例 3
把一个文件系统挂载到非空目录后，访问该目录会看到什么？
:::

::: details 解析
该目录成为挂载点，路径解析会进入被挂载文件系统；原目录中的内容暂时被遮蔽，但没有被删除，卸载后可以再次访问。
:::

::: info 例 4
文件系统卸载前为什么要检查文件是否仍在使用并写回脏数据？
:::

::: details 解析
仍在使用的文件可能存在未完成操作或有效引用，脏数据也可能只保存在内存中。直接卸载会造成访问失效或磁盘数据不一致，因此系统通常拒绝忙碌的卸载请求，并先完成必要的写回。
:::

::: info 例 5
超级块通常保存哪些信息？
:::

::: details 解析
超级块保存文件系统类型、卷容量、块大小、空闲空间状态以及 inode 区和数据区位置等全局元数据，是文件系统挂载和管理的重要依据。
:::

## 答题技巧

- 位示图题先求磁盘块总数对应的位数，再换算为字节。
- VFS 解决统一接口问题，挂载解决文件系统接入目录树的问题。
