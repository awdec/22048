<h1><center>第一节 文件系统基础</center></h1>

::: info 例 1
哪种文件分配方式最适合高效随机访问？连续分配的主要代价是什么？
:::

::: details 解析
连续分配可由起始块号直接计算任意逻辑块的位置，随机访问效率高；主要代价是产生外部碎片、文件增长困难，并可能需要预先知道文件大小。
:::

::: info 例 2
磁盘块大小为 $1\text{ KB}$，块号占 $4$ 字节，一个一级间接索引块可指向多少数据块？
:::

::: details 解析
一个索引块可以保存：
$$
\frac{1024}{4}=256
$$
个块号，因此可指向 $256$ 个数据块，对应 $256\text{ KB}$ 的文件数据。
:::

::: info 例 3
某 inode 有 $10$ 个直接地址和一个一级间接地址，块大小为 $4\text{ KB}$，块号占 $4$ 字节，最大文件大小是多少？
:::

::: details 解析
一个间接索引块可保存 $4096/4=1024$ 个块号，总数据块数为：
$$
10+1024=1034.
$$
最大文件大小为：
$$
1034\times4\text{ KB}=4136\text{ KB}.
$$
:::

::: info 例 4
某文件只采用二级索引分配，块大小为 $1\text{ KB}$，每个块号占 $4$ 字节。最大文件大小是多少？
:::

::: details 解析
每个索引块可保存 $1024/4=256$ 个块号，二级索引可定位 $256^2$ 个数据块，因此最大文件大小为：
$$
256^2\times1\text{ KB}=64\text{ MB}.
$$
:::

::: info 例 5
访问两级索引文件的某个数据块，若 inode 已在内存、两个索引块和数据块均未缓存，至少需要几次磁盘访问？
:::

::: details 解析
需要依次读取一级索引块、二级索引块和目标数据块，共 $3$ 次磁盘访问。
:::

::: info 例 6
对一个已打开文件执行定位操作，是否会直接读取或修改文件内容？写入超过原文件末尾时，文件长度是否可能改变？
:::

::: details 解析
定位操作只修改当前文件位置指针，本身不读写文件内容。随后若从该位置写入并超过原文件末尾，系统会分配所需空间，文件长度相应增加。
:::

## 答题技巧

- 先计算一个索引块能够保存多少块号。
- 最大文件大小只统计数据块容量，不把索引块本身计入文件数据。
- 注意区分文件的逻辑结构、物理结构和访问方式。
- 打开文件会建立运行时表项；定位只改变文件位置指针，不等于实际读写。
