<h1><center>第三节 磁盘和固态硬盘</center></h1>

::: info 例 1
磁头当前位于磁道 $50$，请求序列为 $55,58,39,18$。按 FCFS 计算总移动磁道数。
:::

::: details 解析
$$
|55-50|+|58-55|+|39-58|+|18-39|
=5+3+19+21=48.
$$
:::

::: info 例 2
对上题采用 SSTF，求服务顺序和总移动量。
:::

::: details 解析
从 $50$ 开始，最近请求依次为：
$$
55\rightarrow58\rightarrow39\rightarrow18.
$$
恰与本题 FCFS 相同，总移动量仍为 $48$。SSTF 并不保证每组请求都优于 FCFS，只是每一步局部选择最近请求。
:::

::: info 例 3
SCAN 与 LOOK 的关键区别是什么？
:::

::: details 解析
SCAN 沿当前方向移动到磁盘物理端点再反向；LOOK 只移动到该方向上最远的待服务请求就反向，避免无请求区间的移动。
:::

::: info 例 4
SSD 是否仍需按 SSTF 优化机械寻道距离？
:::

::: details 解析
通常不需要。SSD 没有机械磁头和旋转延迟，SSTF 所优化的机械寻道距离不再存在。分析 SSD 时应重点关注其读写性能、擦除后才能改写的特点和磨损均衡。
:::

::: info 例 5
磁头位于 $100$，请求为 $55,58,39,18,90,160,150$，当前向大磁道方向移动。采用 LOOK，求服务顺序和总移动量。
:::

::: details 解析
先按递增方向服务：
$$
150\rightarrow160,
$$
到最远请求后反向：
$$
90\rightarrow58\rightarrow55\rightarrow39\rightarrow18.
$$
总移动量为：
$$
(160-100)+(160-18)=60+142=202.
$$
:::

::: info 例 6
一次磁盘访问平均寻道时间为 $5\text{ ms}$，平均旋转延迟为 $4\text{ ms}$，传输时间为 $1\text{ ms}$，求平均访问时间。
:::

::: details 解析
$$
T_a=T_s+T_r+T_t=5+4+1=10\text{ ms}.
$$
:::

::: info 例 7
为什么 SSD 需要磨损均衡？
:::

::: details 解析
闪存单元的可擦写次数有限。如果写入长期集中在少数物理块，这些块会过早失效。磨损均衡把擦写操作分散到不同块，以延长 SSD 的整体寿命。
:::

## 答题技巧

- 磁盘调度题先在数轴上标出当前位置、移动方向和全部请求。
- SCAN、C-SCAN 是否移动到端点要按题目定义；LOOK、C-LOOK 只移动到最远请求。
- SSD 没有机械寻道和旋转延迟；应掌握其读写性能特点、擦除后改写以及磨损均衡。
