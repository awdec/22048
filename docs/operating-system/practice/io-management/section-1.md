<h1><center>第一节 I/O管理概述</center></h1>

::: info 例 1
比较中断驱动 I/O 与 DMA 中 CPU 被打断的频率。
:::

::: details 解析
中断驱动方式通常每传输一个字或较小单位就中断一次；DMA 由控制器成块传输，CPU 只在初始化和整块传输完成时参与，因此中断频率更低。
:::

::: info 例 2
DMA 传输期间 CPU 能否继续执行指令？
:::

::: details 解析
可以，但 DMA 与 CPU 会竞争内存总线。DMA 可以采用周期窃取等方式取得总线，CPU 在部分存储周期可能需要等待。
:::

::: info 例 3
非阻塞 I/O 与阻塞 I/O 的返回时机有何不同？
:::

::: details 解析
阻塞 I/O 在操作暂时不能完成时使调用进程等待；非阻塞 I/O 立即返回当前结果或“暂不可用”状态，调用者可以继续执行并在稍后重试。
:::

::: info 例 4
程序直接控制、中断驱动和 DMA 三种方式中，CPU 干预程度如何变化？
:::

::: details 解析
程序直接控制需要 CPU 持续查询并参与每次数据传输，干预最多；中断驱动允许 CPU 在设备工作时执行其他任务，但每次传输仍要处理中断；DMA 由控制器成块传输，CPU 主要负责初始化和完成处理，干预最少。
:::

::: info 例 5
字符设备和块设备在访问方式上有什么典型区别？
:::

::: details 解析
字符设备通常按字节流顺序传输，不支持任意位置访问；块设备以固定大小的数据块传输，通常支持按块随机访问。
:::

## 答题技巧

- 比较 I/O 控制方式时，重点判断 CPU 是否忙等待、每次传输是否由 CPU 完成，以及中断发生的频率。
- DMA 并非完全脱离 CPU，只是减少 CPU 对数据传输过程的干预。
