<h1><center>第二节 设备独立性软件</center></h1>

::: info 例 1
设备独立性软件和设备驱动程序哪一个更依赖具体硬件？二者如何衔接？
:::

::: details 解析
设备驱动程序更依赖具体设备和控制器。设备独立性软件负责统一接口、逻辑设备映射、保护、分配和缓冲等通用功能，再通过操作系统规定的驱动接口，把规范化 I/O 请求交给对应的设备驱动程序。
:::

::: info 例 2
应用程序使用逻辑设备名而不直接指定物理设备有什么好处？逻辑设备表起什么作用？
:::

::: details 解析
逻辑设备名使应用程序不依赖固定的物理设备。更换同类设备、调整设备分配或重定向请求时，应用程序通常无须修改。逻辑设备表保存逻辑设备到物理设备及相应驱动程序的映射，是实现设备独立性的重要数据结构。
:::

::: info 例 3
单缓冲输入中，设备输入一块数据耗时 $T$，把数据从系统缓冲区送入用户工作区耗时 $M$，进程处理一块耗时 $C$。处理 $n$ 块数据总时间是多少？
:::

::: details 解析
第一块数据依次经过输入、传送和处理。此后，设备输入下一块与进程处理当前块可以并行，但缓冲区到用户工作区的传送需要单独进行。因此总时间为：

$$
T+M+(n-1)\bigl[\max(T,C)+M\bigr]+C.
$$

当 $n$ 很大时，稳定阶段每块约耗时 $\max(T,C)+M$。
:::

::: info 例 4
在与上题相同的条件下使用双缓冲，忽略资源竞争时，稳定阶段处理每块数据约需多久？处理 $n$ 块总时间是多少？
:::

::: details 解析
双缓冲允许设备向一个缓冲区输入时，系统把另一个缓冲区的数据送入用户工作区并由进程处理。因此稳定阶段每块约耗时：

$$
\max(T,M+C).
$$

处理 $n$ 块的总时间为：

$$
T+(n-1)\max(T,M+C)+M+C.
$$

若题目明确忽略缓冲区到工作区的传送时间，则可令 $M=0$，稳定阶段为 $\max(T,C)$。
:::

::: info 例 5
输入缓冲池初始有 3 个空缓冲。两个设备各取得一个缓冲并填满，而用户进程尚未取走数据。此时空缓冲队列和输入队列各有多少个缓冲？用户处理并归还一块后如何变化？
:::

::: details 解析
两个设备填满缓冲后，空缓冲队列剩 $3-2=1$ 个，输入队列有 2 个。用户取走一个满缓冲时，该缓冲暂时成为提取输入工作缓冲，输入队列变为 1 个；处理完成并归还后，它重新进入空缓冲队列，空缓冲数变为 2。各队列的访问必须进行互斥和同步保护。
:::

::: info 例 6
设备分配时，SDT、DCT 和 I/O 请求队列分别记录什么信息？
:::

::: details 解析
- SDT 是系统设备表，汇总系统中的设备，并给出相应设备控制信息的入口。
- DCT 是设备控制表，记录设备标识、类型、状态、占用者、等待队列及所连接的控制器。
- I/O 请求队列保存暂时不能执行的请求；请求控制块记录操作类型、数据位置、数据量、请求进程和完成状态等信息。

它们共同描述进程、I/O 请求、设备和控制器之间的对应及占用关系。具体名称和组织方式可因操作系统而异。
:::

::: info 例 7
为进程分配一个独占设备时，为什么不能只修改设备的“忙/闲”标志？
:::

::: details 解析
系统还要完成逻辑设备到物理设备的映射，检查访问权限和分配安全性，记录占用者，并确认控制器及相关 I/O 通路能够启动。设备暂时不可用时，还应建立请求控制信息并把请求加入等待队列。因此，设备分配是完整的资源管理过程，不只是修改一个状态位。
:::

::: info 例 8
静态设备分配和动态设备分配各有什么优缺点？
:::

::: details 解析
静态分配在进程运行前一次取得全部所需设备，结束后统一释放，能够防止设备分配死锁，但设备利用率较低；动态分配在运行过程中按需申请和释放，利用率较高，但进程持有部分独占设备再等待其他设备时可能形成死锁。
:::

::: info 例 9
SPOOLing 系统中的井和缓冲区分别位于哪里？各起什么作用？
:::

::: details 解析
输入井和输出井位于磁盘等外存，用于较长期地排队保存输入数据和输出作业；输入、输出缓冲区位于内存，用于设备、内存和外存之间传送数据时的暂存与速度匹配。井不是内存缓冲区，二者不能混淆。
:::

::: info 例 10
SPOOLing 能否把一台打印机变成真正并行工作的多台物理打印机？
:::

::: details 解析
不能。多个进程可以并发地把打印任务提交到磁盘输出井，因而在逻辑上共享打印机；打印进程仍要按照调度次序把任务逐个送往一台物理打印机。SPOOLing 提供的是虚拟设备和逻辑共享，不是物理复制或物理并行。
:::

::: info 例 11
三个进程几乎同时打印大文件。结合逻辑设备、输出井、内存缓冲、打印进程和物理打印机说明其工作过程。
:::

::: details 解析
1. 各进程向统一的逻辑打印设备提交任务，不直接占用物理打印机。
2. 系统经内存输出缓冲把各任务写入磁盘输出井，并建立任务控制信息。
3. 数据成功进入输出井后，用户进程通常即可继续运行。
4. 打印进程按照调度策略从输出井选择任务，经输出缓冲逐步送往打印机。
5. 驱动程序和中断处理程序推进实际输出；任务完成后，系统更新状态并回收井空间。
:::

::: info 例 12
为什么设备驱动程序接口要由操作系统统一规定？统一接口是否意味着所有设备支持完全相同的操作？
:::

::: details 解析
统一接口使设备独立性软件能够用一致方式调用不同驱动，把寄存器、控制时序和设备错误处理等硬件细节限制在驱动内部。但不同设备的能力不同，支持的操作不必完全相同。例如，字符设备一般不能任意定位，设备特有功能可通过专用控制操作实现。
:::

::: info 例 13
设备驱动程序与中断处理程序的职责有何区别？
:::

::: details 解析
驱动程序负责把抽象 I/O 请求转换为设备命令、设置控制器或 DMA 参数、启动设备并处理完整的设备控制逻辑；中断处理程序在设备发出中断时快速保存必要现场、判断中断原因、读取状态并通知驱动或唤醒进程。两者协同完成 I/O，但触发时机和主要职责不同。
:::

## 答题技巧

- 设备独立性软件处理通用策略，设备驱动程序处理具体硬件控制，中断处理程序响应设备中断。
- 缓冲区用于协调速度、传输粒度和数据到达时机，并提高设备与进程的并行程度。
- 设备分配要结合逻辑设备映射、权限、设备状态、控制器状态和请求队列综合判断。
- SPOOLing 的井位于外存，缓冲区位于内存；它实现逻辑共享，不产生多台物理设备。
