<h1><center>第二节 设备独立性软件</center></h1>

::: info 例 1
设备独立性软件和设备驱动程序哪一个更依赖具体硬件？
:::

::: details 解析
设备驱动程序更依赖具体控制器和设备。设备独立性软件向上提供统一接口，并完成逻辑设备名映射、设备保护、分配和缓冲等通用功能。
:::

::: info 例 2
设备驱动程序接口为什么要由操作系统统一规定？
:::

::: details 解析
统一接口使上层能够使用一致的打开、关闭、读、写和控制操作调用不同设备驱动，同时把寄存器、控制时序和中断处理等硬件细节限制在驱动内部。
:::

::: info 例 3
设备输入一块数据耗时 $T$，进程处理一块耗时 $C$。忽略首次填充和切换开销，双缓冲稳定阶段处理每块数据约需多久？
:::

::: details 解析
输入和处理可以并行，稳定阶段吞吐量由较慢的一方决定，因此每块数据约需：
$$
\max(T,C).
$$
:::

::: info 例 4
磁盘高速缓存和磁盘缓冲区的主要目的相同吗？
:::

::: details 解析
不完全相同。缓存保存数据副本，利用局部性减少再次访问慢速磁盘；缓冲主要协调传输速度、批量和数据粒度，数据通常还要继续交付给接收方。
:::

::: info 例 5
SPOOLing 能否把一台打印机变成真正并行工作的多台物理打印机？
:::

::: details 解析
不能。SPOOLing 把多个作业先写入磁盘输出井，再由打印进程依次送往一台打印机，只是在逻辑上让多个进程共享独占设备。
:::

::: info 例 6
应用程序使用逻辑设备名而不直接指定物理设备有什么好处？
:::

::: details 解析
操作系统可以把逻辑设备名映射到可用的物理设备。更换同类设备、调整设备分配或重定向请求时，应用程序通常无须修改，从而实现设备独立性。
:::

## 答题技巧

- 设备独立性软件处理通用策略，设备驱动程序处理具体硬件细节。
- SPOOLing 的井位于外存，缓冲区位于内存。
- 缓冲解决速度与粒度不匹配，缓存利用局部性保存副本。
