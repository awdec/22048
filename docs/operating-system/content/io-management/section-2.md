<h1><center>第二节 设备独立性软件</center></h1>

## 1. 设备独立性

设备独立性是指应用程序使用逻辑设备名和统一操作访问设备，无须了解设备的物理特性和具体控制方法。更换同类设备时，应用程序通常不需要修改。

设备独立性软件位于设备驱动程序之上，其主要功能包括：

- 提供统一的设备访问接口。
- 将逻辑设备名映射为物理设备。
- 完成设备保护、分配与回收。
- 提供缓冲、缓存和 SPOOLing 等通用功能。
- 向上层报告统一格式的设备错误。

## 2. 逻辑设备名与物理设备名

应用程序通过逻辑设备名提出请求，操作系统利用逻辑设备表查找相应的物理设备和驱动程序。这种映射使程序不依赖固定的设备编号，也便于设备替换和请求重定向。

## 3. 设备驱动程序

设备驱动程序与具体控制器和设备密切相关，负责把上层抽象 I/O 请求转换为硬件命令，设置控制器寄存器并启动设备。

驱动程序通常还负责检查设备状态、处理错误，并与中断处理程序协作完成请求。操作系统通过统一的驱动接口调用设备初始化、打开、关闭、读、写和控制等操作。

## 4. 中断处理程序

设备完成操作或发生异常时，控制器发出中断。中断处理程序保存必要现场，读取设备状态，处理错误或传输结果，唤醒等待进程，并把后续工作交给驱动程序或内核其他模块。

中断处理程序应尽量简短，以减少关中断或高优先级执行对系统响应的影响。

## 5. 缓冲管理

缓冲的主要作用包括：

- 缓和 CPU 与设备之间的速度差异。
- 减少对 CPU 的中断频率。
- 提高 CPU 与设备之间的并行性。
- 解决数据传输粒度不匹配。

### 5.1 单缓冲

设备把数据送入一个缓冲区，进程再从缓冲区取走数据。设备输入与用户处理可以部分重叠。

### 5.2 双缓冲

两个缓冲区交替使用，一个由设备填充，另一个由进程处理，使输入和处理能够更充分地并行。

### 5.3 循环缓冲与缓冲池

循环缓冲由多个缓冲区首尾相接；缓冲池统一管理空缓冲、输入满缓冲和输出满缓冲，适合多个进程与设备共享。

缓冲主要协调速度和数据粒度；高速缓存则保存数据副本，利用局部性减少对慢速层次的访问。

## 6. 设备分配与回收

设备分配需要记录设备、控制器、占用者、设备状态和等待队列等信息，以便完成逻辑设备到物理设备的映射以及设备的分配与回收。

独占设备一次只能分配给一个进程；共享设备可以交错处理多个请求。设备使用完毕后，系统应回收占用标志并唤醒等待进程。分配策略需要兼顾安全性、公平性和设备利用率。

## 7. SPOOLing

假脱机技术利用磁盘模拟独占设备，把独占设备改造为可以被多个进程共享的虚拟设备。

以打印为例，用户进程把输出写入磁盘输出井，打印守护进程再按顺序把数据送往打印机。SPOOLing 通常包含：

- 输入井和输出井。
- 输入缓冲区和输出缓冲区。
- 输入进程和输出进程。

::: warning 易错点
SPOOLing 的输入井和输出井位于外存；内存中的输入、输出缓冲区只用于暂存传输数据。SPOOLing 使独占设备在逻辑上共享，并不会把一台物理设备变成多台设备。
:::
