<h1><center>第二节 操作系统发展历程</center></h1>

## 1. 手工操作阶段

早期计算机没有操作系统，用户直接使用机器。程序和数据的装入、运行以及结果输出都由人工完成，主要矛盾是人的操作速度远低于计算机的处理速度，导致处理机经常空闲。

## 2. 批处理系统

### 2.1 单道批处理系统

作业被成批送入计算机，由监督程序自动依次运行。它减少了人工干预，但内存中始终只有一道作业，作业进行 I/O 时处理机仍会空闲。

### 2.2 多道批处理系统

内存中同时存放多道作业。当一道作业因 I/O 暂停时，处理机转去运行其他作业，从而提高资源利用率和系统吞吐量。

多道批处理系统具有多道、宏观并行和微观串行的特点，但用户提交作业后不能及时与系统交互。

## 3. 分时操作系统

分时系统把处理机时间划分为很短的时间片，轮流为多个终端用户服务。它具有同时性、交互性、独立性和及时性，使每个用户都感觉自己在独占计算机。

分时系统强调及时响应，但通常不能保证在严格的截止时间内完成任务。

## 4. 实时操作系统

实时系统要求在规定时间内响应外部事件并完成处理：

- **硬实时系统**：必须在截止时间前完成任务，错过截止时间可能造成严重后果。
- **软实时系统**：允许偶尔错过截止时间，但系统性能会下降。

实时系统通常强调及时性和可靠性，常用于工业控制、航空航天和多媒体等场景。

## 5. 其他操作系统形态

- **网络操作系统**：支持网络通信和网络资源共享。
- **分布式操作系统**：管理分布在不同计算机上的资源，并向用户提供统一的系统视图。
- **个人计算机操作系统**：强调易用性、图形交互和对个人应用的支持。
- **嵌入式操作系统**：面向特定设备，通常对资源占用、可靠性和实时性有较高要求。

## 6. 发展主线

| 阶段 | 主要目标 | 典型特点 |
| --- | --- | --- |
| 手工操作 | 直接使用硬件 | 人机矛盾突出 |
| 单道批处理 | 减少人工干预 | 自动顺序执行、资源利用率低 |
| 多道批处理 | 提高资源利用率和吞吐量 | 多道、无交互 |
| 分时系统 | 改善人机交互 | 时间片轮转、及时响应 |
| 实时系统 | 保证规定时间内完成任务 | 截止时间、可靠性高 |

::: warning 易错点
多道批处理系统和分时系统都利用多道程序技术；前者主要追求吞吐量，后者主要追求交互性和响应时间。
:::
