<h1><center>第一节 操作系统的基本概念</center></h1>

## 1. 操作系统的概念

操作系统（Operating System，OS）是控制和管理计算机系统的硬件与软件资源、合理组织计算机工作流程，并为用户和应用程序提供服务的系统软件。

操作系统位于计算机硬件与用户程序之间：

$$
\text{用户与应用程序}\longleftrightarrow\text{操作系统}\longleftrightarrow\text{计算机硬件}.
$$

它向下控制处理机、内存、外部设备等硬件，向上为应用程序提供进程、文件、虚拟地址空间等抽象，使应用程序无须直接处理复杂的硬件细节。

### 1.1 操作系统是系统软件

操作系统是计算机系统中最基本的系统软件。应用软件通常在操作系统提供的运行环境中执行，并通过操作系统提供的接口取得计算、存储和 I/O 服务。

操作系统不是某一个单独的管理程序，而是由内核及相关系统程序共同形成的软件系统。内核是操作系统的核心，通常包含中断与异常处理、进程调度、内存管理和设备控制等必须在特权状态下执行的功能；不能简单地把“内核”与“整个操作系统”完全等同。

### 1.2 操作系统的三种理解角度

- 资源管理者：管理处理机、存储器、文件和 I/O 设备，协调多个程序对资源的使用。
- 用户与硬件之间的接口：向用户和应用程序提供方便、统一的操作方式。
- 对硬件的扩充：隐藏底层硬件细节，为应用程序提供功能更强、使用更方便的虚拟机器。

## 2. 操作系统的功能和目标

### 2.1 操作系统的目标

操作系统设计和运行的主要目标包括：

- 方便性：为用户和应用程序提供易于使用的接口，屏蔽硬件操作细节。
- 有效性：合理分配和调度系统资源，提高资源利用率与系统吞吐量。
- 安全性与可靠性：隔离不同程序，保护系统资源，并能够处理异常和错误。
- 可扩展性：便于增加新功能、支持新设备并适应系统规模变化。

不同目标之间可能需要权衡。例如，提高吞吐量的调度策略不一定能够使每个交互进程都获得最短响应时间。

### 2.2 计算机资源的管理

操作系统作为资源管理者，主要具有以下功能。

| 管理对象 | 主要功能 |
| --- | --- |
| 处理机管理 | 进程与线程的创建和撤销、调度、同步、通信以及死锁处理 |
| 存储器管理 | 内存分配与回收、地址转换、共享、保护和虚拟内存管理 |
| 文件管理 | 文件和目录的创建、删除、读写、存储空间管理、共享与保护 |
| 设备管理 | 设备分配与回收、设备驱动、中断处理、缓冲以及 I/O 调度 |

操作系统必须记录资源的状态，按照一定策略进行分配，并在使用结束后回收资源。多个程序并发运行时，还要防止它们相互破坏并协调共享资源的访问次序。

### 2.3 为用户和应用程序提供接口

操作系统提供的接口可以分为用户接口和程序接口。

| 接口 | 使用者 | 作用 |
| --- | --- | --- |
| 联机命令接口 | 交互式用户 | 用户输入一条命令，系统解释并执行一条命令 |
| 脱机命令接口 | 批处理作业 | 用户预先编写作业控制命令，由系统依次执行 |
| 图形用户接口 | 交互式用户 | 通过窗口、图标、菜单等图形元素操作系统 |
| 程序接口 | 应用程序 | 由一组系统调用组成，供程序请求操作系统服务 |

系统调用是操作系统向应用程序提供程序接口的基本方式。应用程序执行系统调用时，会通过规定机制进入内核，由操作系统完成相应服务。

库函数不等于系统调用：有些库函数完全在用户态完成，有些库函数则在内部封装一个或多个系统调用。普通函数调用也不一定引起用户态到内核态的转换。

### 2.4 扩充硬件功能

裸机只提供指令、寄存器、物理内存和设备接口等底层功能。操作系统在其上建立更高级的抽象：

- 用进程或线程抽象正在执行的程序。
- 用文件和目录抽象外存中的数据。
- 用虚拟地址空间扩充并隔离物理内存。
- 用统一 I/O 接口隐藏不同设备的控制差异。

从应用程序角度看，经过操作系统扩充后的计算机比裸机更容易使用，因此操作系统也可以看作虚拟机器的提供者。

## 3. 操作系统的特征

操作系统具有并发、共享、虚拟和异步四个基本特征，其中并发和共享是最基本的特征。

### 3.1 并发

并发是指两个或多个事件在同一时间间隔内发生。在单处理器系统中，多个进程可以在一段时间内交替执行，从宏观上看同时推进，但任一时刻通常只有一个进程真正占用处理器。

并行是指两个或多个事件在同一时刻发生，通常需要多核、多处理器或多个功能部件支持。

::: tip 并发与并行
单核处理器可以通过进程切换实现并发，但不能在同一时刻并行执行两个处理器指令流；多核处理器上的多个进程既可以并发，也可能真正并行。
:::

### 3.2 共享

共享是指系统中的资源可以供多个并发执行的进程共同使用，主要有两种方式：

- 互斥共享：一段时间内只允许一个进程访问该资源，其他申请者必须等待，例如未采用虚拟化的打印机。
- 同时共享：允许多个进程在同一时间段内共同访问资源；各次访问在微观上既可能交替，也可能真正并行，例如多个进程读取同一个只读文件。

“同时共享”强调一段时间内允许多个进程共同使用，不等于每个微小时间点都必须发生物理上的同时访问。

### 3.3 虚拟

虚拟是指通过某种技术把一个物理实体变为若干逻辑上的对应物，或者把有限的物理资源表现为更大、更方便使用的逻辑资源。

- 时分复用：不同进程在不同时间片使用同一处理器，使每个进程都产生仿佛拥有独立处理器的效果。
- 空分复用：把存储空间划分、组合或映射成多个逻辑空间，例如每个进程拥有独立的虚拟地址空间。

虚拟技术并没有凭空增加物理资源，而是改变了资源的组织、映射和使用方式。

### 3.4 异步

异步是指并发执行的多个进程以各自独立、不可预知的速度向前推进。中断发生时间、进程调度次序和资源等待时间等因素，都可能改变进程每次运行的具体执行时序。

异步不等于程序结果必然随机。只要程序正确使用同步与互斥机制，在相同输入下仍应得到符合设计要求的结果；缺少同步的数据竞争才可能导致结果不确定。

### 3.5 四个特征之间的关系

- 并发使多个执行活动在同一系统中共同推进，从而产生资源共享的需要。
- 资源共享为多个活动并发执行提供物质基础，因此并发与共享互为存在条件。
- 虚拟技术通常建立在资源共享和并发执行的基础上。
- 异步是多个活动并发推进、相互制约时表现出的执行特征。

::: warning 易错点
并发描述同一时间间隔内多个事件共同推进，并行描述同一时刻多个事件同时发生；异步描述执行时序难以预知，不表示正确程序的运行结果必然不可重复。
:::
