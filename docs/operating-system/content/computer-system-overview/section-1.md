<h1><center>第一节 操作系统的基本概念</center></h1>

## 1. 操作系统的概念

操作系统是控制和管理计算机硬件与软件资源、合理组织计算机工作流程，并为用户和应用程序提供接口的系统软件。

它位于硬件与应用程序之间：

$$
\text{用户/应用程序}\rightarrow\text{操作系统}\rightarrow\text{硬件}
$$

## 2. 操作系统的目标和功能

操作系统的主要目标是方便用户使用计算机、提高系统资源利用率，并使计算机系统能够安全、稳定地运行。

- **处理机管理**：进程控制、调度、同步、通信与死锁处理。
- **存储器管理**：内存分配、地址转换、保护与虚拟内存。
- **文件管理**：文件、目录、磁盘空间和访问权限。
- **设备管理**：设备分配、驱动、中断、缓冲与磁盘调度。
- **接口服务**：命令接口、程序接口和图形用户接口。

从不同角度看，操作系统既是计算机资源的管理者，也是用户与硬件之间的接口，还对硬件进行扩充，为应用程序提供更易使用的虚拟计算机。

## 3. 操作系统的基本特征

### 3.1 并发

并发是指多个事件在同一时间间隔内发生。单处理器上多个进程宏观同时推进、微观交替执行，属于并发。

并行是指多个事件在同一时刻发生，需要多核处理器等硬件支持。单核处理器可以并发，但不能在同一时刻真正执行两个用户进程。

### 3.2 共享

系统资源可供多个并发进程共同使用：

- **互斥共享**：一段时间内只允许一个进程访问资源。
- **同时共享**：允许一段时间内多个进程交替或并行访问资源。

### 3.3 虚拟

虚拟是指通过某种技术把一个物理实体映射为若干逻辑实体，如利用时分复用形成虚拟处理器，利用空分复用形成虚拟内存。

### 3.4 异步

并发进程以不可预知的速度向前推进。程序若正确使用同步机制并避免数据竞争，在相同输入和运行条件下应得到可再现的结果；若多个进程无同步地竞争共享数据，执行结果可能不同。

::: tip 核心关系
并发和共享是操作系统最基本的特征，二者互为存在条件；虚拟以并发和共享为前提，异步则是并发运行的自然结果。
:::

## 4. 操作系统提供的接口

- **命令接口**：包括联机命令接口和脱机命令接口，供用户直接组织和控制作业。
- **程序接口**：由一组系统调用组成，供应用程序请求操作系统服务。
- **图形用户接口**：通过窗口、图标和菜单等方式实现交互。

库函数不等于系统调用。库函数可以完全在用户态完成，也可能在内部封装系统调用。

::: warning 易错点
系统调用是操作系统向应用程序提供的程序接口；普通函数调用不一定进入内核态。
:::
