<h1><center>第六节 虚拟机</center></h1>

## 1. 虚拟机的概念

虚拟机通过虚拟化技术把一台物理计算机抽象为多个相互隔离的执行环境。每个虚拟机都拥有虚拟处理器、虚拟内存和虚拟设备，可以像使用独立计算机一样运行客户操作系统和应用程序。

同一物理机上的虚拟机共享硬件资源，但地址空间、处理器状态和设备状态彼此隔离。

## 2. 虚拟机监控程序

虚拟机监控程序（VMM，也称 Hypervisor）负责创建和管理虚拟机，分配处理器、内存与 I/O 资源，并处理客户操作系统对敏感资源的访问。

### 2.1 第一类虚拟机监控程序

第一类 VMM 直接运行在硬件上，控制硬件并管理多个客户操作系统，不依赖通用宿主操作系统，通常具有较好的性能和隔离性。

### 2.2 第二类虚拟机监控程序

第二类 VMM 作为应用程序运行在宿主操作系统之上，通过宿主操作系统获得设备和资源服务，安装和使用较方便，但调用路径通常更长。

## 3. 虚拟化的实现

- **完全虚拟化**：向客户操作系统提供完整硬件接口，客户操作系统通常无须修改。
- **半虚拟化**：客户操作系统通过专门接口与 VMM 协作，需要一定适配，但可减少部分模拟开销。
- **硬件辅助虚拟化**：利用处理器提供的虚拟化扩展，使敏感操作能被 VMM 安全地截获和处理。

## 4. 虚拟机的特点

- **隔离性**：一个虚拟机中的故障通常不会直接破坏其他虚拟机。
- **封装性**：虚拟机状态可以保存、复制和迁移。
- **资源复用**：多个虚拟机共享一台物理机，提高硬件利用率。
- **灵活性**：同一硬件平台可同时运行不同的客户操作系统。

虚拟化会带来额外的资源管理和模拟开销，过度分配资源还可能导致虚拟机之间相互争用。

::: tip 判断方法
第一类 VMM 直接管理硬件；第二类 VMM 依赖宿主操作系统。客户操作系统运行在虚拟机中，宿主操作系统只出现在第二类 VMM 的结构中。
:::
