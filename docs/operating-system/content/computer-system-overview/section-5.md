<h1><center>第五节 操作系统引导</center></h1>

## 1. 引导的含义

操作系统引导是计算机从加电或复位开始，到操作系统内核装入内存、完成初始化并接管系统的过程。主存中的内容断电后会丢失，因此启动时需要借助固件和引导程序从非易失性存储设备装入内核。

## 2. 引导程序

引导程序是一段负责定位并装入操作系统内核的程序。为解决“由谁装入引导程序”的问题，计算机把最初执行的固件保存在 ROM 或闪存中。

引导可以分阶段完成：固件先装入规模较小的引导程序，再由引导程序识别文件系统、读取配置并装入完整内核。

## 3. 典型引导过程

1. CPU 复位后从规定地址开始执行固件。
2. 固件完成基本硬件检查和初始化，选择启动设备。
3. 固件装入并运行引导程序。
4. 引导程序把操作系统内核及必要参数装入内存，然后移交控制权。
5. 内核初始化中断、内存管理、设备驱动和文件系统，创建首批系统进程。
6. 系统启动用户态服务，最终进入可登录或可交互状态。

::: warning 易错点
计算机启动时最先运行的不是操作系统内核，而是固件。固件和引导程序完成前期工作后，内核才获得处理器控制权。
:::
