<h1><center>第二节 虚拟内存管理</center></h1>

## 1. 局部性原理

- **时间局部性**：最近访问的数据或指令很可能再次被访问。
- **空间局部性**：访问某地址后，很可能继续访问其附近地址。

虚拟内存以局部性原理为基础，只把程序当前需要的部分装入内存，其余部分保存在外存中。

## 2. 虚拟内存的概念与特征

虚拟内存从逻辑上扩充内存容量，使程序看到的地址空间可以大于实际物理内存。它具有以下特征：

- **多次性**：作业分多次调入内存，而不是一次全部装入。
- **对换性**：页面可以在内存和外存之间换入、换出。
- **虚拟性**：用户看到的逻辑内存容量可以大于物理内存。

虚拟内存的实际容量受计算机地址结构和外存容量限制。

## 3. 请求分页管理

请求分页系统只在页面被访问时将其调入内存。页表项除页框号外，通常还包含：

- 存在位：页面当前是否在内存。
- 访问位：页面近期是否被访问。
- 修改位：页面换出前是否需要写回外存。
- 保护位：页面的读、写、执行权限。

## 4. 缺页异常处理

1. 处理器访问页面，发现存在位为 $0$。
2. 产生缺页异常并转入内核。
3. 内核检查地址是否合法。
4. 寻找空闲页框；没有空闲页框时选择牺牲页。
5. 若牺牲页已修改，先将它写回外存。
6. 从外存读入所需页面。
7. 更新页表和 TLB。
8. 重新执行引发缺页的指令。

缺页是由当前指令触发的可恢复故障，不是外中断；页面调入完成后，设备会通过 I/O 中断通知处理器。

## 5. 页框分配与置换范围

当空闲页框不足时，操作系统需要回收某个可替换页框。若其中的页面已被修改，回收前必须写回外存；未修改页面已有外存副本，通常可直接回收。回收后还要使原页表项失效，并处理可能存在的 TLB 项。原页面所属进程以后再次访问该页时会发生缺页。

- **固定分配**：每个进程获得的页框数在运行期间保持不变。
- **可变分配**：系统可以在运行期间调整进程的页框数。
- **局部置换**：牺牲页只能从当前进程占用的页框中选择。
- **全局置换**：牺牲页可以从系统中的可替换页框中选择。

固定分配通常搭配局部置换；可变分配可以搭配全局置换或局部置换。

## 6. 页面置换算法

### 6.1 最佳置换 OPT

淘汰未来最长时间不再访问的页面。OPT 能得到最少缺页次数，但需要预知未来，只能作为理论最优基准。

### 6.2 先进先出 FIFO

淘汰最早进入内存的页面，实现简单，但可能出现 Belady 异常，即增加页框后缺页次数反而增多。

### 6.3 最近最少使用 LRU

淘汰最长时间未被访问的页面，利用过去预测未来。LRU 属于栈算法，不会出现 Belady 异常，但精确实现需要较多硬件支持。

### 6.4 时钟 CLOCK

CLOCK 使用访问位和循环指针。指针遇到访问位为 $0$ 的页面就将其淘汰；遇到访问位为 $1$ 的页面则清零并继续扫描。

改进型 CLOCK 同时考虑访问位和修改位，优先淘汰未访问且未修改的页面，以减少写回开销。

| 算法 | 淘汰对象 | Belady 异常 |
| --- | --- | --- |
| OPT | 未来最晚使用 | 无 |
| FIFO | 最早进入内存 | 可能有 |
| LRU | 最久未访问 | 无 |
| CLOCK | 根据访问位循环检查 | LRU 的近似实现 |

## 7. 抖动与工作集

某段时间窗口内进程实际访问的页面集合称为工作集；分配给进程的物理页框集合称为驻留集。若驻留集长期小于工作集，进程会频繁缺页。

系统把大部分时间用于页面换入换出，处理器利用率反而下降的现象称为抖动。其原因通常是同时运行的进程过多、每个进程获得的页框不足。

缓解抖动的方法包括：

- 减少多道程序度。
- 按工作集为进程分配页框。
- 使用缺页率控制动态调整驻留集。

## 8. 内存映射文件

内存映射把文件的一部分关联到进程虚拟地址空间，使进程可以像访问内存一样读写文件。首次访问尚未装入的映射页时会发生缺页，内核将对应文件块调入页框；修改后的页面可按映射方式写回文件。

多个进程映射同一文件区域可以实现共享。解除映射时，操作系统撤销虚拟地址范围与文件之间的关联。

## 9. 缺页率

若访问序列长度为 $N$，缺页次数为 $F$，则：

$$
\text{缺页率}=\frac{F}{N}.
$$

计算时应明确初始页框是否为空、第一次装入是否计为缺页，以及采用的置换算法和破平规则。

::: warning 易错点
TLB 未命中只表示快表中没有地址映射，不一定缺页；只有合法页面不在内存时才触发缺页异常。
:::
