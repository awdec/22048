<h1><center>第七节 多处理器的基本概念</center></h1>

::: info 例 1.
按照 Flynn 分类，一台由多个处理器执行不同指令流并处理不同数据流的系统属于（ ）。<br>
A. SISD<br>
B. SIMD<br>
C. MISD<br>
D. MIMD
:::

::: details 解析
答案：D。

多个指令流、多个数据流对应 MIMD。典型多核通用处理器系统通常属于 MIMD；每个核心内部仍可使用 SIMD 指令。因此选 D。
:::

::: info 例 2.
向量处理器的主要特点是（ ）。<br>
A. 一条向量指令对一组数据元素执行同类操作
B. 每个数据元素必须由完全独立的程序控制
C. 不能使用流水线
D. 必然拥有分布式地址空间
:::

::: details 解析
答案：A。

向量指令以向量为操作对象，开发数据级并行性，通常体现广义 SIMD 思想。它并不要求多个独立指令流，也可以使用流水执行部件。因此选 A。
:::

::: info 例 3.
同时多线程（SMT）是指（ ）。<br>
A. 一个核心在同一周期可从多个硬件线程选择并发射指令
B. 每个核心只能保存一个线程的体系结构状态
C. 多台计算机通过网络交换消息
D. 把一个指令拆成多个微操作
:::

::: details 解析
答案：A。

SMT 在超标量核心内保存多个硬件线程的状态，并可在同一周期从不同线程选择指令使用多个发射槽。它不等于多核，也不等于指令译码。因此选 A。
:::

::: info 例 4.
关于共享内存多处理器，下列说法正确的是（ ）。<br>
A. 各处理器必须拥有彼此独立、互不可见的地址空间
B. SMP 强调各处理器地位和系统功能基本对等
C. NUMA 不提供统一共享地址空间
D. 增加核心数后所有程序必然线性加速
:::

::: details 解析
答案：B。

共享内存系统向处理器提供统一共享地址空间；NUMA 的本地和远程访问时间不同，但仍可共享地址空间。SMP 强调处理器地位对等。串行部分、通信和同步开销都会限制多核加速。因此选 B。
:::

## 本节小结

Flynn 分类、向量处理、硬件多线程、多核和共享内存描述的是不同维度。做题时应先判断题目讨论的是指令流、数据流、线程状态、物理核心还是地址空间。
