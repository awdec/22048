<h1><center>第三节 数据通路的功能和基本结构</center></h1>

::: info 例 1.
在典型单总线 CPU 数据通路中，同一时钟节拍内通常允许（ ）。<br>
A. 多个源寄存器同时驱动总线<br>
B. 一个源驱动总线，多个目的寄存器同时接收
C. 任意多个源和目的同时使用总线
D. 总线只能连接两个部件
:::

::: details 解析
答案：B。

为避免电气冲突，一个时刻通常只能有一个源驱动单总线；只要控制和建立时间允许，多个目的寄存器可以同时锁存同一总线数据。因此选 B。
:::

::: info 例 2.
在带有暂存寄存器 Y、Z 的单总线数据通路中，实现 `R1←R2+R3` 的合理微操作顺序是（ ）。<br>
A. `R2out, Yin; R3out, ADD, Zin; Zout, R1in`<br>
B. `R2out, R3out, ADD, R1in`
C. `R1out, Yin; R2out, ADD, R3in`
D. `R3out, R1in; R2out, R1in`
:::

::: details 解析
答案：A。

单总线不能同时送出 $R2$ 和 $R3$，因此先把一个操作数送入 Y，再让另一个操作数经总线与 Y 参加 ALU 运算，结果暂存于 Z，最后写入 R1。因此选 A。
:::

::: info 例 3.
与单总线数据通路相比，专用通路通常具有的特点是（ ）。<br>
A. 硬件连接更少，控制更简单
B. 可以提高并行传送能力，但硬件和控制更复杂
C. 任何两个部件之间都必须直接相连
D. 不需要多路选择器
:::

::: details 解析
答案：B。

专用通路或多端口结构能减少共享资源冲突，提高并行性，但连接、端口和控制逻辑通常更多。它不要求任意两部件完全互连，也常使用多路选择器。因此选 B。
:::

## 本节小结

数据通路题的关键不是背微操作序列，而是检查源、目的、暂存寄存器、ALU 输入和共享资源是否在同一节拍发生冲突。
