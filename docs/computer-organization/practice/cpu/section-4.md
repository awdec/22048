<h1><center>第四节 控制器的功能和工作原理</center></h1>

::: info 例 1.
硬布线控制器产生控制信号的主要依据不包括（ ）。<br>
A. 指令操作码<br>
B. 时序信号
C. 条件和状态标志
D. 用户程序源代码
:::

::: details 解析
答案：D。

硬布线控制逻辑通常根据译码结果、当前时序状态以及条件标志组合产生控制信号，不直接读取高级语言源代码。因此选 D。
:::

::: info 例 2.
某控制存储器共有 1024 个微指令字，若采用直接给出下地址的方式，则微指令的下地址字段至少需要（ ）位。<br>
A. 8<br>
B. 10<br>
C. 16<br>
D. 32
:::

::: details 解析
答案：B。

$1024=2^{10}$，因此至少需要 10 位才能给出控制存储器中的全部微地址。因此选 B。
:::

::: info 例 3.
下列关于微程序控制器的说法中，正确的是（ ）。<br>
A. 一条机器指令等于一条微指令
B. 微命令是微操作的控制信号，微指令是若干微命令及顺序信息的编码
C. 控制存储器用于保存普通用户数据
D. 微程序控制器不需要形成下一条微指令地址
:::

::: details 解析
答案：B。

一条机器指令通常对应一段微程序，一条微指令可同时发出若干相容微命令，并给出或参与形成后继微地址。控制存储器保存微程序而非普通用户数据。因此选 B。
:::

::: info 例 4.
水平型微指令与垂直型微指令相比，通常具有（ ）。<br>
A. 并行操作能力较强、字长较长
B. 并行操作能力较弱、字长一定更长
C. 完全不需要译码
D. 控制存储器容量一定更小
:::

::: details 解析
答案：A。

水平型微指令的控制字段通常更接近直接控制，能并行表示较多微命令，但字长和控制存储器位容量往往更大。因此选 A。
:::

## 本节小结

硬布线控制侧重组合逻辑和状态转换，微程序控制侧重微指令、控制存储器和后继微地址形成。二者都必须与既定数据通路相匹配。
