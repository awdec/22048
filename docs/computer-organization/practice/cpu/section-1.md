<h1><center>第一节 CPU 的功能和基本结构</center></h1>

::: info 例 1.
下列部件中，通常属于程序员可见寄存器的是（ ）。<br>
A. 指令寄存器 IR<br>
B. 存储器地址寄存器 MAR<br>
C. 通用寄存器<br>
D. 微地址寄存器
:::

::: details 解析
答案：C。

通用寄存器是 ISA 规定的程序可见状态。IR、MAR 和微地址寄存器通常属于处理器内部实现状态，不供普通机器程序直接指定。因此选 C。
:::

::: info 例 2.
取指过程中，下列寄存器传送顺序合理的是（ ）。<br>
A. `IR←PC; PC←M[IR]`<br>
B. `MAR←PC; MDR←M[MAR]; IR←MDR`<br>
C. `MDR←PC; MAR←IR; PC←MDR`<br>
D. `IR←MAR; MAR←MDR`
:::

::: details 解析
答案：B。

PC 给出指令地址，经 MAR 访问主存，读出的指令先进入 MDR，再送入 IR。实际实现可以通过 Cache 或专用通路优化，但逻辑数据依赖不变。因此选 B。
:::

::: info 例 3.
下列关于 CPU 功能的说法中，错误的是（ ）。<br>
A. 指令控制保证按规定顺序执行指令<br>
B. 操作控制产生完成微操作所需的控制信号<br>
C. 时间控制安排控制信号的时刻和持续时间<br>
D. CPU 的数据加工功能只包括算术运算，不包括逻辑运算
:::

::: details 解析
答案：D。

CPU 的数据加工既包括算术运算，也包括逻辑、移位、比较等操作。因此选 D。
:::

## 本节小结

应能说明 CPU 的五类基本功能，并区分程序可见寄存器与内部暂存、控制寄存器。寄存器的具体名称不是所有处理器都相同。
