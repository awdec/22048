<h1><center>第六节 指令流水线</center></h1>

::: info 例 1.
某理想单发射流水线有 5 级，各级均为 1 个时钟周期，不考虑任何停顿。连续执行 20 条指令至少需要（ ）个时钟周期。<br>
A. 20<br>
B. 24<br>
C. 25<br>
D. 100
:::

::: details 解析
答案：B。

$k$ 级理想流水线执行 $n$ 条指令需要：

$$
k+n-1=5+20-1=24
$$

个周期。因此选 B。
:::

::: info 例 2.
在经典五级 MIPS 流水线中，前一条指令为 `lw R1,0(R2)`，后一条紧接着执行 `add R3,R1,R4`。即使具有常见的数据转发，通常仍需要暂停的主要原因是（ ）。<br>
A. `lw` 的数据要到 MEM 阶段末尾才产生，而 `add` 的 EX 阶段过早需要该数据
B. 两条指令同时写 R1
C. 两条指令一定发生控制冒险
D. `add` 必须访问数据存储器
:::

::: details 解析
答案：A。

这是典型 Load-use RAW 冒险。装入数据在 MEM 阶段末尾才可用，紧随其后的算术指令在下一周期 EX 阶段就需要它，常见转发仍来不及，因此需要插入一个停顿周期。因此选 A。
:::

::: info 例 3.
下列措施中，主要用于处理控制冒险的是（ ）。<br>
A. 增加数据 Cache 容量
B. 分支预测和错误路径冲刷
C. 寄存器重命名消除 RAW 真相关
D. 把所有指令改为访存指令
:::

::: details 解析
答案：B。

控制冒险来自分支等控制转移导致下一条取指地址不确定。分支预测可以提前选择路径，预测错误时冲刷错误路径并重新取指。因此选 B。
:::

::: info 例 4.
下列关于超标量和动态流水线的说法中，正确的是（ ）。<br>
A. 超标量处理器一个周期只能发射一条指令
B. 动态调度可以在保持程序语义的前提下让已就绪指令先执行
C. 乱序执行必然使体系结构结果乱序提交
D. 超标量的实际 IPC 一定等于发射宽度
:::

::: details 解析
答案：B。

超标量允许每周期发射多条指令，但实际 IPC 受依赖、资源和分支影响。动态调度可让已就绪指令越过阻塞指令，常配合按序提交维持精确状态。因此选 B。
:::

## 本节小结

流水线计算先求理想周期数，再加入结构、数据和控制停顿。冒险处理必须结合结果产生阶段、操作数使用阶段和实际转发路径判断。
