<h1><center>第二节 指令执行过程</center></h1>

::: info 例 1.
一条普通机器指令的逻辑执行过程通常首先进行（ ）。<br>
A. 写回结果<br>
B. 取指<br>
C. 处理中断<br>
D. 访问数据存储器
:::

::: details 解析
答案：B。

正常执行的机器指令首先需要根据 PC 取得指令并送入 IR，随后译码并按指令需要完成取数、执行、访存和写回。并非每条指令都需要独立的数据访存或写回阶段。因此选 B。
:::

::: info 例 2.
下列关于指令周期、机器周期和时钟周期的关系，正确的是（ ）。<br>
A. 一条指令固定只占一个时钟周期<br>
B. 一个机器周期固定包含一个指令周期<br>
C. 指令周期可以由若干机器周期组成，每个机器周期又可包含若干时钟周期<br>
D. 三者在所有处理器中含义完全相同
:::

::: details 解析
答案：C。

在经典模型中，指令周期可包含取指、间址、执行和中断等机器周期，机器周期又可细分为时钟节拍。具体处理器和题目可能使用不同层次，必须服从题设。因此选 C。
:::

::: info 例 3.
下列关于单周期和多周期处理器的说法中，正确的是（ ）。<br>
A. 单周期处理器所有指令的 CPI 均为 1，因此一定最快<br>
B. 多周期处理器可以让不同指令使用不同数量的时钟周期<br>
C. 单周期处理器的时钟周期只需覆盖最简单指令的延迟<br>
D. 多周期处理器不能复用同一硬件部件
:::

::: details 解析
答案：B。

单周期处理器的时钟周期必须覆盖最慢指令的组合路径，CPI 为 1 不能保证执行时间最短。多周期结构允许不同指令经历不同周期，并可在不同时刻复用同一部件。因此选 B。
:::

## 本节小结

分析指令执行时，应先画出数据依赖，再安排微操作时序；不能仅根据阶段名称假定所有指令经历完全相同的硬件过程。
