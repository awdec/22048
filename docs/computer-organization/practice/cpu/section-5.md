<h1><center>第五节 异常和中断机制</center></h1>

::: info 例 1.
下列事件中，通常属于同步异常的是（ ）。<br>
A. 键盘输入请求
B. 定时器中断
C. 执行除数为 0 的除法指令
D. DMA 完成通知
:::

::: details 解析
答案：C。

除零由当前指令执行直接引发，在相同程序状态下具有同步性。键盘、定时器和 DMA 完成请求通常来自处理器外部，属于异步中断。因此选 C。
:::

::: info 例 2.
发生缺页后，操作系统把所缺页面调入主存并更新页表，随后通常应（ ）。<br>
A. 执行导致缺页指令的下一条指令
B. 重新执行导致缺页的指令
C. 永久终止进程
D. 清空所有 Cache
:::

::: details 解析
答案：B。

缺页属于可恢复的故障。页面调入并修正地址转换状态后，应重新执行原指令，使该指令完成原本未完成的访存。因此选 B。
:::

::: info 例 3.
关于外部可屏蔽中断的响应，下列说法正确的是（ ）。<br>
A. 中断请求出现后 CPU 必须立即在任意微操作中间响应
B. 只要请求存在，就不需要检查中断允许和优先级
C. CPU 通常在体系结构规定的安全边界检查请求，并在允许且优先级满足时响应
D. 全部通用寄存器一定由硬件自动保存
:::

::: details 解析
答案：C。

外部中断响应还受中断允许、屏蔽和优先级控制，通常在指令边界等安全时点进入处理。硬件自动保存哪些状态由体系结构规定，其他现场常由软件保存。因此选 C。
:::

::: info 例 4.
下列关于中断响应优先级和中断处理优先级的说法中，正确的是（ ）。<br>
A. 二者在所有系统中完全相同
B. 响应优先级用于多个请求的硬件判优，处理优先级还可能由屏蔽字调整
C. 处理优先级只由设备速度决定
D. 中断屏蔽会使所有请求永久丢失
:::

::: details 解析
答案：B。

响应优先级解决同时到达时先响应谁；允许嵌套时，处理优先级还取决于屏蔽关系。屏蔽通常表示暂不响应，并不必然丢弃请求。因此选 B。
:::

## 本节小结

异常和中断题应区分来源、同步性、返回地址、能否恢复以及硬件响应与软件处理各自完成的工作。
