<h1><center>第一节 I/O 接口</center></h1>

::: info 例 1.
下列功能中，不属于典型 I/O 接口基本功能的是（ ）。<br>
A. 地址译码和设备选择
B. 数据缓冲和格式转换
C. 保存设备状态
D. 执行用户程序中的全部算术运算
:::

::: details 解析
答案：D。

I/O 接口负责主机与外设之间的选择、控制、缓冲、状态和信号转换。普通算术运算由 CPU 或专用运算部件完成。因此选 D。
:::

::: info 例 2.
CPU 要检查设备是否就绪，通常应读取 I/O 接口的（ ）。<br>
A. 数据端口
B. 状态端口
C. 控制端口
D. 主存地址寄存器
:::

::: details 解析
答案：B。

状态端口保存就绪、忙、错误和中断请求等状态；数据端口传送数据，控制端口接收启动、复位等命令。因此选 B。
:::

::: info 例 3.
下列关于统一编址和独立编址的说法中，正确的是（ ）。<br>
A. 统一编址中 I/O 端口与主存共享地址空间
B. 统一编址必须使用专门 I/O 指令
C. 独立编址不能区分不同端口
D. 独立编址必然占用主存地址空间
:::

::: details 解析
答案：A。

统一编址把端口映射到主存地址空间，可使用普通访存指令访问；独立编址为 I/O 设置单独地址空间，通常使用专门 I/O 指令。因此选 A。
:::

::: info 例 4.
某独立编址的 I/O 空间有 10 位端口地址，若每个地址对应一个端口，则最多可区分（ ）个端口地址。<br>
A. 10<br>
B. 100<br>
C. 1024<br>
D. 2048
:::

::: details 解析
答案：C。

10 位地址共有 $2^{10}=1024$ 种编码。因此选 C。端口地址数量不一定等于物理外设数量，一个外设可以包含多个端口。
:::

## 本节小结

接口题要区分接口与端口：一个接口可以包含数据、状态和控制等多个逻辑端口，端口与物理寄存器也不一定严格一一对应。
