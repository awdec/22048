<h1><center>第二节 I/O 方式</center></h1>

::: info 例 1.
程序查询方式的主要特点是（ ）。<br>
A. CPU 反复读取设备状态，设备未就绪时可能忙等
B. 外设准备好后一定通过中断通知 CPU
C. 数据块由 DMA 控制器直接搬运
D. CPU 完全不参与控制
:::

::: details 解析
答案：A。

程序查询由 CPU 主动检查状态并在设备就绪后执行数据传送。若设备长时间未就绪，CPU 会浪费较多时间。短等待场景下轮询仍可能合理。因此选 A。
:::

::: info 例 2.
在典型程序中断方式中，外设数据与主存之间的数据传送通常由（ ）完成。<br>
A. CPU 执行中断服务程序
B. 外设绕过接口直接写主存
C. DMA 控制器在所有情况下完成
D. 链接器
:::

::: details 解析
答案：A。

中断减少 CPU 对设备状态的等待，但数据搬运通常仍由 CPU 在中断服务程序中执行。DMA 才主要由 DMA 控制器完成成批传送。因此选 A。
:::

::: info 例 3.
DMA 控制器开始一次主存到外设的块传送前，CPU 通常不需要设置（ ）。<br>
A. 主存起始地址
B. 传送方向
C. 传送数量
D. 每个数据字的算术运算结果
:::

::: details 解析
答案：D。

CPU 通常设置主存地址、传送方向、设备或通道信息和数据计数，然后启动 DMA。DMA 控制器自动更新地址和计数，不需要 CPU 预先给出每个数据字的算术结果。因此选 D。
:::

::: info 例 4.
下列关于 DMA 和中断的说法中，正确的是（ ）。<br>
A. 使用 DMA 后完全不再需要中断
B. DMA 传送的每个字节都必须经过 CPU 通用寄存器
C. DMA 可负责数据块传送，并在完成后用中断通知 CPU
D. DMA 控制器永远不能成为总线主设备
:::

::: details 解析
答案：C。

DMA 减少 CPU 对每个数据单位的参与，控制器获得主存或总线访问权后完成数据块传送，结束时通常通过中断通知 CPU 收尾。因此选 C。
:::

::: info 例 5.
允许中断嵌套时，一个高优先级请求能否打断正在执行的低优先级中断服务程序，主要还取决于（ ）。<br>
A. 是否开放中断且该请求未被屏蔽
B. 两个设备的数据宽度是否相同
C. 主存是否采用小端方式
D. 指令是否采用扩展操作码
:::

::: details 解析
答案：A。

优先级较高只是必要条件之一，还必须允许嵌套、开放中断并且该请求没有被屏蔽。因此选 A。
:::

## 本节小结

| 方式 | 谁等待或发现就绪 | 谁搬运数据 | CPU 主要开销 |
| --- | --- | --- | --- |
| 程序查询 | CPU 查询 | CPU | 查询与搬运 |
| 程序中断 | 设备请求、CPU 响应 | CPU 服务程序 | 响应、处理与搬运 |
| DMA | DMA 接收设备请求 | DMA 控制器 | 初始化与完成处理 |
