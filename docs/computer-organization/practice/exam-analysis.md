<h1><center>408 计算机组成原理考点分析</center></h1>

本页用于说明习题覆盖方式，具体考点范围以正文中的考点分析和当年考试大纲为准。

## 题型分布

| 模块 | 主要训练方式 |
| --- | --- |
| 系统概述 | 概念辨析、CPI、执行时间、MIPS、FLOPS |
| 数据表示与运算 | 编码转换、补码运算、溢出、IEEE 754 |
| 存储系统 | 芯片扩展、交叉编址、Cache、虚拟地址转换 |
| 指令系统 | 指令格式、有效地址、控制流和过程调用 |
| CPU | 微操作、控制器、异常中断、流水线和并行处理 |
| 总线 | 带宽、事务阶段、同步与异步定时 |
| I/O 系统 | 端口编址、程序查询、中断和 DMA |

## 答题原则

- 性能题统一使用执行时间、时钟周期数和有效数据量建立公式。
- 机器数题先确定位宽、编码和解释类型，再进行运算。
- Cache、TLB 和主存题先划分地址字段，再判断命中或转换过程。
- 数据通路题只允许题图中实际存在的连接和并行微操作。
- 中断、DMA 和总线题要区分硬件响应、软件处理与数据传送主体。

::: warning 范围说明
总线仲裁、复杂一致性协议、具体 ABI、复杂乱序调度算法等可用于关联理解，但不是现行 408 大纲明确要求展开掌握的独立核心考点。
:::
