<h1><center>第四节 CISC 和 RISC 的基本概念</center></h1>

::: info 例 1.
下列特征中，更符合典型 RISC 设计思想的是（ ）。<br>
Ⅰ. 指令格式规整<br>
Ⅱ. 大量指令可直接对主存操作数进行复杂运算<br>
Ⅲ. 采用 Load-store 结构<br>
Ⅳ. 便于流水线实现<br>
A. Ⅰ、Ⅱ<br>
B. Ⅰ、Ⅲ、Ⅳ<br>
C. Ⅱ、Ⅲ<br>
D. Ⅰ、Ⅱ、Ⅲ、Ⅳ
:::

::: details 解析
答案：B。

典型 RISC 强调简单规整的指令格式、较少的寻址方式和 Load-store 结构，有利于流水线。大量复杂的存储器操作数指令更符合传统 CISC 特征。因此选 B。
:::

::: info 例 2.
关于 CISC 和 RISC，下列说法正确的是（ ）。<br>
A. RISC 的指令种类一定少于所有 CISC<br>
B. CISC 一定采用微程序控制，RISC 一定采用硬布线控制<br>
C. 判断实际性能必须综合指令条数、CPI 和时钟周期<br>
D. RISC 程序的机器指令条数一定更少
:::

::: details 解析
答案：C。

两类设计思想不能用“必然”描述。程序执行时间满足：

$$
T_{CPU}=IC\times CPI\times T_c
$$

因此必须综合比较指令条数、平均 CPI 和时钟周期。因此选 C。
:::

::: info 例 3.
在典型 Load-store 指令系统中，完成 `R1 ← M[R2] + R3` 通常至少需要（ ）。<br>
A. 一条存储指令<br>
B. 一条装入指令和一条寄存器运算指令<br>
C. 一条条件转移指令<br>
D. 一条过程调用指令
:::

::: details 解析
答案：B。

Load-store 结构中，算术逻辑指令的操作数通常来自寄存器。应先用装入指令把 $M[R2]$ 读入寄存器，再执行寄存器加法。因此选 B。
:::

## 本节小结

- CISC 与 RISC 是设计取向，不是互斥的绝对标签。
- RISC 的核心不是“指令名字少”，而是规整、易译码、易流水化。
- 性能比较必须回到 $IC\times CPI\times T_c$，不能只看某一个指标。
