<h1><center>第三节 程序的机器级代码表示</center></h1>

::: info 例 1.
高级语言源程序通常经过下列哪个顺序形成可执行文件？<br>
A. 汇编→编译→装入→链接<br>
B. 编译→汇编→链接<br>
C. 链接→编译→汇编<br>
D. 编译→链接→汇编
:::

::: details 解析
答案：B。

典型过程是高级语言经编译生成汇编程序，汇编器生成可重定位目标文件，链接器合并目标文件和库并生成可执行文件。装入发生在可执行文件形成之后。因此选 B。
:::

::: info 例 2.
某抽象机器用 `CMP R1,R2` 设置条件码，用 `BGE L` 在 $R1\ge R2$ 时转移。下列指令序列最符合 `if (a < b) x = 1; else x = 2;` 的是（ ）。<br>
A. `CMP a,b; BGE ELSE; MOV x,1; JMP END; ELSE: MOV x,2; END:`<br>
B. `CMP a,b; BGE END; MOV x,2; END:`<br>
C. `CMP a,b; BGE ELSE; MOV x,2; JMP END; ELSE: MOV x,1; END:`<br>
D. `MOV x,1; MOV x,2`
:::

::: details 解析
答案：A。

当 $a\ge b$ 时应转到 `ELSE` 写入 2；否则顺序执行写入 1，并跳过 else 分支。因此选 A。
:::

::: info 例 3.
下列关于过程调用的说法中，错误的是（ ）。<br>
A. 调用指令需要以某种方式保存返回地址<br>
B. 栈帧可保存局部变量和被保存寄存器<br>
C. 所有参数都必须通过栈传递<br>
D. 调用者和被调用者应遵守约定的寄存器保存规则
:::

::: details 解析
答案：C。

参数可以通过寄存器、栈或二者结合传递，具体方式由调用约定规定。返回地址也可能压栈或写入链接寄存器。因此选 C。
:::

::: info 例 4.
某循环在进入循环体前令 `i=0`，循环末尾依次执行 `i=i+1` 和“若 `i<10` 则转回循环体”。循环体共执行（ ）次。<br>
A. 9<br>
B. 10<br>
C. 11<br>
D. 无法确定
:::

::: details 解析
答案：B。

循环体对应 $i=0,1,\ldots,9$，共 10 次。分析机器级循环时，应明确比较发生在自增之前还是之后，并检查条件转移方向。
:::

## 本节小结

机器级代码题不要求死记某一种汇编语法，重点是识别数据传送、比较、条件转移、循环回边、返回地址和栈帧等语义。
