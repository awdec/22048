<h1><center>第一节 指令系统</center></h1>

::: info 例 1.
下列内容中，属于指令集体系结构（ISA）规定的是（ ）。<br>
Ⅰ. 机器指令的格式和功能<br>
Ⅱ. 程序可见寄存器<br>
Ⅲ. Cache 的具体容量<br>
Ⅳ. 数据类型及寻址方式<br>
A. 仅Ⅰ、Ⅱ<br>
B. 仅Ⅰ、Ⅳ<br>
C. Ⅰ、Ⅱ、Ⅳ<br>
D. Ⅰ、Ⅱ、Ⅲ、Ⅳ
:::

::: details 解析
答案：C。

ISA 是软件与硬件之间的接口，规定机器指令、程序可见寄存器、数据类型、寻址方式以及异常等体系结构状态。Cache 的具体容量属于微体系结构实现，同一 ISA 的不同处理器可以采用不同 Cache 配置。因此选 C。
:::

::: info 例 2.
某计算机指令字长为 32 位，采用定长操作码，其中操作码占 8 位，其余字段均用于给出一个直接地址。按字节编址时，该指令最多可表示多少种操作，直接地址字段最多可表示多大的地址范围？<br>
A. 256 种操作，$2^{24}$ B<br>
B. 255 种操作，$2^{24}$ B<br>
C. 256 种操作，$2^{32}$ B<br>
D. 8 种操作，$2^{24}$ B
:::

::: details 解析
答案：A。

8 位操作码可形成 $2^8=256$ 种编码；直接地址字段为 $32-8=24$ 位，按字节编址时可表示 $2^{24}$ 个字节地址。因此选 A。
:::

::: info 例 3.
某 16 位指令含 4 位基本操作码和三个 4 位地址字段。现用其中 15 个基本操作码表示三地址指令，将剩余的 1 个基本操作码作为扩展标志，并用第一个地址字段扩展操作码，则最多可表示多少条二地址指令？<br>
A. 4<br>
B. 15<br>
C. 16<br>
D. 32
:::

::: details 解析
答案：C。

剩余的一个 4 位基本操作码作为前缀后，第一个 4 位地址字段改作扩展操作码，可形成 $2^4=16$ 个二地址操作码，后两个地址字段仍用于给出地址。因此选 C。
:::

::: info 例 4.
把汇编源程序转换为可重定位目标文件的系统软件是（ ）。<br>
A. 编译器<br>
B. 汇编器<br>
C. 链接器<br>
D. 装入程序
:::

::: details 解析
答案：B。

汇编器把助记符形式的汇编程序转换为机器指令编码，并生成包含符号表、重定位信息的目标文件。链接器负责合并目标文件并解析外部符号，装入程序负责把可执行文件映射到内存。因此选 B。
:::

## 本节小结

- ISA 描述程序可见的机器接口，不等于具体硬件实现。
- 定长操作码直接按操作码位数计算编码数。
- 扩展操作码以减少某类指令的地址字段为代价增加操作种类。
- 编译、汇编、链接和装入的输入、输出对象必须分清。
