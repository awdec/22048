<h1><center>第二节 寻址方式</center></h1>

::: info 例 1.
某指令的地址字段为 1200，执行该指令时存储单元 $M[1200]=3000$，$M[3000]=25$。若分别采用直接寻址和一次间接寻址，则取得的操作数依次为（ ）。<br>
A. 1200，3000<br>
B. 3000，25<br>
C. 25，3000<br>
D. 1200，25
:::

::: details 解析
答案：B。

直接寻址的有效地址为 1200，操作数为 $M[1200]=3000$。一次间接寻址先由 $M[1200]$ 得到有效地址 3000，再取得 $M[3000]=25$。因此选 B。
:::

::: info 例 2.
某相对转移指令采用“下一条指令地址 + 位移量”形成目标地址。该指令取指完成后 PC 的内容为 1004，指令中的补码位移量为 $-20$，则转移目标地址为（ ）。<br>
A. 980<br>
B. 984<br>
C. 1000<br>
D. 1024
:::

::: details 解析
答案：B。

题目明确以取指完成后的 PC 为基准，因此：

$$
EA=PC+(-20)=1004-20=984
$$

不能再次加上指令长度。因此选 B。
:::

::: info 例 3.
设基址寄存器内容为 4000，变址寄存器内容为 20，形式地址为 100。若采用基址—变址寻址，则有效地址为（ ）。<br>
A. 120<br>
B. 4020<br>
C. 4100<br>
D. 4120
:::

::: details 解析
答案：D。

基址—变址寻址通常按题设计算：

$$
EA=(BR)+(IX)+A=4000+20+100=4120
$$

因此选 D。基址、变址和形式地址各自承担的语义应服从具体 ISA，不能只背名称。
:::

::: info 例 4.
下列关于寻址方式的说法中，正确的是（ ）。<br>
A. 立即寻址的地址字段给出操作数的主存地址<br>
B. 寄存器间接寻址的操作数一定在寄存器中<br>
C. 相对寻址有利于实现位置无关的转移代码<br>
D. 隐含寻址不需要操作数
:::

::: details 解析
答案：C。

立即寻址的字段本身就是操作数；寄存器间接寻址由寄存器给出主存有效地址；隐含寻址只是操作数位置由操作码约定，并非没有操作数。相对地址随程序装入位置一起移动，适合构造位置无关转移。因此选 C。
:::

## 本节小结

有效地址题应按三步处理：先识别寻址方式，再写出有效地址公式，最后区分“有效地址”和“操作数”。相对寻址还必须确认 PC 采用当前指令地址还是下一条指令地址。
