<h1><center>第一节 总线概述</center></h1>

::: info 例 1.
在一次 DMA 传送的总线事务中，DMA 控制器取得总线控制权后通常扮演（ ）。<br>
A. 主设备
B. 从设备
C. 只读存储器
D. 算术逻辑部件
:::

::: details 解析
答案：A。

主设备发起事务，从设备响应事务。DMA 控制器获得总线控制权并发起主存读写时属于主设备；“主、从”描述的是一次事务中的角色。因此选 A。
:::

::: info 例 2.
某同步总线数据宽度为 64 位，工作频率为 200 MHz，每个时钟周期传送两次数据。忽略协议开销，其理论峰值带宽为（ ）。<br>
A. 1.6 GB/s<br>
B. 3.2 GB/s<br>
C. 12.8 GB/s<br>
D. 25.6 GB/s
:::

::: details 解析
答案：B。

64 位等于 8 B，每周期传送两次，因此：

$$
BW=8\text{ B}\times200\times10^6\times2
=3.2\times10^9\text{ B/s}
$$

所以选 B。
:::

::: info 例 3.
某系统按字节编址，地址总线宽度为 32 位，则理论可寻址范围为（ ）。<br>
A. $2^{32}$ bit<br>
B. $2^{32}$ B
C. 32 B<br>
D. 4 GB 个字
:::

::: details 解析
答案：B。

32 位地址可形成 $2^{32}$ 个不同地址，按字节编址时每个地址对应 1 B，因此理论地址空间为 $2^{32}$ B，即 4 GiB。因此选 B。
:::

::: info 例 4.
下列说法正确的是（ ）。<br>
A. 地址总线宽度决定一次能传送的数据位数
B. 数据总线宽度直接决定可寻址地址数量
C. 总线有效带宽通常低于理论峰值带宽
D. 串行总线一定比并行总线慢
:::

::: details 解析
答案：C。

地址宽度主要决定可区分的地址数量，数据宽度影响一次传送的数据量。协议开销、等待和仲裁会使有效带宽低于峰值。串行与并行的实际速度还取决于频率、通道数和协议效率。因此选 C。
:::

## 本节小结

总线性能计算的统一入口是：

$$
\text{有效带宽}=\frac{\text{有效数据量}}{\text{总时间}}
$$

峰值带宽只有在没有等待和协议开销时才可能达到。
