<h1><center>第二节 总线事务和定时</center></h1>

::: info 例 1.
一次典型读总线事务的合理逻辑顺序是（ ）。<br>
A. 返回数据→给出地址→发出读命令
B. 给出地址和读命令→从设备准备数据→传送并结束
C. 先写数据→再确定目标设备
D. 只需发出地址，不需要控制信息
:::

::: details 解析
答案：B。

主设备先指定目标地址和读命令，从设备译码并准备数据，随后双方在满足定时条件时传送数据并结束事务。因此选 B。
:::

::: info 例 2.
下列关于同步定时和异步定时的说法中，正确的是（ ）。<br>
A. 同步定时依靠统一时钟规定采样时刻
B. 异步定时完全没有任何时序约束
C. 同步定时一定比异步定时快
D. 异步定时不能连接速度不同的设备
:::

::: details 解析
答案：A。

同步定时使用共同的时钟边沿组织传送；异步定时依靠请求、应答等握手信号推进，但仍有建立时间、保持时间等约束。实际速度取决于设备和协议，不能绝对比较。因此选 A。
:::

::: info 例 3.
某突发读事务发送首地址和读命令需要 1 个周期，等待首个数据需要 4 个周期，随后连续传送 4 个数据，每个数据占 1 个周期。该事务共需（ ）个周期。<br>
A. 5<br>
B. 8<br>
C. 9<br>
D. 20
:::

::: details 解析
答案：C。

题目没有说明阶段重叠，因此直接相加：

$$
1+4+4=9
$$

个周期。突发传送只发送一次首地址，但仍要计入首个数据准备时间。因此选 C。
:::

::: info 例 4.
异步总线采用请求—应答握手的主要优点是（ ）。<br>
A. 不同速度的设备可以按实际完成时间协调传送
B. 永远不需要等待
C. 不需要地址和数据信号
D. 每次事务固定只占一个时钟周期
:::

::: details 解析
答案：A。

握手使事务按双方实际响应推进，适合连接速度差异较大的设备；代价是握手本身需要额外信号和时间。因此选 A。
:::

## 本节小结

总线定时题必须先画阶段，明确哪些阶段串行、哪些可以重叠，再从事务开始量到允许发起下一事务的时刻。
