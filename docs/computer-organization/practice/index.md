## 使用方法

1. 先独立写出判断依据或计算式，再展开解析。
2. 对地址划分、数据通路和流水线题，先画字段或时序，再代入数值。
3. 遇到“总是、一定、只能”等绝对表述，检查题目是否给出了足够条件。
4. 标为补充或拓展的题目用于理解边界，不应替代大纲核心内容的训练。
