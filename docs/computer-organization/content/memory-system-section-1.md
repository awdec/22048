<h1><center>第一节 存储器概述</center></h1>

存储器用于保存程序和数据。CPU 执行程序时不断从存储器取指令、读操作数并写回结果，因此存储系统的组织方式会直接影响整机的速度、容量和成本。

本节从四条主线建立存储系统的总体框架：

$$
\text{存储器分类}
\longrightarrow
\text{主存组成与操作}
\longrightarrow
\text{层次化结构}
\longrightarrow
\text{性能指标}
$$

## 1. 存储器的分类

同一种存储器可以按照不同标准分类。判断类别时，应先明确采用的是存储介质、存取方式、信息可保存性，还是它在计算机系统中的作用。

### 1.1 按在计算机系统中的作用分类

| 类型 | 所在位置和作用 | 主要特点 |
| --- | --- | --- |
| 寄存器 | 位于 CPU 内部，暂存指令、操作数、地址和状态 | 速度最快，容量最小，单位成本最高 |
| Cache | 位于 CPU 与主存之间，保存近期可能使用的主存块副本 | 对程序员通常透明，缓解 CPU 与主存的速度矛盾 |
| 主存储器 | 保存当前正在运行的程序和数据 | CPU 可以通过访存指令直接访问 |
| 辅助存储器 | 长期保存大量程序和数据，如磁盘、SSD | 容量大、单位成本低，CPU 通常不能用普通访存指令直接访问 |

辅助存储器中的程序和数据通常需要先调入主存，才能由 CPU 直接处理。

### 1.2 按存储介质分类

| 类型 | 基本原理 | 常见实例 |
| --- | --- | --- |
| 半导体存储器 | 利用半导体器件保存二进制信息 | SRAM、DRAM、ROM、Flash |
| 磁表面存储器 | 利用磁性材料的不同磁化状态保存信息 | 磁盘、磁带 |
| 光存储器 | 利用光学性质的差异记录和读取信息 | CD、DVD、BD |

半导体存储器速度通常较快，主要用于寄存器、Cache 和主存；磁盘、磁带和光盘主要用于大容量长期存储。

### 1.3 按存取方式分类

| 类型 | 存取特点 | 常见实例 |
| --- | --- | --- |
| 随机存取存储器 | 任意存储单元的存取时间基本相同，与其物理位置无关 | 半导体 RAM |
| 顺序存取存储器 | 必须按照信息的物理顺序依次查找 | 磁带 |
| 直接存取存储器 | 先直接定位到某一区域，再在该区域内顺序搜索 | 磁盘 |
| 相联存储器 | 根据内容的一部分进行检索，而不是只根据地址访问 | TLB、Cache 标记比较电路中的相联查找结构 |

::: warning 随机存取的含义
“随机存取”表示访问任意地址所需的时间基本相同，并不是随机挑选一个地址，也不表示数据可以随意摆放。
:::

### 1.4 按信息的可更改性分类

| 类型 | 特点 | 常见实例 |
| --- | --- | --- |
| 读写存储器 | 正常工作时既能读出，也能写入 | SRAM、DRAM |
| 只读存储器 | 正常使用时以读取为主，写入或擦除需要特定条件 | Mask ROM、PROM、EPROM、EEPROM、Flash |

“只读”描述的是正常使用方式。EEPROM 和 Flash 可以改写，但写入和擦除通常比普通 RAM 更受限制，所以仍属于广义 ROM 或非易失性半导体存储器。

### 1.5 按断电后信息是否保留分类

| 类型 | 断电后的状态 | 常见实例 |
| --- | --- | --- |
| 易失性存储器 | 信息丢失 | SRAM、DRAM |
| 非易失性存储器 | 信息仍可保留 | ROM、Flash、磁盘、光盘 |

“随机存取”和“易失性”是两个不同维度。例如，Flash 可以按地址读取且断电后不丢失信息，不能因为它具有随机读取能力就把它等同于通常所说的易失性 RAM。

## 2. 主存储器的组成和基本操作

### 2.1 主存储器的功能组成

从功能上看，主存储器主要由存储体、地址译码与驱动电路、读写控制电路以及数据输入/输出电路组成。为了说明 CPU 与主存之间的信息交换，通常还会引入存储器地址寄存器 MAR 和存储器数据寄存器 MDR。

| 部件 | 作用 |
| --- | --- |
| 存储体 | 由大量存储单元构成，实际保存二进制信息 |
| MAR | 保存本次要访问的存储单元地址 |
| 地址译码与驱动电路 | 将 MAR 中的地址译码，选中相应存储单元 |
| MDR | 暂存从主存读出的数据或准备写入主存的数据 |
| 读写控制电路 | 根据读、写和片选等控制信号完成存取操作 |

其基本信息流可以概括为：

$$
\text{地址}
\longrightarrow
MAR
\longrightarrow
\text{地址译码}
\longrightarrow
\text{存储体}
\longleftrightarrow
MDR
\longleftrightarrow
CPU
$$

::: info MAR 和 MDR 的位置
在组成原理的功能模型中，MAR 和 MDR 用来说明 CPU 与主存的接口。不同教材或实际计算机可能把它们画在 CPU 一侧、存储器一侧或存储器控制器中，但地址和数据必须经过相应的接口通路这一点不变。
:::

### 2.2 存储单元、存储字和存储字长

- **存储元**：保存一位二进制信息的物理单元。
- **存储单元**：具有一个独立地址、可作为一个整体访问的一组存储元。
- **存储字**：一个存储单元中保存的二进制代码组合。
- **存储字长**：一个存储字包含的二进制位数。

若一个存储器有 $M$ 个可寻址存储单元，每个存储单元保存 $N$ 位，则常写成：

$$
M\times N\text{ bit}
$$

其总容量为：

$$
C=M\times N\text{ bit}
$$

例如，$4K\times16\text{ bit}$ 表示有 $4K$ 个存储单元，每个存储单元为 $16$ 位，总容量为：

$$
4K\times16\text{ bit}
=64K\text{ bit}
=8\text{ KiB}
$$

在 408 容量计算中，未作特殊说明时通常取 $1K=2^{10}$。

### 2.3 编址方式

编址方式决定一个地址对应多少位数据。

| 编址方式 | 一个地址对应的内容 | 特点 |
| --- | --- | --- |
| 按字节编址 | $1$ 字节，即 $8$ 位 | 现代通用计算机最常见 |
| 按字编址 | $1$ 个存储字 | 地址单位取决于存储字长 |

若 MAR 有 $k$ 位，则最多可表示 $2^k$ 个不同地址。对应的最大可寻址范围为：

- 按字节编址：$2^k\text{ B}$；
- 按 $w$ 位字编址：$2^k\times w\text{ bit}$。

地址空间大小与实际安装的主存容量不一定相等。地址空间由地址位数和编址单位决定，实际主存可以只占其中一部分地址范围。

### 2.4 主存的读操作

主存读操作的基本过程如下：

1. CPU 将待读取单元的地址送入 MAR。
2. CPU 发出读命令。
3. 地址译码电路根据地址选中目标存储单元。
4. 被选中单元的内容经过读出电路送入 MDR。
5. CPU 从 MDR 取得数据。

可以概括为：

$$
MAR\leftarrow\text{地址}
\quad\Longrightarrow\quad
MDR\leftarrow M[MAR]
$$

其中，$M[MAR]$ 表示 MAR 所指向存储单元中的内容。读操作原则上不改变所读信息；若某种存储芯片的物理读出具有破坏性，存储器内部必须完成重写恢复。

### 2.5 主存的写操作

主存写操作的基本过程如下：

1. CPU 将目标地址送入 MAR。
2. CPU 将待写数据送入 MDR。
3. CPU 发出写命令。
4. 地址译码电路选中目标存储单元。
5. 读写控制电路把 MDR 中的数据写入该单元。

可以概括为：

$$
MAR\leftarrow\text{地址},
\qquad
MDR\leftarrow\text{数据}
\quad\Longrightarrow\quad
M[MAR]\leftarrow MDR
$$

写操作会用新内容覆盖目标单元的原有内容。实际读写还必须满足地址、数据和控制信号的建立时间、保持时间等时序要求。

## 3. 存储器的层次化结构

### 3.1 为什么需要层次化存储

单一存储器难以同时满足以下三个目标：

- 速度足够快；
- 容量足够大；
- 单位容量成本足够低。

通常，速度越快的存储器容量越小、单位成本越高；容量越大的存储器速度越慢、单位成本越低。计算机因此采用多级存储结构：

$$
\text{寄存器}
\longleftrightarrow
\text{Cache}
\longleftrightarrow
\text{主存}
\longleftrightarrow
\text{辅助存储器}
$$

从左向右，容量通常逐级增大，速度逐级降低，单位容量成本逐级降低。

| 层次 | 速度 | 容量 | 单位容量成本 | CPU 的访问方式 |
| --- | --- | --- | --- | --- |
| 寄存器 | 最快 | 最小 | 最高 | 指令显式或隐式使用 |
| Cache | 很快 | 较小 | 较高 | 硬件自动访问，对程序员通常透明 |
| 主存 | 较快 | 较大 | 较低 | CPU 通过访存指令访问 |
| 辅助存储器 | 最慢 | 最大 | 最低 | 通常经 I/O 系统访问，数据先调入主存 |

### 3.2 Cache—主存和主存—辅存层次

存储层次中有两组重要关系：

| 层次 | 主要解决的问题 | 信息交换单位 | 主要管理者 |
| --- | --- | --- | --- |
| Cache—主存 | CPU 与主存速度不匹配 | 块或 Cache 行 | 硬件 |
| 主存—辅存 | 主存容量不足 | 页或段 | 操作系统与硬件共同完成 |

Cache 未命中时，需要把包含目标数据的主存块调入 Cache；访问的虚拟页面不在主存时，会发生缺页，由操作系统把页面从辅助存储器调入主存。

### 3.3 局部性原理

层次化存储能够取得良好效果，依赖程序访问的局部性。

| 局部性 | 含义 | 典型例子 |
| --- | --- | --- |
| 时间局部性 | 最近访问过的信息在短时间内可能再次被访问 | 循环变量、循环体中的指令 |
| 空间局部性 | 访问某个地址后，其附近地址可能很快被访问 | 顺序取指、顺序遍历数组 |

Cache 利用时间和空间局部性，把近期使用的主存块保存在更靠近 CPU 的位置；虚拟存储器则只把当前活跃的页面保留在主存中。

### 3.4 层次化存储的整体效果

理想情况下，层次化存储希望从使用者角度呈现出：

- 接近高速存储器的访问速度；
- 接近低速存储器的容量；
- 接近低速存储器的单位容量成本。

这并不表示每次访问都能达到最高层速度。只有当所需信息在较高层命中时，才能避免访问更低、更慢的层次。

## 4. 存储器的主要性能指标

### 4.1 存储容量

存储容量表示存储器能够保存的二进制信息总量：

$$
\text{存储容量}
=
\text{存储单元数}
\times
\text{存储字长}
$$

常见单位有 bit、B、KiB、MiB 和 GiB。在组成原理容量题中通常使用二进制换算：

$$
1\text{ KiB}=2^{10}\text{ B},
\qquad
1\text{ MiB}=2^{20}\text{ B},
\qquad
1\text{ GiB}=2^{30}\text{ B}
$$

做题时必须先判断容量给的是位还是字节，并明确按字节编址还是按字编址。

### 4.2 存取时间

存取时间又称访问时间，记作 $T_A$，表示从启动一次存储器访问到完成该次访问所经历的时间。

- 读操作通常从地址和读命令有效开始，到数据稳定可用为止；
- 写操作通常从地址、数据和写命令有效开始，到写入完成为止。

存取时间越短，存储器速度越快。

### 4.3 存取周期

存取周期又称存储周期，记作 $T_M$，表示连续启动两次独立存储器访问所允许的最小时间间隔。

一般有：

$$
T_M\geq T_A
$$

原因是一次读写的有效访问完成后，存储器内部可能还需要恢复、预充电或刷新等操作，不能立刻启动下一次访问。

::: warning 存取时间与存取周期
存取时间描述“一次访问多久得到结果”，存取周期描述“两次访问最少隔多久”。两者概念不同，数值也不一定相等。
:::

### 4.4 存储器带宽

存储器带宽表示单位时间内存储器能够传输的数据量：

$$
B
=
\frac{\text{传输的数据量}}{\text{传输时间}}
$$

单位可以是 bit/s、B/s 或 word/s。若每个存取周期最多传输 $W$ 位，存取周期为 $T_M$，且各次访问不能重叠，则理论最大带宽为：

$$
B_{max}=\frac{W}{T_M}
$$

例如，每个存取周期传输 $64$ 位，$T_M=80\text{ ns}$，则理论最大带宽为：

$$
B_{max}
=
\frac{64}{80\times10^{-9}}
=800\text{ Mbit/s}
=100\text{ MB/s}
$$

采用多模块交叉存储、突发传输等技术后，可以让多次访问的部分阶段重叠，从而提高连续传输带宽。

### 4.5 单位容量成本

单位容量成本表示保存单位信息所需的成本，常用“成本/bit”衡量。通常有：

$$
\text{速度越快}
\quad\Longrightarrow\quad
\text{单位容量成本越高}
$$

存储系统追求的不是让所有数据都使用最快的器件，而是在满足性能要求的同时，用层次结构降低总体成本。

## 5. 408 常见考法与易错点

| 考点 | 解题入口 |
| --- | --- |
| 存储器分类 | 先判断分类依据，再确定存储器所属类别 |
| 主存组成 | 分清 MAR、MDR、译码器、存储体和控制电路的作用 |
| 读写过程 | 读操作是 $MDR\leftarrow M[MAR]$，写操作是 $M[MAR]\leftarrow MDR$ |
| 容量计算 | 使用“存储单元数 $\times$ 存储字长”，注意 bit 与 B |
| 地址计算 | 地址位数决定可寻址单元数，编址单位决定每个地址对应的数据量 |
| 存储层次 | 掌握速度、容量和单位成本的变化方向 |
| 局部性 | 区分时间局部性和空间局部性 |
| 性能指标 | 区分存取时间、存取周期和带宽 |

特别注意：

- RAM 的“随机”指访问时间基本与地址无关，不表示随机选择地址。
- SRAM 和 DRAM 都是易失性随机存取存储器，Flash 则是非易失性存储器。
- MAR 的位数决定最多能表示多少个地址，MDR 的位数表示一次接口传送的数据宽度；在简化模型中，MDR 位数通常等于存储字长，实际系统中二者也可能不同。
- 地址空间是处理器能够形成的地址范围，实际主存容量可能小于地址空间。
- 存储字长、机器字长和数据总线宽度是不同概念，题目没有明确说明时不能直接认为三者一定相等。
- CPU 通常不能用普通访存指令直接读取磁盘中的数据，数据需要经过 I/O 系统调入主存。
- Cache—主存层次主要解决速度问题，主存—辅存层次主要解决容量问题。
- 存取周期通常不小于存取时间，计算最大连续带宽时要看题目给出的访问组织方式。

## 6. 本节小结

本节的核心关系可以概括为：

$$
\text{存储介质和存取方式决定基本特性}
\longrightarrow
\text{主存通过地址、数据和控制通路完成读写}
\longrightarrow
\text{局部性支持多级存储结构}
\longrightarrow
\text{容量、速度、带宽和成本共同衡量性能}
$$

复习时既要掌握分类和概念，也要能够根据地址位数、存储字长、存取周期和传输宽度完成容量及带宽计算。
