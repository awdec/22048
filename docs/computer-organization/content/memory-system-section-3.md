<h1><center>第三节 主存储器与 CPU 的连接</center></h1>

主存储器与 CPU 的连接，本质上是正确组织地址、数据和控制信号，使 CPU 发出的每个主存地址都能选中唯一的存储芯片及片内单元，并按照规定的位宽完成读写。

本节围绕两条主线展开：

$$
\text{CPU 与主存的连接原理}
\longrightarrow
\text{主存容量的扩展}
$$

## 1. 连接原理

### 1.1 CPU 与主存之间的信息通路

CPU 与主存之间通过地址、数据和控制三类信号交换信息。

| 信号通路 | 方向 | 作用 |
| --- | --- | --- |
| 地址线 | CPU 指向主存 | 指明本次访问的地址 |
| 数据线 | CPU 与主存双向传送 | 读操作时主存向 CPU 传送数据，写操作时方向相反 |
| 控制线 | 主要由 CPU 或存储器控制器发出 | 传送片选、读、写、输出允许等控制信号 |

若 CPU 能够形成 $n$ 位主存地址，则最多可以区分：

$$
2^n
$$

个地址。若按字节编址，最大可寻址空间为：

$$
2^n\text{ B}
$$

数据总线宽度为 $w$ 位，表示一次总线传送最多可以并行传输 $w$ 位数据。地址线宽度决定“能够区分多少个地址”，数据线宽度决定“一次能够传输多少位”，二者不能混淆。

### 1.2 存储芯片的基本接口

典型存储芯片具有以下外部接口：

| 接口 | 常见标记 | 作用 |
| --- | --- | --- |
| 地址输入 | $A_0,A_1,\ldots$ | 选择芯片内部存储单元 |
| 数据输入/输出 | $D_0,D_1,\ldots$ | 传送读出或写入的数据 |
| 片选 | $CS$、$CE$ | 决定芯片是否参与本次访问 |
| 读或输出允许 | $RD$、$OE$ | 允许芯片把数据送到数据总线 |
| 写允许 | $WR$、$WE$ | 允许芯片接收数据并写入目标单元 |

信号名称上方带横线或名称末尾带 `#`，通常表示低电平有效，例如 $\overline{CS}$、$\overline{WE}$。

当片选无效时，芯片不响应读写操作，其输出通常呈高阻状态。这样多个芯片的数据端可以连接到同一组数据线上，而不会在任一时刻同时驱动出不同数据。

### 1.3 地址线的分配

CPU 地址通常分成两部分：

$$
\underbrace{\text{片选地址}}_{\text{选择芯片或芯片组}}
\quad
\underbrace{\text{片内地址}}_{\text{选择芯片内部单元}}
$$

若一片芯片有 $2^k$ 个可寻址单元，则需要 $k$ 位片内地址。通常把 CPU 的低 $k$ 位地址直接连接到芯片地址端，其余高位地址经过译码后产生片选信号。

例如，一片 $8K\times8\text{ bit}$ 芯片具有：

$$
8K=2^{13}
$$

个存储单元，因此需要 $13$ 根片内地址线。若 CPU 按字节编址，可以将 $A_0～A_{12}$ 用作片内地址，高位地址用于确定该芯片在主存地址空间中的位置。

::: warning 先确认编址单位
上面的连接适用于“一片芯片的一个单元对应 CPU 的一个地址单位”的情况。若 CPU 按字节编址，而一个存储字包含多个字节，还要处理字节偏移或字节使能，不能机械地把最低若干位全部作为芯片的字地址。
:::

### 1.4 片选与地址译码

地址译码的任务是根据 CPU 地址产生片选信号，使目标地址只选中应当工作的芯片或芯片组。

常见片选方法如下：

| 方法 | 连接方式 | 特点 |
| --- | --- | --- |
| 全译码法 | 除片内地址外的全部高位地址都参与译码 | 每个存储单元对应唯一系统地址，地址空间利用明确 |
| 部分译码法 | 只有部分高位地址参与译码 | 电路较简单，但未参与译码的地址位会造成地址重映射 |
| 线选法 | 直接使用某一根或少数地址线产生片选 | 电路最简单，但地址空间利用率低，容易出现多个等效地址 |

**地址重映射**是指多个不同的 CPU 地址访问到同一个物理存储单元。它来自未参与片选译码的高位地址，不表示芯片内部真的复制了多份数据。

全译码是 408 地址范围计算的重点。确定某组芯片的地址范围时，可以按以下步骤分析：

1. 根据单片或芯片组的字数确定片内地址位数。
2. 找出全部参与片选译码的高位地址。
3. 根据片选有效条件写出起始地址。
4. 用起始地址加容量再减 $1$ 得到结束地址。

若一段连续地址空间的起始地址为 $A$，包含 $C$ 个地址单元，则结束地址为：

$$
A+C-1
$$

例如，将一片 $8K\times8\text{ bit}$ 芯片映射到按字节编址系统的 `4000H` 开始处。因为：

$$
8K=2000H
$$

所以结束地址为：

$$
4000H+2000H-1=5FFFH
$$

### 1.5 CPU 读主存的过程

CPU 读取主存时，基本过程如下：

1. CPU 把目标地址送上地址线，并在规定时间内保持稳定。
2. 地址译码电路产生相应的片选信号。
3. CPU 或存储器控制器发出读命令，存储芯片允许数据输出。
4. 被选中的存储单元把数据送上数据线。
5. 数据稳定后，CPU 在规定时刻接收数据。
6. 读周期结束，芯片撤销输出，释放数据总线。

可以概括为：

$$
\text{给出地址}
\longrightarrow
\text{片选译码}
\longrightarrow
\text{读控制}
\longrightarrow
\text{主存驱动数据总线}
\longrightarrow
\text{CPU 接收数据}
$$

读操作中，数据总线由被选中的存储器驱动。其他芯片必须保持高阻状态，避免总线冲突。

### 1.6 CPU 写主存的过程

CPU 写入主存时，基本过程如下：

1. CPU 把目标地址送上地址线。
2. CPU 把待写数据送上数据线。
3. 地址译码电路产生相应的片选信号。
4. CPU 或存储器控制器发出写命令。
5. 被选中的存储芯片在规定时刻接收数据并写入目标单元。
6. 写周期结束，撤销片选和写控制信号。

可以概括为：

$$
\text{给出地址和数据}
\longrightarrow
\text{片选译码}
\longrightarrow
\text{写控制}
\longrightarrow
\text{存储器锁存数据}
$$

写操作中，数据总线由 CPU 驱动。地址、数据和写控制信号必须满足芯片规定的建立时间与保持时间。

### 1.7 控制信号的连接原则

- 同一时刻只能让目标芯片或目标芯片组响应访问。
- 读操作时，只允许被选中的芯片驱动数据总线。
- 写操作时，只有被选中的芯片接收数据总线上的内容。
- 多片芯片共同构成一个存储字时，它们应同时被片选并同时读写。
- 多组芯片用于扩充字数时，各组共享数据线，但片选信号必须互斥。
- 具体信号是高电平还是低电平有效，要以题图中的符号为准。

## 2. 主存容量的扩展

CPU 所需的主存字数或字长往往大于单片存储芯片的规格，需要组合多片芯片扩展容量。根据扩展方向，可以分为位扩展、字扩展和字位同时扩展。

### 2.1 芯片数量的基本计算

设目标主存规格为：

$$
M_T\times W_T\text{ bit}
$$

单片芯片规格为：

$$
M_C\times W_C\text{ bit}
$$

当字数和位数均能整除时：

$$
\text{字数方向的组数}
=
\frac{M_T}{M_C}
$$

$$
\text{每组位扩展所需芯片数}
=
\frac{W_T}{W_C}
$$

所需芯片总数为：

$$
N
=
\frac{M_T}{M_C}
\times
\frac{W_T}{W_C}
$$

若不能整除，应根据实际芯片规格向上取整，并注意由此产生的未使用存储单元或数据位。408 题目通常会给出能够整除的规格。

### 2.2 位扩展

位扩展用于增加存储字长，而存储字数不变。

例如，用 $1K\times4\text{ bit}$ 芯片组成 $1K\times8\text{ bit}$ 主存，需要：

$$
\frac{8}{4}=2
$$

片芯片。

连接方法如下：

- 两片芯片的地址线对应并联，共同接收同一个片内地址。
- 两片芯片使用相同的片选、读和写控制信号，同时工作。
- 第一片连接数据线 $D_0～D_3$，第二片连接 $D_4～D_7$。
- 两片分别提供同一个存储字的不同数据位。

位扩展可以概括为：

$$
1K\times4
+
1K\times4
\longrightarrow
1K\times8
$$

位扩展时，多片芯片在一次访问中同时被选中，而不是轮流工作。

### 2.3 字扩展

字扩展用于增加可寻址存储单元的数量，而存储字长不变。

例如，用 $1K\times8\text{ bit}$ 芯片组成 $4K\times8\text{ bit}$ 主存，需要：

$$
\frac{4K}{1K}=4
$$

片芯片。

因为：

$$
1K=2^{10}
$$

所以 CPU 的低 $10$ 位地址 $A_0～A_9$ 连接到每片芯片的片内地址端。还需要 $2$ 位高位地址 $A_{10}、A_{11}$ 经过 $2$—$4$ 译码器，从四片中选择一片。

四片芯片的数据端都连接到同一组 $D_0～D_7$，但任一时刻只允许被片选的一片驱动或接收数据总线。

若从地址 $000H$ 开始连续分配，地址范围如下：

| 芯片 | $A_{11}A_{10}$ | 地址范围 |
| --- | --- | --- |
| 芯片0 | $00$ | `000H～3FFH` |
| 芯片1 | $01$ | `400H～7FFH` |
| 芯片2 | $10$ | `800H～BFFH` |
| 芯片3 | $11$ | `C00H～FFFH` |

字扩展的核心连接原则是：低位地址并联用于片内寻址，高位地址译码用于选择芯片。

### 2.4 字位同时扩展

字位同时扩展既增加存储字数，又增加存储字长。

例如，用 $2K\times4\text{ bit}$ 芯片组成 $8K\times16\text{ bit}$ 主存：

$$
\text{字数方向组数}
=
\frac{8K}{2K}
=4
$$

$$
\text{每组芯片数}
=
\frac{16}{4}
=4
$$

因此总芯片数为：

$$
4\times4=16
$$

具体连接如下：

- 每组 $4$ 片芯片进行位扩展，分别连接 $D_0～D_3$、$D_4～D_7$、$D_8～D_{11}$ 和 $D_{12}～D_{15}$。
- $2K=2^{11}$，因此 $A_0～A_{10}$ 连接所有芯片，作为片内地址。
- $4$ 个字数组需要 $2$ 位片选地址，因此 $A_{11}、A_{12}$ 经过 $2$—$4$ 译码器选择其中一组。
- 同一组内的 $4$ 片芯片共用片选和读写控制信号，同时工作。

字位同时扩展时，应先按位数组成一个完整存储字，再按字数把这些芯片组排列到不同地址范围。

### 2.5 存储芯片组与数据总线

扩展后的每个芯片组必须能够提供 CPU 一次主存访问所需的数据宽度。

若 CPU 数据总线为 $W$ 位，而单片芯片为 $w$ 位，则一组通常需要：

$$
\frac{W}{w}
$$

片芯片同时工作。各芯片负责数据总线中不同的位段。

若 CPU 按字节编址且数据总线一次可以传送多个字节，实际系统还可能设置字节使能信号，以便只读写一个存储字中的部分字节。408 基础连接题若未给出字节使能，通常按照题目给定的存储字长和总线宽度处理。

### 2.6 RAM 与 ROM 的统一编址

RAM 和 ROM 可以占用 CPU 统一主存地址空间中的不同区间。连接时：

- 低位地址用于各芯片内部寻址；
- 高位地址译码后分别产生 RAM 和 ROM 的片选信号；
- 数据端可以共享数据总线；
- ROM 只需要读控制，RAM 同时需要读、写控制；
- 各存储区地址范围不能在全译码条件下发生非预期重叠。

设计地址分配时，通常先根据系统要求确定每个存储区的起始地址和容量，再由地址范围反推高位地址的片选条件。

### 2.7 主存扩展题的解题步骤

遇到芯片连接题时，可以按以下顺序分析：

1. **统一单位**：明确目标和芯片规格中的字数、位数及编址单位。
2. **比较字长**：计算每组需要几片芯片进行位扩展。
3. **比较字数**：计算需要多少个芯片组进行字扩展。
4. **计算芯片总数**：组数乘以每组芯片数。
5. **分配数据线**：同组芯片分别连接数据总线的不同位段。
6. **分配片内地址线**：由单片芯片的字数确定所需低位地址线。
7. **生成片选信号**：其余高位地址经译码选择芯片组。
8. **确定地址范围**：写出每组起始地址和结束地址。
9. **检查控制信号**：确认同组同时选中、不同组互斥，并注意有效电平。

## 3. 408 常见考法与易错点

| 考点 | 解题入口 |
| --- | --- |
| 总线作用 | 地址线确定地址，数据线传送数据，控制线规定操作 |
| 芯片接口 | 分清片选、输出允许和写允许信号 |
| 片内地址 | 由单片芯片的可寻址单元数确定 |
| 片选译码 | 使用高位地址选择芯片或芯片组 |
| 地址范围 | 起始地址加地址单元数再减 $1$ |
| 位扩展 | 地址和控制线并联，数据线分位连接 |
| 字扩展 | 低位地址并联，高位地址译码，数据线共享 |
| 字位扩展 | 先求每组芯片数，再求芯片组数 |

特别注意：

- 地址总线宽度决定最多能形成多少个地址，数据总线宽度决定一次传输的数据位数。
- 芯片规格中的“字数”决定片内地址线数量，“位数”决定单片能够提供的数据位数。
- 位扩展时同组芯片必须同时工作；字扩展时通常一次只选中一个芯片组。
- 全译码中每个物理存储单元具有唯一系统地址；部分译码可能产生多个等效地址。
- 片选信号、读信号和写信号可能低电平有效，必须根据逻辑图判断。
- 多片芯片共享数据总线时，未被选中的芯片必须处于高阻状态。
- 结束地址等于起始地址加地址单元数再减 $1$，不能直接加容量后作为结束地址。
- 按字节编址的系统中，一个多字节存储字可能涉及字节偏移或字节使能，应以题设连接方式为准。

## 4. 本节小结

主存与 CPU 的连接可以归结为：

$$
\text{低位地址完成片内寻址}
\quad
\text{高位地址完成片选译码}
\quad
\text{数据线匹配存储字长}
\quad
\text{控制线规定读写操作}
$$

容量扩展题的核心是先分清扩展方向：位扩展增加字长，字扩展增加存储单元数量，字位同时扩展则把若干位扩展芯片组成一组，再通过高位地址选择不同芯片组。
