<h1><center>第六章 总线</center></h1>

## 本章定位

总线是连接 CPU、主存储器和 I/O 设备的信息通路。

前面几章分别讨论了 CPU、存储器和 I/O 系统中的部件，本章关注这些部件之间如何交换地址、数据和控制信息。

按照考研 408 计算机组成原理的复习要求，总线部分主要把握两条主线：

1. 总线的基本概念、信号组成和性能指标，并以分类和互连结构辅助理解。
2. 一次总线传输如何发生，定时方式如何保证主设备和从设备协调工作。

## 本章内容

### 第一节 总线概述

主要内容：

- 总线的分类（基础补充）
- 总线的性能指标
- 总线的组成与结构（单总线、双总线和多总线结构为扩展）

学习目标：

- 能理解总线的共享性、分时性以及主设备、从设备的基本概念。
- 能区分地址总线、数据总线和控制总线的作用。
- 能理解总线宽度、工作频率、总线周期、带宽和利用率之间的关系。
- 扩展了解总线分类以及单总线、双总线和多总线结构的特点。

### 第二节 总线事务和定时

主要内容：

- 总线事务
- 总线定时

学习目标：

- 能描述读、写和突发事务的基本阶段与数据方向。
- 能区分时钟周期、总线周期、存储周期和指令周期。
- 能比较同步定时和异步定时，理解等待状态与握手信号的作用。
- 能根据事务时序计算传输时间和有效带宽。

## 学习主线

总线章节可以按下面的逻辑理解：

$$
\text{部件互连}
\rightarrow
\text{共享通路}
\rightarrow
\text{组成与性能}
\rightarrow
\text{总线事务}
\rightarrow
\text{定时控制}
\rightarrow
\text{性能计算}
$$

也可以记成一句话：

> 学习总线时，先明确“连接谁、传什么”，再分析“怎样传”，最后计算“传得多快”。

## 408 常见考点

| 考点 | 要求 |
| --- | --- |
| 总线基本概念 | 理解共享性、分时性以及主设备和从设备 |
| 总线组成 | 掌握地址总线、数据总线、控制总线的作用 |
| 总线性能 | 会计算总线带宽、总传输时间 |
| 总线事务 | 会分析读事务、写事务和突发事务的基本流程 |
| 总线定时 | 比较同步定时与异步定时，分析等待和握手过程 |

## 易错点

- 数据总线宽度影响一次能传多少数据，地址总线宽度影响可寻址空间大小。
- 总线周期不等于时钟周期。一个总线周期通常包含多个时钟周期。
- 总线带宽不仅由数据线宽度决定，还与总线频率、传输次数和协议开销有关。
- （基础补充）并行总线不一定比串行总线快，应综合比较频率、通道数和协议效率。
- （扩展）多总线结构可以分散负载，但会增加桥接延迟和控制复杂度。
- 同步定时不是一定最快，若连接慢速设备，可能需要插入等待周期。
- 异步定时适合速度差异较大的设备，但握手控制较复杂。
- （扩展）分离事务只是把请求与响应拆开，并不是同步、异步之外的第三种基本定时方式。
