<h1><center>第二节 计算机的性能指标</center></h1>

现行 408 大纲在本节明确要求掌握：吞吐量、响应时间，CPU 时钟周期、主频、CPI、CPU 执行时间，以及 MIPS 和各级 FLOPS。本节围绕这些指标建立统一的性能分析方法。

## 1. 计算机性能的基本概念

### 1.1 性能与执行时间

对同一个任务，执行时间越短，计算机性能越高。因此：

$$
\text{性能}
\propto
\frac{1}{\text{执行时间}}
$$

若计算机 $X$ 和 $Y$ 执行同一个程序的时间分别为 $T_X$ 和 $T_Y$，则：

$$
\frac{P_X}{P_Y}
=
\frac{T_Y}{T_X}
$$

例如，$X$ 和 $Y$ 执行同一个程序分别需要 $2\text{ s}$ 和 $5\text{ s}$，则：

$$
\frac{P_X}{P_Y}
=
\frac{5}{2}
=
2.5
$$

即 $X$ 的性能是 $Y$ 的 $2.5$ 倍。

::: warning 注意
“性能是原来的 $2.5$ 倍”表示性能提高了 $150\%$，不能表述为“性能提高了 $2.5$ 倍”。做题时要区分“是原来的多少倍”和“提高了多少倍”。
:::

### 1.2 响应时间与吞吐量

| 指标 | 含义 | 关注的问题 |
| --- | --- | --- |
| 响应时间 | 从任务提交到任务完成所经历的总时间 | 一个任务多久完成 |
| 吞吐量 | 单位时间内系统完成的任务数量 | 单位时间能完成多少任务 |

响应时间通常包括 CPU 计算、访存、I/O 和等待等时间；CPU 执行时间只统计 CPU 为该程序工作的时间。

提高处理器速度通常有助于缩短响应时间，并可能提高吞吐量；增加处理器数量更可能提高系统吞吐量，但不一定按相同比例缩短单个任务的响应时间。

::: tip 评价原则
比较计算机性能时，应在相同任务、相同输入和相同统计口径下比较实际执行时间。只比较主频、CPI 或 MIPS 中的某一个数值，结论通常不可靠。
:::

## 2. CPU 时钟周期与主频

### 2.1 基本概念

时钟周期是时钟信号重复一次所需的时间，也可以理解为相邻两个同类有效时钟边沿之间的时间。主频是单位时间内的时钟周期数。

$$
f=\frac{1}{T_c}
$$

其中：

- $f$ 为 CPU 主频，单位是赫兹（Hz）。
- $T_c$ 为 CPU 时钟周期，单位是秒（s）。

时钟周期与时钟脉冲的高电平宽度或低电平宽度不是同一个概念。

### 2.2 主频与周期换算

若 CPU 主频为 $2.5\text{ GHz}$，则时钟周期为：

$$
T_c
=
\frac{1}{2.5\times10^9}\text{ s}
=
0.4\text{ ns}
$$

常用单位如下：

| 时间单位 | 换算 | 频率单位 | 换算 |
| --- | --- | --- | --- |
| $1\text{ ms}$ | $10^{-3}\text{ s}$ | $1\text{ kHz}$ | $10^3\text{ Hz}$ |
| $1\,\mu\text{s}$ | $10^{-6}\text{ s}$ | $1\text{ MHz}$ | $10^6\text{ Hz}$ |
| $1\text{ ns}$ | $10^{-9}\text{ s}$ | $1\text{ GHz}$ | $10^9\text{ Hz}$ |
| $1\text{ ps}$ | $10^{-12}\text{ s}$ | $1\text{ THz}$ | $10^{12}\text{ Hz}$ |

主频越高，表示 CPU 每秒包含的时钟周期越多；但程序执行时间还受到指令条数和 CPI 的影响，因此主频更高不代表程序一定执行得更快。

## 3. CPI 与 CPU 执行时间

### 3.1 指令条数

指令条数（Instruction Count，IC）是执行一个程序所需的机器指令总数，主要受到以下因素影响：

- 算法。
- 程序设计语言。
- 编译器及其优化策略。
- 指令集体系结构。

同一个高级语言程序使用不同编译器或不同 ISA 时，生成的指令条数可能不同。

### 3.2 CPI 与平均 CPI

CPI（Cycles Per Instruction）表示执行每条指令平均需要的时钟周期数：

$$
CPI
=
\frac{\text{程序执行所需的时钟周期总数}}{\text{程序的指令条数}}
$$

若第 $i$ 类指令占程序指令总数的比例为 $p_i$，该类指令的 CPI 为 $CPI_i$，则平均 CPI 为：

$$
CPI
=
\sum_{i=1}^{n}p_iCPI_i
$$

若已知各类指令条数 $IC_i$，则：

$$
CPI
=
\frac{\sum_{i=1}^{n}IC_iCPI_i}{\sum_{i=1}^{n}IC_i}
$$

::: warning 易错点
平均 CPI 必须按各类指令的条数或比例加权，不能直接对各类指令的 CPI 求算术平均数。
:::

### 3.3 CPU 执行时间公式

程序执行所需的时钟周期总数为：

$$
\text{时钟周期总数}=IC\times CPI
$$

因此：

$$
T_{CPU}
=
IC\times CPI\times T_c
$$

又因为 $T_c=1/f$，所以：

$$
\boxed{
T_{CPU}
=
\frac{IC\times CPI}{f}
}
$$

| 因素 | 主要影响来源 |
| --- | --- |
| 指令条数 $IC$ | 算法、语言、编译器、ISA |
| 平均 CPI | 指令组成、CPU 结构、流水线、Cache 等 |
| 主频 $f$ | 时钟设计、关键路径和制造工艺 |

例如，某程序包含 $1.2\times10^9$ 条指令，平均 $CPI=1.5$，CPU 主频为 $3\text{ GHz}$，则：

$$
T_{CPU}
=
\frac{1.2\times10^9\times1.5}{3\times10^9}
=
0.6\text{ s}
$$

比较两台计算机时，应先确认它们执行的是不是同一个程序，以及 $IC$、$CPI$ 和 $f$ 中哪些量发生了变化。

::: tip 拓展辨析：IPC
IPC（Instructions Per Cycle）表示平均每个时钟周期执行的指令条数。在统计对象和统计范围一致时：

$$
IPC=\frac{1}{CPI}
$$

IPC 未被现行大纲单独列为本节考点，可用于辅助理解 CPI，复习时不必脱离 CPI 单独展开。
:::

## 4. MIPS

MIPS（Million Instructions Per Second）表示每秒执行多少百万条机器指令：

$$
MIPS
=
\frac{IC}{T_{CPU}\times10^6}
$$

代入 CPU 执行时间公式可得：

$$
MIPS
=
\frac{f}{CPI\times10^6}
$$

使用该公式时，$f$ 应以 Hz 为单位，CPI 应为相应程序的平均 CPI。

MIPS 存在明显局限：

- 不同 ISA 的一条指令完成的工作量可能不同。
- 同一计算机运行不同程序时，平均 CPI 和 MIPS 可能不同。
- MIPS 没有反映完成任务所需的指令总数。
- MIPS 高不代表完成同一个任务所需的时间一定更短。

因此，不能脱离具体程序，直接使用 MIPS 比较不同指令系统的计算机。

## 5. FLOPS

FLOPS（Floating-point Operations Per Second）表示每秒完成的浮点运算次数：

$$
FLOPS
=
\frac{\text{浮点运算次数}}{\text{执行时间}}
$$

现行 408 大纲明确列出的单位如下：

| 单位 | 数量级 |
| --- | --- |
| MFLOPS | $10^6$ FLOPS |
| GFLOPS | $10^9$ FLOPS |
| TFLOPS | $10^{12}$ FLOPS |
| PFLOPS | $10^{15}$ FLOPS |
| EFLOPS | $10^{18}$ FLOPS |
| ZFLOPS | $10^{21}$ FLOPS |

FLOPS 常用于评价浮点密集型任务。理论峰值 FLOPS 描述理想条件下的最大能力，实际程序通常只能达到其中一部分。

MIPS 统计机器指令，FLOPS 统计浮点运算，二者统计对象不同，不能直接换算。

## 6. 408 常见考法与易错点

| 考法 | 解题入口 |
| --- | --- |
| 吞吐量与响应时间 | 分清系统处理能力与单个任务完成时间 |
| 主频与周期换算 | 使用 $f=1/T_c$ |
| 平均 CPI | 按各类指令的条数或比例加权 |
| CPU 执行时间 | 使用 $T_{CPU}=IC\times CPI/f$ |
| MIPS | 使用 $MIPS=f/(CPI\times10^6)$，并检查适用范围 |
| FLOPS | 分清浮点运算次数、执行时间和单位数量级 |
| 性能比较 | 性能之比等于执行时间之比的倒数 |

需要特别避免以下错误：

- 仅凭主频高低判断两台计算机的实际性能。
- 把 CPI 当成每一条指令都固定需要的周期数。
- 计算平均 CPI 时忘记按指令比例加权。
- 指令系统或编译器变化后，仍假定指令条数不变。
- 用 MIPS 直接比较不同 ISA 的计算机。
- 混淆吞吐量与响应时间。
- 混淆“性能是原来的多少倍”和“性能提高了多少倍”。
- 混淆 MFLOPS、GFLOPS、TFLOPS、PFLOPS、EFLOPS 和 ZFLOPS 的数量级。

## 7. 本节小结

本节最重要的计算主线是：

$$
\text{时钟周期总数}
=
IC\times CPI
$$

$$
\boxed{
T_{CPU}
=
\frac{IC\times CPI}{f}
}
$$

复习时应抓住三点：

1. 完成同一个任务所需的执行时间，是比较性能最直接的依据。
2. 指令条数、CPI 和主频共同决定 CPU 执行时间，单一指标不能代表整机性能。
3. 吞吐量、响应时间、MIPS 和 FLOPS 分别反映不同方面，比较时必须统一任务、条件和统计口径。
