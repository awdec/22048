<h1><center>第二节 主存储器</center></h1>

现代主存主要由半导体存储器构成。本节围绕三类核心问题展开：SRAM 和 DRAM 如何保存信息，非易失性存储器如何在断电后保留信息，以及多模块存储器如何提高连续访存带宽。

$$
\text{半导体随机存取存储器}
\longrightarrow
\text{非易失性存储器}
\longrightarrow
\text{多模块存储器}
$$

## 1. 半导体随机存取存储器

半导体随机存取存储器通常简称 RAM。其任意存储单元都可以通过地址直接选中，而且不同地址的存取时间基本相同。

RAM 在正常工作时可以反复读写，但断电后信息通常会丢失，因此 SRAM 和 DRAM 都属于易失性存储器。

### 1.1 RAM 芯片的基本结构

半导体 RAM 芯片通常包含以下部分：

| 部件 | 作用 |
| --- | --- |
| 存储矩阵 | 由大量存储元构成，保存二进制信息 |
| 地址译码器 | 根据地址选中相应的存储单元或存储行、列 |
| 读写电路 | 完成数据的读出、放大和写入 |
| 地址引脚 | 接收片内地址 |
| 数据引脚 | 输入或输出数据 |
| 控制引脚 | 接收片选、读、写或输出允许等控制信号 |

若芯片规格为：

$$
2^k\times w\text{ bit}
$$

则芯片包含 $2^k$ 个可寻址单元，每个单元为 $w$ 位。一般需要 $k$ 根片内地址线和 $w$ 根数据线；若地址采用分时复用，实际地址引脚数可以少于 $k$。

片选信号无效时，芯片通常不响应读写命令，其数据输出处于高阻状态，以便多个芯片共享数据总线。

### 1.2 SRAM

SRAM 是静态随机存取存储器。其存储元通常使用双稳态电路保存一位信息，只要保持供电且没有新的写入，状态就能稳定保持，不需要周期性刷新。

SRAM 的主要特点：

- 读写速度快；
- 不需要刷新；
- 存储元所需晶体管较多，集成度相对较低；
- 单位容量成本较高；
- 断电后信息仍会丢失；
- 常用于 Cache 等高速小容量存储器。

::: warning “静态”的含义
SRAM 的“静态”表示通电期间无须刷新，不表示它是非易失性存储器。SRAM 断电后同样不能保留信息。
:::

### 1.3 DRAM

DRAM 是动态随机存取存储器。其存储元利用电容上的电荷状态表示一位信息。由于电荷会逐渐泄漏，即使没有读写，信息也只能保持有限时间，因此必须定期刷新。

DRAM 的主要特点：

- 存储元结构简单，集成度高；
- 容量大，单位容量成本低；
- 速度通常慢于 SRAM；
- 需要周期性刷新；
- 读取通常具有破坏性，读出后需要恢复原数据；
- 常用作计算机主存。

SRAM 与 DRAM 的核心区别如下：

| 项目 | SRAM | DRAM |
| --- | --- | --- |
| 基本存储元 | 双稳态电路 | 电容及访问晶体管 |
| 是否需要刷新 | 不需要 | 需要 |
| 读出是否通常具有破坏性 | 否 | 是，读后需要恢复 |
| 速度 | 较快 | 较慢 |
| 集成度 | 较低 | 较高 |
| 单位容量成本 | 较高 | 较低 |
| 典型用途 | Cache | 主存 |
| 断电后是否保留信息 | 否 | 否 |

### 1.4 DRAM 地址复用

DRAM 存储矩阵通常按行和列组织。访问某个单元时，先给出行地址，再给出列地址。行地址和列地址可以分时共用同一组地址引脚，从而减少芯片引脚数量。

若 DRAM 矩阵有 $2^r$ 行、$2^c$ 列，则完整地址需要 $r+c$ 位；采用行、列地址分时复用后，地址引脚数通常只需：

$$
\max(r,c)
$$

地址复用减少的是芯片地址引脚数量，不会减少芯片内部可寻址单元数量，也不会改变存储容量。

### 1.5 DRAM 刷新

刷新是把 DRAM 存储元中的信息读出并重新写入，以补偿电容电荷泄漏的过程。刷新通常具有以下特点：

- 按存储矩阵的行进行；
- 每次刷新一行中的多个存储元；
- 由存储器控制器和刷新地址计数器组织；
- 刷新期间，相应存储体通常不能完成普通读写；
- 刷新只需要行地址，不需要把数据传送给 CPU。

设 DRAM 有 $R$ 行，要求所有行在最大刷新间隔 $T_R$ 内至少刷新一次，则平均每隔：

$$
t=\frac{T_R}{R}
$$

至少应安排一次按行刷新。

常见刷新方式如下：

| 刷新方式 | 组织方法 | 主要影响 |
| --- | --- | --- |
| 集中刷新 | 在最大刷新间隔中的一段时间内，连续刷新所有行 | 会形成一段不能正常访存的刷新死区 |
| 分散刷新 | 把一次正常访存和一次刷新安排在成对的周期中 | 没有很长的集中死区，但每个基本访存周期都受到影响 |
| 异步刷新 | 将各行刷新均匀分散在最大刷新间隔内 | 兼顾死区长度和正常访存效率，较为常用 |

::: tip 刷新次数的判断
刷新次数由存储矩阵的行数决定，而不是由芯片的总存储单元数直接决定。题目给出多个 DRAM 芯片时，还要判断它们能否共享同一个刷新行地址并同时刷新。
:::

### 1.6 DRAM 芯片和内存条

实际主存通常不是由一片 DRAM 芯片单独构成，而是把多片 DRAM 芯片安装在印制电路板上，组成内存条。内存条也称内存模块，常见外形为 DIMM。

#### DRAM 芯片的组织形式

一片 DRAM 芯片常写成：

$$
M\times w\text{ bit}
$$

其中，$M$ 表示芯片内部可寻址单元数，$w$ 表示每次读写能够提供的数据位数。按 408 容量题常用的二进制换算，$1G=2^{30}$。例如，$1G\times8\text{ bit}$ 芯片共有 $1G$ 个地址单元，每个单元为 $8$ 位，芯片总容量为：

$$
1G\times8\text{ bit}=8\text{ Gbit}=1\text{ GiB}
$$

这里的 $\times8$ 描述芯片的数据宽度，不表示芯片只有 $8$ 个存储单元。

#### 芯片组与 Rank

当一片 DRAM 芯片的数据宽度小于主存数据通路宽度时，需要多片芯片并行工作。共同提供一个完整存储字或一次完整数据传输的芯片集合称为一个芯片组，在现代内存条中通常对应一个 Rank。

同一 Rank 内的芯片具有以下连接特点：

- 共享地址信号和主要控制信号；
- 在同一次访问中同时被选中；
- 分别连接数据总线的不同位段；
- 合起来提供内存条规定的数据宽度。

例如，用 $1G\times8\text{ bit}$ 芯片组成 $64$ 位数据宽度的 Rank，需要：

$$
\frac{64}{8}=8
$$

片芯片。该 Rank 的组织形式为：

$$
1G\times64\text{ bit}
$$

总数据容量为：

$$
1G\times64\text{ bit}=8\text{ GiB}
$$

若内存条支持纠错码，还可能增加专门保存校验位的芯片。例如，$64$ 位数据加 $8$ 位校验信息时，内存条数据通路可组织为 $72$ 位；是否计算校验位容量应以题目说明为准。

#### 内存条的基本连接

内存条通过金手指与内存控制器相连，主要传送地址、数据和控制信号。一条内存条可以包含一个或多个 Rank：

- Rank 选择信号决定本次由哪个芯片组响应；
- Rank 内各芯片共享地址和控制信号，并行提供数据；
- 不同 Rank 可以共享内存条的数据引脚，但同一时刻只有被选中的 Rank 驱动数据通路；
- DRAM 芯片内部的 Bank、内存条上的 Rank 和多模块存储器中的存储模块是不同层次的概念，不能混用。

::: tip 408 解题入口
遇到内存条容量题时，先根据芯片数据宽度求一个 Rank 需要的并行芯片数，再根据 Rank 数量求整条内存条容量。若题目给出 ECC 芯片，应先判断容量是只统计数据位，还是连同校验位一起统计。
:::

### 1.7 SRAM、DRAM 易错结论

- SRAM 和 DRAM 都能随机存取，也都能正常读写。
- SRAM 不刷新，DRAM 必须刷新。
- DRAM 的刷新与普通读操作后的恢复不是同一个概念：刷新是周期性维持信息，读后恢复是破坏性读出的后续动作。
- SRAM 和 DRAM 都是易失性的，不能用“是否刷新”判断断电后信息是否保留。
- DRAM 地址复用减少引脚，不减少地址位数所表达的地址信息。

## 2. 非易失性存储器

非易失性存储器在断电后仍能保留信息。主存系统中常见的非易失性半导体存储器包括各种 ROM 和 Flash。

### 2.1 ROM 的基本特点

ROM 是只读存储器的统称。它在正常工作时以读出为主，写入或擦除通常需要专门的操作、设备或较长时间。

ROM 的主要特点：

- 断电后能够保存信息；
- 读取时仍然可以根据地址随机访问；
- 适合保存启动程序、固件和较少修改的数据；
- “只读”不等于绝对不能改写，不同 ROM 的写入方式不同。

### 2.2 ROM 的主要类型（扩展）

| 类型 | 写入与擦除方式 | 主要特点 |
| --- | --- | --- |
| Mask ROM | 制造时写入 | 内容固定，批量生产成本低，不能由用户改写 |
| PROM | 用户使用专用设备写入一次 | 写入后通常不能擦除 |
| EPROM | 使用紫外线整体擦除，再重新写入 | 擦除时通常需要从系统中取下芯片 |
| EEPROM | 可用电信号擦除和写入 | 可在线改写，通常能以字节或较小单位更新 |
| Flash | 使用电信号写入，通常按块擦除 | 集成度高、容量大，广泛用于固态存储 |

这些器件从 Mask ROM 到 EEPROM、Flash，可改写能力逐渐增强，但写入和擦除一般仍比普通 RAM 读取慢。

### 2.3 Flash 存储器

Flash 是一种可电擦除、可重新编程的非易失性半导体存储器。它兼有较快的随机读取能力和断电保存信息的能力。

Flash 的主要特点：

- 读取可以按地址进行；
- 写入前通常需要满足相应页面或块的状态要求；
- 擦除通常以块为单位，不能像 SRAM、DRAM 那样直接覆盖任意单元；
- 写入和擦除速度慢于读取；
- 擦写次数有限，需要通过控制器进行磨损均衡等管理；
- 可用于固件存储、U 盘、存储卡和 SSD。

SSD 的通道组织、闪存转换层和磨损均衡属于外部存储器内容，本节只需掌握 Flash 的非易失性、按块擦除及读写不对称等基本特征。

### 2.4 RAM、ROM 与非易失性的关系

RAM、ROM 和易失性描述的不是完全相同的分类维度：

- RAM 强调能够按地址随机存取，并可在正常工作中读写；
- ROM 强调正常工作时以读取为主，改写受到限制；
- 易失性或非易失性强调断电后能否保存信息。

因此，不能简单把“RAM”理解为随机存放，也不能把“ROM”理解为只能顺序读取。Flash 断电后不丢失，且读取时同样可以按地址访问。

## 3. 多模块存储器

提高单个存储芯片的速度比较困难，因此可以使用多个存储模块并行或交叉工作，提高主存的连续访问吞吐率。

多模块存储器主要提高带宽，并不必然缩短一次单字访问的存取时间。

### 3.1 单体多字存储器

单体多字存储器把多个相邻存储字组成一个更宽的存储单元，在一个存取周期内同时读出多个字。

若一次并行读出 $m$ 个字，则存储体、数据寄存器和内部数据通路都要具有相应宽度。读出的多个字可以通过宽总线并行传送，也可以在外部总线上分时传送。

这种方式适合顺序读取和按块传送，但存在以下限制：

- 一次总是读出固定的一组相邻字；
- 访问不连续地址时，读出的其他字可能无用；
- 存储体仍是一个整体，不能独立启动多次访问。

### 3.2 多体并行存储器

多体并行存储器由 $m$ 个容量和速度相同、可以独立启动访问的存储模块组成。每个模块通常具有自己的地址寄存器、数据寄存器和读写控制电路。

若每个模块的规格为 $N\times W\text{ bit}$，共有 $m$ 个模块，则总容量为：

$$
mN\times W\text{ bit}
$$

多体并行存储器有高位交叉编址和低位交叉编址两种基本组织方式。

### 3.3 高位交叉编址

设总地址有 $n$ 位，模块数为 $m=2^r$。高位交叉编址用地址的高 $r$ 位选择模块，低 $n-r$ 位作为模块内地址：

$$
\underbrace{\text{模块号}}_{r\text{ 位}}
\quad
\underbrace{\text{模块内地址}}_{n-r\text{ 位}}
$$

连续地址先集中在同一个模块中，填满一个模块后才进入下一个模块。因此：

- 便于按模块扩充连续地址空间；
- 不同模块可以独立工作；
- 连续访问通常集中在同一模块，难以形成流水访问；
- 常用于存储容量扩展，也称顺序编址方式。

### 3.4 低位交叉编址

低位交叉编址用地址的低 $r$ 位选择模块，高 $n-r$ 位作为模块内地址：

$$
\underbrace{\text{模块内地址}}_{n-r\text{ 位}}
\quad
\underbrace{\text{模块号}}_{r\text{ 位}}
$$

若把地址 $A$ 看成存储字地址，则：

$$
\text{模块号}=A\bmod m
$$

$$
\text{模块内地址}=\left\lfloor\frac{A}{m}\right\rfloor
$$

当 $m=4$ 时，连续字地址的分布为：

| 字地址 | 模块号 | 模块内地址 |
| ---: | ---: | ---: |
| $0$ | $0$ | $0$ |
| $1$ | $1$ | $0$ |
| $2$ | $2$ | $0$ |
| $3$ | $3$ | $0$ |
| $4$ | $0$ | $1$ |
| $5$ | $1$ | $1$ |

连续地址依次分布到不同模块，因此可以在前一个模块尚未完成访问时启动下一个模块，实现交叉流水访问。低位交叉编址也称交叉编址方式。

::: warning 地址单位
上述公式中的 $A$ 是存储字地址。若题目给出的是按字节编址的字节地址，应先根据一个存储字包含的字节数确定字地址或块内偏移，不能直接套用 $A\bmod m$。
:::

### 3.5 模块冲突

低位交叉编址并不保证任意访问序列都能并行。如果新的访问在某个模块完成上一次访问之前又选中了同一模块，就会发生模块冲突。

对于 $m$ 个低位交叉模块，字地址之差为 $m$ 的整数倍时，它们映射到同一模块：

$$
A_1\equiv A_2\pmod m
$$

例如，$m=4$ 时，字地址 $0、4、8、12$ 都位于模块 $0$。这些地址若在过短时间内连续发出，就不能充分利用模块并行性。

### 3.6 连续访存时间与带宽

设每个模块的存取周期为 $T$，相邻模块能够启动访问或通过总线传送一个字的最小时间间隔为 $\tau$。

为了让低位交叉存储器在连续访问时不因模块尚未恢复而停顿，模块数通常应满足：

$$
m\geq\left\lceil\frac{T}{\tau}\right\rceil
$$

若模块数足够、访问连续且没有冲突，连续读取 $n$ 个字所需时间通常为：

$$
T+(n-1)\tau
$$

其中，第一个字在 $T$ 时间后得到，此后每隔 $\tau$ 得到一个字。

例如，$m=4$、$T=80\text{ ns}$、$\tau=20\text{ ns}$，连续读取 $8$ 个字且无冲突时：

$$
80+(8-1)\times20=220\text{ ns}
$$

若每个字为 $W$ 位，流水稳定后的理论峰值带宽为：

$$
B_{max}=\frac{W}{\tau}
$$

实际题目还可能受到总线宽度、控制开销、地址序列和模块冲突影响，应按题设判断能否使用理想流水公式。

### 3.7 三种组织方式对比

| 组织方式 | 访问特点 | 主要作用 |
| --- | --- | --- |
| 单体多字 | 一次从同一存储体读出多个相邻字 | 增大一次读出的数据宽度 |
| 高位交叉多体 | 连续地址先位于同一模块 | 便于容量扩展，连续访问并行性较弱 |
| 低位交叉多体 | 连续地址分布到不同模块 | 支持交叉流水，提高连续访问带宽 |

## 4. 408 常见考法与易错点

| 考点 | 解题入口 |
| --- | --- |
| SRAM 与 DRAM | 比较存储元、刷新、破坏性读出、速度、集成度和用途 |
| DRAM 地址复用 | 行地址与列地址分时使用同一组引脚 |
| DRAM 刷新 | 根据行数和最大刷新间隔计算相邻刷新时间 |
| DRAM 芯片和内存条 | 根据芯片组织形式、数据宽度和 Rank 数量计算内存条容量 |
| Flash | 掌握非易失、按块擦除及读写不对称 |
| 高低位交叉 | 先拆分模块号和模块内地址，再判断连续地址分布 |
| 模块冲突 | 判断相邻访问是否在模块恢复前再次选择同一模块 |
| 连续访存时间 | 在满足模块数且无冲突时使用 $T+(n-1)\tau$ |

特别注意：

- SRAM 不需要刷新，但断电后信息会丢失。
- DRAM 的刷新按行进行，不能用总存储单元数直接代替行数。
- 地址复用减少的是 DRAM 地址引脚数，不减少存储容量。
- 同一 Rank 内的 DRAM 芯片并行提供数据位；增加 Rank 通常增加可寻址容量，不等同于增加单次数据宽度。
- ROM 可以按地址随机读取，“只读”不等于顺序存取。
- Flash 通常按块擦除，不能把它的写操作等同于普通 RAM 覆盖写。
- 高位交叉用高位选择模块，低位交叉用低位选择模块。
- 多模块存储器主要提高吞吐率和带宽，单字访问时间不一定缩短。
- 低位交叉只有在模块数足够且地址序列不冲突时才能达到理想流水性能。

## 5. 本节小结

本节的核心关系可以概括为：

$$
\text{SRAM 以速度见长}
\quad
\text{DRAM 以容量和成本见长}
\quad
\text{ROM/Flash 负责非易失保存}
