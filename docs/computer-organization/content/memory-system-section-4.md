<h1><center>第四节 外部存储器</center></h1>

外部存储器简称外存，用于长期保存大量程序和数据。外存具有容量大、单位容量成本低、断电后信息不丢失等特点，但访问速度通常低于主存。

CPU 一般不能使用普通访存指令直接处理外存中的数据。外存通过 I/O 系统与主机交换信息，程序和数据通常需要先调入主存，才能由 CPU 执行或使用。

本节重点讨论两类 408 外部存储器：

$$
\text{磁盘存储器}
\qquad
\text{固态硬盘}
$$

## 1. 磁盘存储器

磁盘存储器利用磁性材料表面的不同磁化状态记录二进制信息。传统机械硬盘由盘片、主轴、磁头、磁头臂、驱动机构和磁盘控制器等部分组成。

### 1.1 磁盘的物理结构

| 组成 | 含义 |
| --- | --- |
| 盘片 | 表面覆盖磁性材料的圆形介质，工作时绕主轴旋转 |
| 盘面 | 盘片上能够记录信息的表面 |
| 磁头 | 对相应盘面执行读写操作的部件 |
| 磁头臂 | 带动磁头沿盘片半径方向移动 |
| 主轴 | 带动所有盘片以固定转速旋转 |
| 磁盘控制器 | 接收主机命令，控制定位、数据传输和差错检测等操作 |

同一主轴上的盘片以相同角速度旋转。各盘面的磁头通常安装在同一执行机构上，会一起沿半径方向移动。

### 1.2 磁道、扇区和柱面

| 概念 | 含义 |
| --- | --- |
| 磁道 | 一个盘面上的同心圆形记录区域 |
| 扇区 | 磁道划分出的数据记录区域，是传统模型中的基本读写单位 |
| 柱面 | 所有盘面上半径相同的磁道集合 |
| 记录面号 | 指明使用哪个盘面及对应磁头 |

磁头定位到某一半径后，不移动磁头臂而只切换磁头，就可以访问同一柱面中的不同盘面。

传统 408 题目常把磁盘地址理解为：

$$
\text{柱面号}
+
\text{盘面号}
+
\text{扇区号}
$$

实际磁盘通常向主机提供连续的逻辑块地址，由磁盘控制器完成逻辑块到物理位置的映射；计算题若明确给出盘面、磁道和扇区参数，则按题设的传统模型分析。

### 1.3 磁盘的读写过程

读取一个磁盘块通常经历以下过程：

1. **寻道**：移动磁头，使其到达目标柱面。
2. **选择磁头**：选择目标记录面对应的磁头。
3. **旋转等待**：等待目标扇区旋转到磁头下方。
4. **数据传输**：磁盘旋转经过目标扇区时，连续读出或写入数据。
5. **接口传送**：磁盘控制器经过缓冲和校验后与主机交换数据。

磁盘的随机访问延迟较大，主要原因是寻道和旋转等待涉及机械运动。顺序访问时，磁头可以连续读取相邻扇区，能够显著减少机械定位开销。

### 1.4 磁盘容量

若磁盘各磁道的扇区数相同，则格式化数据容量可以按下式计算：

$$
C
=
\text{可用盘面数}
\times
\text{每面磁道数}
\times
\text{每道扇区数}
\times
\text{每扇区字节数}
$$

这里必须使用实际可记录数据的盘面数，不能看到盘片数后直接乘 $2$；有些盘面可能不用于存储数据。

例如，某磁盘有 $4$ 个可用盘面，每面有 $1024$ 条磁道，每道有 $64$ 个扇区，每个扇区为 $512\text{ B}$，则容量为：

$$
4\times1024\times64\times512\text{ B}
=2^{27}\text{ B}
=128\text{ MiB}
$$

若题目给出柱面数，则：

$$
\text{柱面数}=\text{每面磁道数}
$$

因此也可以使用：

$$
C
=
\text{柱面数}
\times
\text{每柱面磁道数}
\times
\text{每道扇区数}
\times
\text{每扇区字节数}
$$

::: warning 容量单位
传统 408 容量题未作特殊说明时，常取 $1K=2^{10}$、$1M=2^{20}$。实际硬盘厂商标注容量时通常采用十进制单位。考试应严格按照题目给出的单位关系换算。
:::

### 1.5 磁盘转速与旋转时间

磁盘转速通常使用 rpm，即每分钟转数。若转速为 $R\text{ rpm}$，旋转一周所需时间为：

$$
T_{rev}
=
\frac{60}{R}\text{ s}
=
\frac{60000}{R}\text{ ms}
$$

若目标扇区相对于磁头的初始位置是随机的，平均旋转延迟通常取半圈时间：

$$
T_{rot}
=
\frac{T_{rev}}{2}
=
\frac{30000}{R}\text{ ms}
$$

“平均半圈”只用于目标扇区初始位置均匀随机的情况。若题目给出了目标扇区和磁头的具体相对位置，应按实际旋转角度计算。

### 1.6 数据传输时间

若一个磁道有 $S$ 个等长扇区，读取同一磁道内连续的 $n$ 个扇区，传输时间为：

$$
T_{trans}
=
\frac{n}{S}T_{rev}
$$

若已知磁盘的持续数据传输率为 $v$，传输 $B$ 字节数据所需时间为：

$$
T_{trans}=\frac{B}{v}
$$

上述扇区公式假设数据位于同一磁道并连续排列。若读取范围跨越磁道或柱面，还可能产生额外的磁头切换、寻道或旋转等待，必须按照题目条件处理。

### 1.7 磁盘访问时间

一次磁盘访问时间通常由下列部分构成：

$$
T_{access}
=
T_{seek}
+
T_{rot}
+
T_{trans}
+
T_{ctrl}
$$

其中：

- $T_{seek}$：寻道时间；
- $T_{rot}$：旋转延迟；
- $T_{trans}$：数据传输时间；
- $T_{ctrl}$：控制器、排队或接口开销，题目未给出时通常忽略。

平均寻道时间一般由题目直接给出。除非题目明确提供寻道模型，否则不能简单把最大寻道时间除以 $2$ 当作平均寻道时间。

例如，某磁盘转速为 $7200\text{ rpm}$，平均寻道时间为 $8\text{ ms}$，每道有 $200$ 个扇区。读取同一磁道内连续的 $20$ 个扇区，忽略控制器开销：

$$
T_{rev}=\frac{60000}{7200}\approx8.33\text{ ms}
$$

$$
T_{rot}=\frac{8.33}{2}\approx4.17\text{ ms}
$$

$$
T_{trans}=\frac{20}{200}\times8.33\approx0.83\text{ ms}
$$

所以平均访问时间为：

$$
T_{access}
\approx
8+4.17+0.83
=13.00\text{ ms}
$$

### 1.8 磁盘的性能特点

- 容量大，单位容量成本低；
- 断电后能够长期保存信息；
- 顺序传输速度较高；
- 随机访问需要机械寻道和旋转等待，延迟较大；
- 数据访问通常以扇区或逻辑块为单位；
- 内部控制器和缓存可以改善接口传输效率，但不能消除机械定位延迟。

磁盘调度算法主要属于操作系统的 I/O 管理内容。本节只需理解不同访问顺序会影响寻道距离，不在这里展开 FCFS、SSTF、SCAN 等调度算法。

## 2. 固态硬盘

固态硬盘简称 SSD，通常以 NAND Flash 作为存储介质，并通过控制器向主机提供与块设备相似的访问接口。

SSD 没有磁头和旋转盘片，因此不存在机械寻道时间和旋转延迟，但仍然存在 Flash 读取、编程、擦除、地址映射和垃圾回收等开销。

### 2.1 SSD 的基本组成

SSD 通常由以下部分构成：

| 部件 | 作用 |
| --- | --- |
| Flash 存储芯片 | 实际保存数据 |
| SSD 控制器 | 处理主机命令，完成地址映射、并行调度、纠错和维护 |
| 缓冲存储器 | 缓存映射信息或待传输数据，具体实现可以不同 |
| 主机接口 | 通过 SATA、PCIe/NVMe 等接口与计算机连接 |

多个 Flash 通道和芯片可以并行工作，从而提高 SSD 的读写吞吐率。

### 2.2 Flash 的层次结构

从概念上看，SSD 中的 Flash 可以组织为：

$$
\text{芯片}
\longrightarrow
\text{块}
\longrightarrow
\text{页}
\longrightarrow
\text{存储单元}
$$

- **页**通常是读取和编程写入的基本单位；
- **块**由多个页组成，是擦除的基本单位；
- 主机看到的逻辑块与 Flash 物理页之间由控制器进行映射。

这里的 Flash 块是擦除单位，不要与文件系统块、磁盘逻辑块或 Cache 块混为一谈。

### 2.3 读、写和擦除

Flash 的三种基本操作具有明显的不对称性：

| 操作 | 常见单位 | 特点 |
| --- | --- | --- |
| 读取 | 页 | 速度较快，不需要先擦除 |
| 编程写入 | 页 | 比读取慢，只能把存储单元向允许的编程状态改变 |
| 擦除 | 块 | 最慢，一次影响块中的多个页 |

Flash 不能像普通 RAM 那样任意覆盖已经写入的物理页。更新数据时，控制器通常执行异地更新：

1. 把新数据写入另一个可用物理页；
2. 更新逻辑地址到物理页的映射；
3. 将原物理页标记为无效；
4. 在适当时机回收包含无效页的块。

这就是 SSD 写入过程比简单读取复杂的重要原因。

### 2.4 闪存转换层（扩展）

闪存转换层 FTL 位于 SSD 控制器中，负责把主机使用的逻辑块地址转换为 Flash 的物理页位置。

FTL 的主要作用包括：

- 维护逻辑地址到物理地址的映射；
- 支持异地更新，隐藏 Flash 不能原地覆盖写的限制；
- 组织垃圾回收；
- 执行磨损均衡；
- 管理坏块并配合差错校验。

因此，主机看到的是一个可以按逻辑块读写的设备，而不是直接操作 Flash 的物理页和块。

### 2.5 垃圾回收与写放大（扩展）

一个 Flash 块中可能同时存在有效页和无效页。为了重新获得可写的空闲块，控制器需要执行垃圾回收：

1. 选择包含较多无效页的块；
2. 把仍然有效的页复制到其他位置；
3. 擦除整个旧块；
4. 将擦除后的块重新加入空闲块集合。

垃圾回收需要额外的数据搬移和擦除，会增加写入延迟，并可能产生写放大。

**写放大**是指 Flash 内部实际写入的数据量大于主机请求写入的数据量。垃圾回收、有效页搬移和元数据更新都可能导致写放大。

### 2.6 磨损均衡

Flash 存储块能够承受的擦写次数有限。如果某些块被反复擦写而其他块很少使用，前者会更早失效。

磨损均衡通过在不同物理块之间分散擦写操作，使各块的擦写次数尽量均匀，从而延长 SSD 的整体使用寿命。

磨损均衡改变的是数据的物理存放位置。由于 FTL 维护地址映射，这种移动通常对主机透明。

### 2.7 SSD 的性能特点

- 没有机械寻道和旋转等待，随机访问延迟远低于磁盘；
- 可以利用多个 Flash 通道并行访问；
- 读取、写入和擦除的速度不同，通常读取最快、擦除最慢；
- 小规模随机写可能引发异地更新和垃圾回收，代价高于读取；
- Flash 擦写寿命有限，需要磨损均衡和坏块管理；
- 无机械部件，抗振动能力较强，工作噪声低；
- 性能会受到空闲块数量、垃圾回收、并行度和控制器策略影响。

### 2.8 磁盘与 SSD 对比

| 项目 | 磁盘存储器 | 固态硬盘 |
| --- | --- | --- |
| 存储介质 | 磁性盘片 | Flash |
| 机械部件 | 有 | 无 |
| 随机访问延迟 | 较高，包含寻道和旋转等待 | 较低，无机械定位延迟 |
| 顺序传输 | 适合连续传输 | 可通过多通道获得较高带宽 |
| 更新方式 | 可以覆盖目标扇区 | 通常异地更新，擦除以块为单位 |
| 使用寿命限制 | 主要受机械磨损等因素影响 | Flash 块擦写次数有限 |
| 抗振动能力 | 较弱 | 较强 |
| 单位容量成本 | 通常较低 | 通常较高 |

SSD 没有机械访问时间，不等于访问没有延迟。读取、编程、擦除、映射查询、垃圾回收和接口传输仍然需要时间。

## 3. 408 常见考法与易错点

| 考点 | 解题入口 |
| --- | --- |
| 磁盘结构 | 分清盘片、盘面、磁道、扇区和柱面 |
| 磁盘容量 | 可用盘面数 $\times$ 每面磁道数 $\times$ 每道扇区数 $\times$ 扇区大小 |
| 转速换算 | $T_{rev}=60000/R\text{ ms}$ |
| 平均旋转延迟 | 在随机位置假设下取旋转一周时间的一半 |
| 传输时间 | 连续 $n$ 个扇区使用 $(n/S)T_{rev}$ |
| 总访问时间 | 寻道时间、旋转延迟、传输时间及题目给出的额外开销相加 |
| SSD 读写 | 页是读和编程单位，块是擦除单位 |
| SSD 使用寿命 | 理解擦写次数限制及磨损均衡的作用 |

特别注意：

- 盘片数不一定等于可用盘面数，容量计算应使用题目给出的记录面数量。
- 柱面是不同盘面上半径相同的磁道集合，不是一个盘面上的圆环区域。
- rpm 是每分钟转数，换算毫秒时使用 $60000/R$。
- 平均旋转延迟通常为半圈，但平均寻道时间不能在没有题设依据时直接取最大值的一半。
- 磁盘访问时间通常远大于单纯的数据传输时间，随机访问中机械延迟占主要部分。
- SSD 没有寻道和旋转延迟，但仍有 Flash 和控制器访问开销。
- SSD 通常按页读取和编程、按块擦除，三种操作的粒度不同。
- 垃圾回收用于回收无效页占据的空间，磨损均衡用于延长设备寿命，二者作用不同。

## 4. 本节小结

本节的核心关系可以概括为：

$$
\text{磁盘通过机械定位访问扇区}
\quad\Longrightarrow\quad
\text{重点计算容量与访问时间}
$$

$$
\text{SSD 通过控制器管理 Flash}
\quad\Longrightarrow\quad
\text{重点理解页、块、地址映射和擦写管理}
$$

复习磁盘时要把寻道、旋转和传输三个阶段分开；复习 SSD 时要抓住“页读写、块擦除、不能原地覆盖、控制器完成地址映射”这条主线。
